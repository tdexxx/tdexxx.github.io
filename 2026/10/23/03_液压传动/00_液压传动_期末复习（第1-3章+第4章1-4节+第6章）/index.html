二、第一章 液压流体力学基础

2.1 第一节 液压油液

（1）液压油的四大作用

传递运动和动力、冷却（带走热量）、润滑、防锈。

（2）粘度的三种表示（填空题第 1 题）

名称 符号/单位 说明
动力粘度 $\mu$，Pa·s 由牛顿内摩擦定律定义，$\tau = \mu \dfrac{du}{dy}$
运动粘度 $\nu = \dfrac{\mu}{\rho}$，m²/s（常用 mm²/s） 液压油牌号的数字就是它
相对粘度（条件粘度） 恩氏粘度 °E 等 用特定粘度计测出的条件性数值

必背：工程中常用的是动力粘度、运动粘度和相对粘度（条件粘度）三种。
牌号举例：L-HM46 中的 46 表示该油在 40 ℃ 时的运动粘度约为 46 mm²/s。

（3）粘度与温度

温度升高 → 粘度减小（变稀）；温度降低 → 粘度增大（变稠）。

  • 粘度太大：吸油困难、流动阻力大、功率损失大、发热；
  • 粘度太小：泄漏增大、容积效率下降、润滑不良、磨损加剧。
  • 因此低温或寒冷工况应选粘度较小（牌号较低）的油，高温工况选牌号较高的油。

（4）可压缩性

用体积弹性模量 $K$ 表示：$K = -V\dfrac{\Delta p}{\Delta V}$，$K$ 越大越难压缩。

  • 液压油的 $K$ 很大（约 1.4～2 GPa），在一般工程计算中可视为不可压缩流体；
  • 但压力越高，压缩量并不按线性无限增大——液体体积随压力增大而减小，但减小量是有限的、非线性的（这是判断题第 21 题的陷阱）。

2.2 第二节 液体静力学

（1）静压力的两个重要特性

  1. 静压力的方向永远垂直于作用面，并指向作用面内部（只能压不能拉）；
  2. 静止液体内任意一点各方向的静压力相等（与方向无关，是标量）。

（2）静压力基本方程

$p = p_0 + \rho g h$

  • $p_0$ 为液面压力，$h$ 为距液面的深度；
  • 结论：同一液体中，深度相同的点压力相等（等压面）；压力随深度线性增大。

（3）压力的表示与单位

表示法 含义
绝对压力 以绝对真空为零点
相对压力（表压力） 以大气压为零点，仪表测到的就是它
真空度 绝对压力低于大气压时，$p_{真}=p_a-p_{绝}$

关系：绝对压力 = 大气压 + 相对压力。
单位换算：$1\ \text{MPa}=10^6\ \text{Pa}$，$1\ \text{bar}=10^5\ \text{Pa}$，$1\ \text{at}=9.8\times10^4\ \text{Pa}$。

（4）帕斯卡原理（静压传递原理）

在密闭容器内，施加于静止液体上的压力，将等值地传递到液体各点。

  • 这是液压传动的理论基础（17 世纪帕斯卡提出）；
  • 推论：液压系统的压力由负载决定，负载越大压力越高；
  • 应用：液压千斤顶、液压机——力放大靠面积比：$F_2 = F_1\dfrac{A_2}{A_1}$。

（5）静压力对固体壁面的作用力

$F = pA$（$p$ 为形心处压力，$A$ 为承压面积）；曲面则取投影面积。

2.3 第三节 液体动力学（计算题核心）

（1）基本概念

概念 含义
理想液体 无粘性、不可压缩的假想液体
稳定流动 流场中任一点的压力、流速、密度不随时间变化
流线 某一瞬时，线上各点速度方向与该点切线重合
流束 流线的集合
通流截面 流束中与所有流线正交的截面
流量 $q$ 单位时间通过某通流截面的液体体积，$q=vA$
平均流速 $v$ $v=\dfrac{q}{A}$（工程计算都用平均流速）

（2）流量连续性方程

依据：质量守恒（不可压缩 → 体积守恒）

$q = v_1 A_1 = v_2 A_2 = \text{常量}$

即：流速与通流面积成反比。

推论（液压缸常用）：$v=\dfrac{q}{A}$，面积越大速度越慢、推力越大。

（3）伯努利方程

理想液体稳定流动（沿流线，取两截面）：

$p_1 + \dfrac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \dfrac{1}{2}\rho v_2^2 + \rho g z_2$

实际液体（计入能量损失 $\Delta p_w$）：

$p_1 + \dfrac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \dfrac{1}{2}\rho v_2^2 + \rho g z_2 + \Delta p_w$

三项物理意义：压力能 + 动能 + 位能 = 常量。

判断题第 29 题的陷阱：题目说”理想液体在水平等截面直管中作稳定流动时，各截面压力保持不变”——这个表述在理想液体条件下是对的（无损失、等截面等速、水平等位），但原题给的是”实际液体“，实际液体有沿程损失 $\Delta p_w$，压力沿流动方向逐渐降低，所以原题判错。
记忆点：理想液体无损失→压力不变；实际液体有损失→压力沿程下降。

（4）动量方程

$\sum F = \rho q (v_2 - v_1)$

用于求液流对壁面的作用力（如弯管、阀口、液压缸的液动力）。

2.4 第四节 管道流动（计算题核心）

（1）两种流态

流态 特征
层流 流体质点作线状有序运动，各层互不掺混
紊流（湍流） 质点作杂乱无章的运动，有横向脉动与掺混

（2）雷诺数与临界雷诺数（填空题第 2 题 / 单选题第 11 题）

$Re = \dfrac{v d}{\nu} = \dfrac{\rho v d}{\mu}$

物理本质：惯性力与粘性力之比。

判据 数值
下临界雷诺数（圆管） $Re_{cr} = 2320$
上临界雷诺数 约 4000 以上（不稳定，不作判据）

判定：**$Re < 2320$ 为层流；$Re \ge 2320$ 为紊流**。

其他通流截面的临界雷诺数不同（如缝隙流、同心环缝），考试只考圆管 2320。

（3）沿程压力损失

层流（圆管）：$\lambda = \dfrac{64}{Re}$（部分教材写 75/Re，以教材为准）

紊流：$\lambda$ 由雷诺数和管壁相对粗糙度共同决定（查莫迪图/经验公式）。

通用公式：$\Delta p_\lambda = \lambda \dfrac{l}{d}\cdot\dfrac{\rho v^2}{2}$

结论：沿程损失与管长成正比、与管径成反比、与流速的平方成正比。

（4）局部压力损失

$\Delta p_\zeta = \zeta \dfrac{\rho v^2}{2}$

$\zeta$ 为局部阻力系数（查表），对应弯头、接头、阀口、截面突变等处。

（5）系统总压力损失（填空题第 3 题）

$\Delta p_{\text{总}} = \sum \Delta p_\lambda + \sum \Delta p_\zeta$

即：总压力损失 = 沿程压力损失 + 局部压力损失。

工程上也可用 $\Delta p_{\text{总}} = \sum \Delta p_{\text{额定}}\left(\dfrac{q}{q_{\text{额定}}}\right)^2$ 估算（阀类元件）。

2.5 第五节 孔口流动

（1）薄壁小孔（$l/d \le 0.5$）

$q = C_d A \sqrt{\dfrac{2\Delta p}{\rho}}$

  • $C_d$ 为流量系数，薄壁孔约 0.62；
  • 流量与 $\Delta p$ 的平方根成正比，即 $m=0.5$；
  • 特点：流量受粘度影响小、受压力影响大，适合作调节元件。

（2）细长孔（$l/d > 4$）

$q = \dfrac{\pi d^4 \Delta p}{128 \mu l}$

  • 流量与 $\Delta p$ 成正比（$m=1$），与粘度成反比；
  • 特点：受油温（粘度）影响大，不宜作调节元件。

（3）通用形式

$q = K A \Delta p^{m}$

孔口类型 $m$
薄壁孔 0.5
短孔 0.5～1 之间
细长孔 1

滑阀阀口按薄壁孔处理（$m=0.5$）；锥阀阀口也近似薄壁孔。

2.6 第六节 缝隙流动（只记结论）

缝隙类型 泄漏特点
平板缝隙 泄漏量与缝隙高度的三次方成正比、与长度成反比
同心圆环缝隙 同上，缝隙（半径间隙）的三次方
偏心圆环缝隙 偏心越大泄漏越大，完全偏心时泄漏量是同心时的 2.5 倍

**核心结论：缝隙泄漏 $\propto h^3$**——所以配合间隙稍大，泄漏就急剧增加，这是容积效率下降的主因。

2.7 第七节 液压冲击与气穴现象

（1）液压冲击

原因：管路中液流速度突然变化（阀门突然关闭/换向、执行元件突然停止），因液体惯性产生压力急剧升高。

危害：压力峰值可达正常工作压力的数倍，引起振动、噪声、管路破裂、元件损坏、密封失效。

减小措施：

  1. 延长阀门关闭/换向时间（缓慢关闭）；
  2. 在冲击处设置蓄能器或安全阀；
  3. 加大管径、缩短管路长度（降低流速与惯性）；
  4. 采用橡胶软管吸收冲击；
  5. 在液压缸端部设缓冲装置。

（2）气穴（空穴）现象

原因：液流中某处压力低于该温度下的空气分离压（或饱和蒸气压），溶解的空气析出或液体汽化，形成气泡。

危害：气泡到高压区急剧溃灭，产生局部高压冲击与高温，造成气蚀（金属表面剥落）、振动、噪声、流量与压力不稳定。

防止措施：

  1. 降低吸油高度、增大吸油管径、减小吸油阻力；
  2. 保证液压泵的吸油口密封良好，防止吸入空气；
  3. 控制油温，避免油液粘度下降、蒸气压升高；
  4. 提高系统背压，避免局部低压；
  5. 采用抗泡性好的液压油。

三、第二章 液压泵

3.1 第一节 概述

（1）作用与能量转换

液压泵是系统的**”心脏”和动力元件：输入机械能（转矩、转速），输出液压能**（压力、流量）。

（2）液压泵工作的三个必要条件（简答/填空高频）

  1. 具有密封（密闭）的工作腔；
  2. 密封工作腔的容积能周期性变化（增大吸油、减小压油）；
  3. 具有配流装置（单向阀、配油盘、配流轴等），把吸油口与压油口隔开。

缺第 3 条的后果：压油时油会向阻力小的吸油口倒流，建立不起压力。

（3）压力的三个概念

名称 含义
工作压力 实际出口压力，由负载决定（负载↑则压力↑，空载近似为 0）
额定压力 铭牌规定的、可连续工作的最高压力
最大压力 短时允许的极限压力，超过会破坏结构，不允许长期使用

（4）排量、流量与效率（计算题核心）

量 公式 说明
排量 $V$ — 每转一周排出的液体体积，只由结构决定，与转速无关
理论流量 $q_t$ $q_t = V n$ $n$ 为转速
实际流量 $q$ $q = q_t \eta_v = V n \eta_v$ 扣除泄漏
容积效率 $\eta_v$ $\eta_v = \dfrac{q}{q_t}$ 反映泄漏损失
机械效率 $\eta_m$ $\eta_m = \dfrac{T_t}{T_i}$ 反映摩擦损失
总效率 $\eta$ $\eta = \eta_v \eta_m$ 如各 0.9，则总效率 0.81
输出功率 $P_o$ $P_o = p q$ 液压功率
输入功率 $P_i$ $P_i = \dfrac{P_o}{\eta} = 2\pi n T_i$ 机械功率

单位提醒：$p$ 用 Pa、$q$ 用 m³/s 时功率为 W；工程上常用 $P(\text{kW}) = \dfrac{p(\text{MPa})\times q(\text{L/min})}{60}$。

（5）效率特性曲线

  • 压力升高 → 油膜改善润滑 → 机械效率上升；
  • 压力升高 → 缝隙泄漏增大 → 容积效率下降；
  • 两者乘积 → 总效率曲线存在最大值，选泵应使工作压力落在总效率最高点附近。

（6）分类

分类依据 类型
排量能否调节 定量泵 / 变量泵
油口能否对调 单向泵 / 双向泵
结构形式 齿轮泵、叶片泵、柱塞泵、螺杆泵

3.2 第二节 柱塞泵

（1）径向柱塞泵

  • 转子与定子偏心安装，柱塞沿径向布置；
  • 转子转动时柱塞径向往复，靠配流轴上的腰形窗口与隔墙分隔吸、压油区；
  • 改变偏心距 $e$ 即可变量（可双向变量）。

（2）轴向柱塞泵（填空题第 4 题）

类型 结构要点
斜盘式 斜盘固定不转、缸体旋转，柱塞端部经滑履压在斜盘上，靠斜盘倾斜面轴向往复；靠配油盘配流
斜轴式 传动圆盘与主轴做成一体，经球铰/连杆带动柱塞，允许主轴与缸体轴线有夹角

变量原理（必考）：改变斜盘倾角 $\alpha$ 即可改变柱塞行程、从而改变排量。

  • $\alpha$ 增大 → 行程增大 → 排量增大；
  • $\alpha = 0$ → 排量为 0（停止供油）；
  • $\alpha$ 反向 → 吸、压油口互换，流向改变，可做双向变量泵。

结构细节：

  • 滑履 + 静压支承：柱塞空心引压力油到滑履底面，形成静压支承，减小摩擦磨损，滑履磨坏可更换；
  • 配油盘减震槽：让柱塞腔在高低压切换前预先缓慢卸压，减小压力突变冲击；
  • 柱塞数取奇数（如 9 个）比偶数（如 10 个）流量脉动更小；
  • 定位销：防止配油盘装错方向（装错会使吸、压油口连通，无法建压）。

总评：压力高、流量大、单位功率重量小、寿命长、易变量；缺点结构复杂、价高、噪声大、对油液污染敏感。

3.3 第三节 叶片泵

（1）单作用叶片泵

  • 转子与定子偏心，每转完成一次吸油、一次压油（一个吸油口、一个压油口）；
  • 改变偏心距 $e$ 的大小和方向可改变排量和流向 → 可做双向变量泵；
  • 径向力不平衡。

限压式变量叶片泵（单选题第 12 题的答案）：

  • 在单作用叶片泵上加压力反馈油路；
  • 当系统压力超过弹簧设定值时，反馈压力推动定子、使偏心距减小直至为 0，排量归零、停止供油；
  • 作用：限制最高压力、起安全保护，是从开环到闭环（反馈）控制的典型。

（2）双作用叶片泵（重点）

  • 定子与转子同心；
  • 定子内表面由 8 段曲线组成（两段大圆弧 + 两段小圆弧 + 四段过渡曲线，常用等加速等减速曲线）；
  • 每转两次吸油、两次压油；配油盘上对称布置两个吸油口、两个压油口；
  • 径向力对称平衡，运转平稳、噪声低；
  • 结构对称、无偏心可调 → 只能定量，不能变量，但可正反转；
  • 叶片相对转子径向前倾一个角度（减小压力角、改善受力）。

单作用 vs 双作用 一句话对比：单作用偏心、可变量、径向力不平衡、一次吸压；双作用同心、定量、径向力平衡、两次吸压。

3.4 第四节 齿轮泵（**简答题必考”困油”**）

（1）外啮合齿轮泵工作原理

一对齿轮转动：脱开啮合侧齿间槽容积增大 → 吸油；进入啮合侧齿间槽容积减小 → 压油。
啮合线（啮合点）把吸油腔与压油腔隔开（重合度 > 1，至少两对齿同时接触）。

（2）排量近似公式

$V \approx 6.66, z, m^2 b$

$z$ 齿数、$m$ 模数、$b$ 齿宽。系数 6.66 略大于 $2\pi$，因为齿间槽体积比轮齿体积略大。
齿数越多（节圆直径一定）流量脉动越小。

4.2 第二节 液压缸

（1）单杆活塞缸的三种连接方式（填空题第 5 题 / 单选第 13 题）

设无杆腔面积 $A_1 = \dfrac{\pi D^2}{4}$，有杆腔面积 $A_2 = \dfrac{\pi (D^2-d^2)}{4}$，活塞杆截面积 $A_杆 = A_1 - A_2 = \dfrac{\pi d^2}{4}$。

连接方式 速度 推力
无杆腔进油（有杆腔回油） $v_1 = \dfrac{q}{A_1}$（最慢） $F_1 = p A_1$（最大）
有杆腔进油（无杆腔回油） $v_2 = \dfrac{q}{A_2}$ $F_2 = p A_2$
差动连接（两腔同时进压力油） $v_3 = \dfrac{q}{A_1-A_2} = \dfrac{q}{A_杆}$（最快） $F_3 = p(A_1-A_2) = p A_杆$（最小）

速度比（往返速比）：$\lambda_v = \dfrac{v_2}{v_1} = \dfrac{A_1}{A_2} = \dfrac{D^2}{D^2-d^2}$

（2）差动连接（简答题必考）

定义：单杆活塞缸的两腔同时通入压力油，因无杆腔有效面积 $A_1$ 大于有杆腔有效面积 $A_2$，活塞仍向有杆腔一侧运动，有杆腔排出的油液与泵的供油合流后一起进入无杆腔，这种连接方式叫差动连接。

特点：

  1. 推力小：$F = p(A_1-A_2) = pA_杆$，只有无杆腔进油推力的 $\dfrac{A_杆}{A_1}$；
  2. 速度快：$v = \dfrac{q}{A_杆}$，比无杆腔进油快 $\dfrac{A_1}{A_杆}$ 倍；
  3. 可在不增大泵流量的前提下获得较高的快进速度——这是它最大的工程价值（组合机床动力滑台的快进就靠它）；
  4. 只能实现单向的快速运动（反向不差动）。

记忆：**”差动 = 小推力 + 高速度”**，因为有效面积变小了（面积小 → 力小、速度快）。

（3）其他形式液压缸

类型 特点
双杆活塞缸 两腔有效面积相等，往返速度与推力相等
柱塞缸 只能单向运动，回程靠自重或弹簧；结构简单、制造方便，适合长行程
摆动缸（摆动马达） 输出往复摆动（一定角度内的转矩），有单叶片、双叶片式
伸缩（套筒）缸 多级套筒，行程长、收缩后体积小
增压缸 利用大小活塞面积差获得短时高压

五、第四章 液压控制阀（只考 1–4 节）

5.1 第一节 概述

（1）分类

类别 作用 代表
方向控制阀 控制油路通断与流向 单向阀、换向阀
压力控制阀 控制与调节系统压力 溢流阀、减压阀、顺序阀、压力继电器
流量控制阀 控制流量、调节速度 节流阀、调速阀、分流集流阀

（2）基本要求

结构简单、密封可靠、动作灵敏、压力损失小、抗污染、通用性好。

（3）性能参数

额定压力、额定流量、压力损失、内泄漏量、启闭特性、灵敏度等。

5.2 第二节 方向控制阀

（1）单向阀

  • 只允许油液单向通过，反向截止；
  • 开启压力约 0.03～0.05 MPa；
  • 液控单向阀：正常时作单向阀，控制口通压力油时可反向导通——这是液压锁的核心元件。

（2）换向阀的”位”与”通”（必考）

  • 位（工作位置数） = 图形符号中正方形框的个数；
  • 通（油口数） = 一个框上引出的油口数；
  • 常用：二位二通、二位三通、二位四通、三位四通、三位五通；
  • 油口标注：P 压力油口（进油）、T（O） 回油口、A/B 通执行元件两腔。

读图方法：先数框（几位），再数一个框上的接口（几通）。外部油口数量与位置不随阀芯位置改变。

（3）换向阀的操纵方式

方式 特点 适用
手动 结构简单、操作力小 小流量、就地操作
机动（行程） 靠挡块/凸轮压下滚轮 行程控制
电磁 电气控制方便、自动化程度高；但电磁力有限 中低压、中小流量
液动 靠压力油推动阀芯，推力大 高压大流量
电液 小电磁阀作先导，压力油推动主阀芯；兼顾电气控制方便与大流量驱动 高压大流量、换向平稳性要求高（单选题第 17 题）

（4）三位换向阀的中位机能（填空题第 7 题 / 判断题第 25 题）

中位机能 P、T、A、B 连通关系 功能特点
O 型 全部封闭 缸锁紧（保位）；泵不卸荷（P 口封闭，须靠溢流阀溢流）
H 型 全部连通 缸浮动；泵卸荷
Y 型 A、B 通 T，P 封闭 缸浮动（两腔通油箱）；泵不卸荷
M 型 P 通 T，A、B 封闭 泵卸荷；缸两腔封闭锁紧

  • Y 型中位可实现液压缸浮动、液压泵不卸荷；
  • M 型中位可实现液压泵卸荷、液压缸两腔封闭锁紧。

判断题第 25 题：”O 型中位各油口全部封闭，可同时实现液压缸锁紧和液压泵卸荷” → 错。O 型 P 口封闭，泵不能卸荷。

5.3 第三节 压力控制阀（简答题第 33 题）

（1）溢流阀

直动式溢流阀：

  • 常态关闭（阀口关闭）；
  • 进口压力升高到能克服弹簧预紧力时，阀芯移动、阀口打开，多余油溢回油箱；
  • 作用：溢流调压、安全保护（过载保护）、系统卸荷；
  • 缺点：调压偏差大（压力随流量变化），高压大流量时弹簧尺寸大、不灵敏。

先导式溢流阀（填空题第 8 题）：

  • 由主阀和先导阀两部分组成；
  • 先导阀负责控制与调节溢流压力（通过少量控制油），主阀通过 90% 以上溢流量；
  • 优点：调压偏差小、高压大流量时压力稳定性好；
  • 远程控制口：正常可堵死；接远程调压阀可远程调压；直接接油箱即可实现系统卸荷。

关键理解：溢流阀只有阀口开启并实际溢流时，进口压力才由调定压力决定；阀口未开时，进口压力由负载决定，此时溢流阀”说了不算”。

（2）减压阀

  • 出口压力反馈、常态开启（这是它和溢流阀最本质的区别）；
  • 出口压力高于调定值时，阀芯移动使减压口关小、阀口压差增大，把出口压力拉回调定值；
  • 反馈油道来自出油口；
  • 用于支路降压（如夹紧、定位等需要低压的支路）。

（3）顺序阀

  • 本质是液压压力开关，不承担溢流调压作用；
  • 进口压力达到调定值后阀口打开，压力油进入下一个执行元件支路；
  • 用于顺序动作（如”定位缸先动、夹紧缸后动”）；
  • 分内控/外控、内泄/外泄。

（4）压力继电器

把液压压力信号转换为电信号：压力升到设定值时推动柱塞、接通电气触点；压力降低后排油复位。可配合电磁阀实现自动往复或顺序控制。

（5）三阀比较总表（简答题第 33 题的标准答案）

比较项 溢流阀 减压阀 顺序阀
工作原理 利用进口压力与弹簧力平衡，维持进口压力恒定 利用出口压力与弹簧力平衡，维持出口压力恒定 利用进口压力与弹簧力平衡，达到调定值时接通油路
常态阀口状态 关闭 开启 关闭
控制压力来源 进口压力 出口压力 进口压力（内控）；也可外控
泄油方式 内泄（内泄式）或外泄 必须外泄（出口压力油不能回进口） 内泄或外泄
主要用途 溢流调压、安全保护、卸荷 支路降压、稳压 顺序动作、背压、卸荷

记忆口诀：**溢流阀”进口控、常闭、稳进口”；减压阀”出口控、常开、稳出口”；顺序阀”进口控、常闭、做开关”**。

5.4 第四节 流量控制阀

（1）节流阀

  • 通过改变节流口通流面积（开度）调节流量；
  • 流量 $q = K A \Delta p^{m}$；
  • 缺点：流量随负载（压差）变化而变化，速度稳定性差。

（2）调速阀（填空题第 10 题 / 单选题第 19 题）

  • 由定差减压阀与节流阀串联组成；
  • 定差减压阀使节流阀前后压差保持恒定；
  • 因此流量只取决于节流口开度、不受负载变化影响，速度稳定性好；
  • 反向时需并联单向阀（单向调速阀）。

（3）分流集流阀

使两个（或多个）执行元件获得相同流量，实现速度同步。

六、第六章 液压基本回路

6.1 第一节 压力控制回路

回路 作用 关键元件/做法
调压回路 限定系统最高压力 溢流阀（单级）；多级调压用多个溢流阀 + 换向阀切换，或先导式溢流阀接远程调压阀
卸荷回路 执行元件停止时使泵低压运行、减少功率损耗与发热 压力卸荷：换向阀中位使 P 通 T（H/M/K 型）、或先导式溢流阀远程口接油箱；流量卸荷：变量泵排量调到近零

6.2 第二节 速度控制回路（一）：调速回路（简答题第 34 题）

（1）三类节流调速回路对比（核心考点）

前提：定量泵 + 溢流阀（常开、正常工作时就溢流）+ 节流阀，靠改变节流口面积调速，多余流量经溢流阀回油箱。

对比项 进油节流调速 回油节流调速 旁路节流调速
节流阀位置 泵与无杆腔之间 有杆腔与油箱之间 与执行元件并联（旁路回油箱）
速度负载特性 差（负载↑→速度↓） 较好（有背压，运动较平稳） 最差（负载↑→速度↑，特性”软”）
承载能力 一般 好（能承受负值负载） 差
效率与发热 低、发热大（有溢流损失+节流损失） 低、发热大 较高、发热较小（正常时溢流阀关闭，无溢流损失）
低速稳定性 一般 好（背压大） 差
典型应用 轻载、低速、要求不高 要求运动平稳、有负值负载 功率较大、速度较高、要求不高

要点：三种节流调速都有节流损失，效率都低于容积调速。旁路节流效率最高（因为正常工作时溢流阀不溢流），但速度负载特性最差。

（2）容积调速回路（效率最高）

组合 特点
变量泵 + 定量马达（恒扭矩调速） 改变泵排量调速；无溢流损失、无节流损失，效率高、发热小，适合大功率系统；输出扭矩恒定、功率随转速变化
定量泵 + 变量马达（恒功率调速） 改变马达排量调速；输出功率恒定、扭矩随转速变化
变量泵 + 变量马达 调速范围大，但结构复杂

单选题第 18 题：效率最高的是 容积调速回路。
判断题第 28 题：”变量泵-定量马达容积调速回路既没有溢流损失也没有节流损失，效率高发热小，适合大功率” → 对。

（3）容积节流调速（联合调速）

变量泵 + 调速阀：泵的流量自动与调速阀所需流量匹配，无溢流损失、只有节流损失，效率介于两者之间。

6.3 第三节 速度控制回路（二）：快速运动与速度换接

（1）快速运动回路

方式 原理 特点
液压缸差动连接 两腔同时进油，靠面积差快速伸出 不增大泵流量即可提速，结构简单（单选第 20 题 / 判断第 30 题）

增速缸 靠面积差增速 用于大型压力机

（2）YT4543 型组合机床动力滑台（单选第 20 题 / 判断第 30 题）

工作循环：快进 → 一工进 → 二工进 → 死挡铁停留 → 快退 → 原位停止。

  • 快进采用液压缸差动连接（在不增大泵流量的前提下获得较高快进速度）；
  • 工进由调速阀控制（容积节流调速，速度稳定）；
  • 快退时两腔换接，靠差动或双泵实现。

该内容属于第七章典型系统，但以例题形式并入第六章”快速运动回路”考核，务必记住”快进 = 差动连接“。

6.4 第四节 方向控制回路（简答题第 35 题）

（1）换向回路

用换向阀改变执行元件运动方向；要求换向平稳、无冲击（可用电液换向阀、或加缓冲）。

（2）锁紧回路（简答题第 35 题核心）

两种方案对比：

方案 原理 锁紧精度
O 型/M 型中位机能 靠换向阀中位把缸两腔封闭 差：滑阀有间隙泄漏，长时间锁紧会缓慢漂移
两个液控单向阀（液压锁） 锥阀式单向阀线接触密封，几乎无泄漏 高：可达长时间精确锁紧

为什么液压锁精度远高于 O/M 型？

  1. 密封形式不同：换向阀是滑阀（间隙密封），必然有内泄漏；液控单向阀是锥阀（线接触、金属对金属），接近无泄漏；
  2. 液压锁把两腔的油直接封死在缸口，泄漏路径最短、容积最小；
  3. 即使换向阀有泄漏，也不影响缸两腔的封闭。

对换向阀中位机能的要求：

  • 必须使液控单向阀的控制口通油箱（否则控制油一直有压力，单向阀被顶开，锁不住）；
  • 因此中位应采用 H 型、Y 型（A、B 通 T）这类使两腔通油箱的机能；
  • 不能用 O 型、M 型——O/M 型把 A、B 封闭，控制口憋压，液压锁失效。

这是一道”反直觉”的题：单看”封闭”好像 O/M 型更严，但液压锁要求控制口卸压，所以反而要用 H/Y 型。

（3）制动回路

使执行元件快速平稳停止：用溢流阀（背压）、顺序阀或专用制动阀产生制动背压。

7.4 简答题：五个必背模板

模板 1：外啮合齿轮泵的困油现象

（1）形成原因
齿轮泵要连续供油，齿轮重合度必须大于 1，因此会出现两对轮齿同时啮合的瞬间。此时这两对齿之间形成一个既不与吸油腔相通、也不与压油腔相通的封闭容积（困油区）。

（2）主要危害
齿轮继续转动时，这个封闭容积先由大变小——油液无处可去、被强行压缩，压力急剧升高，使轴承承受很大的附加载荷，产生冲击、振动和噪声，并加剧油液发热；
随后封闭容积又由小变大——形成局部真空，油液中的空气析出、产生气穴与气蚀，腐蚀齿面和轴承。

（3）常用消除措施
在齿轮两侧的端盖或浮动轴套（侧板）上开卸荷槽：

  • 使封闭容积缩小时与压油腔相通（把油排出去）；
  • 使封闭容积增大时与吸油腔相通（把油补进来）；
  • 同时保证吸油腔与压油腔仍被隔开，不影响正常吸压油。

补充：卸荷槽有对称双槽、偏移槽等形式；内啮合齿轮泵因结构原因基本无困油。

模板 2：单杆活塞缸的差动连接

（1）什么是差动连接
把单杆活塞缸的无杆腔与有杆腔同时接通压力油，称为差动连接。由于无杆腔有效面积 $A_1$ 大于有杆腔有效面积 $A_2$，活塞所受合力仍指向有杆腔一侧，于是活塞向外伸出；同时有杆腔排出的油液与液压泵的供油汇合后一起进入无杆腔，形成”回油再利用“。

（2）计算公式
速度：$v = \dfrac{q}{A_1-A_2} = \dfrac{q}{A_杆}$
推力：$F = p(A_1-A_2) = p A_杆$

（3）工程特点

  1. 推力小：有效面积只剩活塞杆截面积，推力仅为无杆腔进油时的 $\dfrac{A_杆}{A_1}$；
  2. 速度快：同一流量下速度提高 $\dfrac{A_1}{A_杆}$ 倍，是三种连接方式中速度最快的；
  3. 最大价值：在不增大液压泵流量的前提下获得较高的快进速度，从而可用小流量泵满足”快进—工进”的变速要求，减小装机功率；
  4. 只能实现单方向的快速运动，反向不能差动；
  5. 常用于组合机床动力滑台的快进、各类机床的快进回路。

模板 3：溢流阀、减压阀、顺序阀的比较

见 5.3（5）三阀比较总表，答题时按”工作原理 / 常态阀口状态 / 控制压力来源 / 泄油方式”四项逐条写，再补一句主要用途即可拿满分。

关键得分点：

  • 溢流阀：进口压力控制、常态关闭、稳进口压力；
  • 减压阀：出口压力控制、常态开启、稳出口压力、必须外泄；
  • 顺序阀：进口压力控制、常态关闭、做开关用。

模板 4：三种节流调速回路的特点

见 6.2（1）三类节流调速回路对比表。答题按”速度负载特性 / 承载能力 / 效率与发热”三方面写：

  • 进油节流调速：速度负载特性差（负载增大则速度下降），承载能力一般，有溢流损失和节流损失、效率低、发热大；结构简单，用于轻载低速。
  • 回油节流调速：因有杆腔存在背压，运动平稳、速度负载特性较好，能承受负值负载，但效率同样低、发热大；用于要求平稳的场合。
  • 旁路节流调速：速度负载特性最差（负载增大速度反而增大），承载能力差，但正常工作时溢流阀关闭、无溢流损失，效率最高、发热最小；用于功率较大、速度较高、精度要求不高的场合。

模板 5：液压锁为什么比 O/M 型锁紧精度高 + 对中位机能的要求

（1）为什么精度高

  1. 密封原理不同：三位换向阀是滑阀结构、靠间隙密封，阀芯与阀孔之间必然存在间隙，压力油会缓慢泄漏，长时间锁紧时活塞杆会缓慢漂移；而液控单向阀是锥阀结构、靠锥面与阀座线接触密封，属于”金属对金属”的硬密封，几乎无泄漏。
  2. 封闭位置不同：液压锁把两个液控单向阀直接装在液压缸两腔的进出口处，把油液封死在缸口，封闭容积最小、泄漏路径最短；而 O/M 型是靠换向阀在中位封闭，离缸较远、封闭容积大。
  3. 可靠性：即使换向阀本身有内泄漏，也不影响液压锁对缸两腔的封闭。

（2）对换向阀中位机能的要求
必须使液控单向阀的控制油口与油箱相通（控制口卸压），否则控制油一直有压力，会把单向阀顶开、锁紧失效。
因此中位机能应选 H 型或 Y 型（A、B 两腔通油箱）；
不能选 O 型或 M 型——它们把 A、B 口封闭，控制口憋压，液压锁无法锁紧。

题型 A：连续性方程求流速

液压泵流量 $q = 25$ L/min，经内径 $d = 20$ mm 的管道输送到液压缸。求管内平均流速。

解：
$A = \dfrac{\pi d^2}{4} = \dfrac{\pi\times(0.02)^2}{4} = 3.142\times10^{-4}\ \text{m}^2$
$q = \dfrac{25\times10^{-3}}{60} = 4.167\times10^{-4}\ \text{m}^3/\text{s}$
$v = \dfrac{q}{A} = \dfrac{4.167\times10^{-4}}{3.142\times10^{-4}} \approx 1.33\ \text{m/s}$

题型 B：伯努利方程求流速/压力

水箱液面比出口高 $h = 2$ m，液面与出口均通大气，忽略损失。求出口流速。

解：取液面为 1-1、出口为 2-2，$p_1=p_2=p_a$，$v_1\approx0$，$z_1-z_2=h$：

$\rho g h = \dfrac{1}{2}\rho v_2^2 \Rightarrow v_2 = \sqrt{2gh} = \sqrt{2\times9.8\times2} \approx 6.26\ \text{m/s}$

题型 C：判断流态 + 计算沿程压力损失

上题管路长 $l = 2$ m，油液密度 $\rho = 900$ kg/m³、运动粘度 $\nu = 20$ mm²/s。判断流态并求沿程压力损失。

解：
$Re = \dfrac{vd}{\nu} = \dfrac{1.33\times0.02}{20\times10^{-6}} = 1330$
$Re = 1330 < 2320$ → 层流

层流：$\lambda = \dfrac{64}{Re} = \dfrac{64}{1330} = 0.0481$

$\Delta p_\lambda = \lambda\dfrac{l}{d}\cdot\dfrac{\rho v^2}{2} = 0.0481\times\dfrac{2}{0.02}\times\dfrac{900\times1.33^2}{2}$
$= 0.0481\times100\times796.0 \approx 3829\ \text{Pa} \approx 3.83\ \text{kPa}$

题型 D：孔口流量计算

薄壁孔口面积 $A = 0.1$ cm²，孔口前后压差 $\Delta p = 0.5$ MPa，油液 $\rho = 900$ kg/m³，$C_d = 0.62$。求通过孔口的流量。

$\approx 2.07\times10^{-4}\ \text{m}^3/\text{s} = 12.4\ \text{L/min}$

解：
理论流量：$q_t = Vn = 25\times1500 = 37500\ \text{mL/min} = 37.5\ \text{L/min}$
实际流量：$q = q_t\eta_v = 37.5\times0.9 = 33.75\ \text{L/min} = 5.625\times10^{-4}\ \text{m}^3/\text{s}$
输出功率：$P_o = pq = 10\times10^6\times5.625\times10^{-4} = 5625\ \text{W} = 5.625\ \text{kW}$
总效率：$\eta = \eta_v\eta_m = 0.9\times0.9 = 0.81$
输入功率：$P_i = \dfrac{P_o}{\eta} = \dfrac{5.625}{0.81} \approx 6.94\ \text{kW}$

题型 F：液压缸三种连接（差动是重点）

单杆活塞缸内径 $D = 100$ mm，活塞杆直径 $d = 70$ mm，供油压力 $p = 5$ MPa，流量 $q = 25$ L/min。分别求无杆腔进油、有杆腔进油、差动连接时的速度与推力。

解：
$A_1 = \dfrac{\pi D^2}{4} = \dfrac{\pi\times0.1^2}{4} = 7.854\times10^{-3}\ \text{m}^2$
$A_2 = \dfrac{\pi(D^2-d^2)}{4} = \dfrac{\pi(0.1^2-0.07^2)}{4} = 4.005\times10^{-3}\ \text{m}^2$
$A_杆 = A_1-A_2 = \dfrac{\pi d^2}{4} = \dfrac{\pi\times0.07^2}{4} = 3.849\times10^{-3}\ \text{m}^2$
$q = \dfrac{25\times10^{-3}}{60} = 4.167\times10^{-4}\ \text{m}^3/\text{s}$

连接方式 速度 推力
无杆腔进油 $v_1=\dfrac{4.167\times10^{-4}}{7.854\times10^{-3}}=0.053\ \text{m/s}=3.18\ \text{m/min}$ $F_1=5\times10^6\times7.854\times10^{-3}=39.3\ \text{kN}$
有杆腔进油 $v_2=\dfrac{4.167\times10^{-4}}{4.005\times10^{-3}}=0.104\ \text{m/s}=6.24\ \text{m/min}$ $F_2=5\times10^6\times4.005\times10^{-3}=20.0\ \text{kN}$
差动连接 $v_3=\dfrac{4.167\times10^{-4}}{3.849\times10^{-3}}=0.108\ \text{m/s}=6.50\ \text{m/min}$ $F_3=5\times10^6\times3.849\times10^{-3}=19.2\ \text{kN}$

结论印证：差动连接速度最高、推力最小（$v_3>v_2>v_1$，$F_3<F_2<F_1$）。

题型 G：液压马达

液压马达排量 $V = 40$ mL/r，输入流量 $q = 30$ L/min，容积效率 $\eta_v = 0.95$，机械效率 $\eta_m = 0.9$，进出口压差 $\Delta p = 10$ MPa。求转速与输出转矩。

解：
$n = \dfrac{q\eta_v}{V} = \dfrac{30\times10^{-3}\times0.95}{40\times10^{-6}} = \dfrac{2.85\times10^{-2}}{4\times10^{-5}} = 712.5\ \text{r/min}$
$T = \dfrac{\Delta p V\eta_m}{2\pi} = \dfrac{10\times10^6\times40\times10^{-6}\times0.9}{2\pi} = \dfrac{360}{6.283} \approx 57.3\ \text{N}\cdot\text{m}$

题型 H：进油节流调速回路求速度

定量泵流量 $q_p = 25$ L/min，溢流阀调定压力 $p_s = 3$ MPa。节流阀为薄壁孔口，$A = 0.02$ cm²，$C_d = 0.62$，$\rho = 900$ kg/m³。液压缸无杆腔面积 $A_1 = 50$ cm²，负载 $F = 10$ kN。求活塞速度与溢流阀溢流量。

解：
缸工作压力：$p_1 = \dfrac{F}{A_1} = \dfrac{10\times10^3}{50\times10^{-4}} = 2\times10^6\ \text{Pa} = 2\ \text{MPa}$
节流阀压差：$\Delta p = p_s - p_1 = 3-2 = 1\ \text{MPa}$
通过节流阀流量：
$q_1 = 0.62\times(0.02\times10^{-4})\times\sqrt{\dfrac{2\times10^6}{900}} = 0.62\times2\times10^{-6}\times47.14 \approx 5.85\times10^{-5}\ \text{m}^3/\text{s}$
$= 3.51\ \text{L/min}$
活塞速度：$v = \dfrac{q_1}{A_1} = \dfrac{5.85\times10^{-5}}{50\times10^{-4}} = 0.0117\ \text{m/s} = 0.70\ \text{m/min}$
溢流量：$q_y = q_p - q_1 = 25 - 3.51 = 21.49\ \text{L/min}$

这一步揭示了进油节流调速效率低的根源：泵输出的 25 L/min 里只有 3.51 L/min 做了有用功，86% 的流量经溢流阀白白流回油箱并转化为热量。

五、计算题

（1）管内流速与流态

$A = \dfrac{\pi d^2}{4} = \dfrac{\pi\times0.02^2}{4} = 3.142\times10^{-4}\ \text{m}^2$
$q = \dfrac{25\times10^{-3}}{60} = 4.167\times10^{-4}\ \text{m}^3/\text{s}$
$v = \dfrac{q}{A} = \dfrac{4.167\times10^{-4}}{3.142\times10^{-4}} \approx 1.33\ \text{m/s}$
$Re = \dfrac{vd}{\nu} = \dfrac{1.33\times0.02}{20\times10^{-6}} \approx 1330 < 2320$ → 层流

（2）沿程压力损失

层流 $\lambda = \dfrac{64}{Re} = \dfrac{64}{1330} \approx 0.0481$
$\Delta p_\lambda = \lambda\dfrac{l}{d}\cdot\dfrac{\rho v^2}{2} = 0.0481\times\dfrac{2}{0.02}\times\dfrac{900\times1.33^2}{2} \approx 3.83\ \text{kPa}$

（3）无杆腔进油

$A_1 = \dfrac{\pi\times0.1^2}{4} = 7.854\times10^{-3}\ \text{m}^2$
$v_1 = \dfrac{q}{A_1} = \dfrac{4.167\times10^{-4}}{7.854\times10^{-3}} \approx 0.053\ \text{m/s} = 3.18\ \text{m/min}$
$F_1 = pA_1 = 5\times10^6\times7.854\times10^{-3} \approx 39.3\ \text{kN}$

（4）差动连接

$A_杆 = \dfrac{\pi d^2}{4} = \dfrac{\pi\times0.07^2}{4} = 3.849\times10^{-3}\ \text{m}^2$
$v_3 = \dfrac{q}{A_杆} = \dfrac{4.167\times10^{-4}}{3.849\times10^{-3}} \approx 0.108\ \text{m/s} = 6.50\ \text{m/min}$
$F_3 = pA_杆 = 5\times10^6\times3.849\times10^{-3} \approx 19.2\ \text{kN}$

变化规律：差动连接的速度是无杆腔进油的 $\dfrac{A_1}{A_杆}=\dfrac{7.854}{3.849}\approx2.04$ 倍（速度提高约 1 倍）；推力是无杆腔进油的 $\dfrac{A_杆}{A_1}\approx0.49$ 倍（推力减小约一半）。即**”速度高、推力小”**，这正是差动连接能在不增大泵流量前提下实现快进的原因。
