S7-1200 硬件结构、循环扫描与启保停控制

S7-1200 PLC硬件结构与启保停控制实训笔记：CPU模块与DC/DC/DC选型、循环扫描五阶段、博途设备组态（通信左信号右），及电动机启停自锁梯形图（含考点）

本文整理《S7-1200 PLC 硬件结构与启保停控制实训（PLC 硬件结构与编程基础）》一课，是从继电接触控制进入 PLC 实训的第一课。内容分四部分：第一部分讲 PLC 的硬件结构与外部接口——数字量/模拟量 I/O 单元（A/D、D/A 转换，010V、420mA 标准信号）、I/O 扩展接口与通信接口、特殊功能模块、系统总线与人机界面/远程 I/O/变频器通信（PROFINET、CM 1241、Modbus/USS）；第二部分讲 PLC 的循环扫描工作原理——RUN/STOP 两种模式、扫描周期、内部处理（看门狗）/通信服务/输入采样/程序执行/输出刷新五个阶段、输入映像寄存器与输出锁存器、系统响应滞后与窄脉冲丢失；第三部分讲西门子 S7-1200 硬件——CPU 面板与型号（1211C/1212C/1214C/1215C/1217C）、DC/DC/DC 与 AC/DC/继电器命名含义、高速计数/PWM/PTO/运动控制/PID 等集成工艺功能、信号模块 SM/信号板 SB/通信模块 CM/电源模块 PM 及”通信模块在 CPU 左侧、信号模块在右侧“的组态规则；第四部分是实训核心——用 TIA Portal（博途）完成一台电动机的启动-保持-停止（启保停/自锁）梯形图：I/O 分配（启动 SB2→I0.0、停止 SB1→I0.1、输出 Q0.0）、自锁触点原理、下载与监控仿真，以及晶体管输出带交流负载时用中间继电器做交直流转换和强弱电隔离。文末附例题、术语地址表、待核对清单和主动回忆题（含答案要点）。

一、核心结论

  • PLC 硬件由输入部分、CPU（运算器＋存储器）、输出部分（继电器/晶体管/晶闸管）和电源组成，外部通过 I/O 端子和通信接口连接现场设备。
  • 模拟量输入单元核心是 A/D（模数转换）：把现场连续变化的模拟信号（标准为 010V 电压、420mA 电流）经滤波、采样转换成 CPU 能处理的数字量；模拟量输出单元核心是 D/A（数模转换）：把 CPU 的数字量还原成模拟量去控制执行机构。
  • 主机 I/O 点数不足时通过 I/O 扩展接口接扩展单元；特殊功能单元包括模拟量 I/O 模块、通信模块、高速计数模块、运动控制模块；各模块经系统总线与人机界面（触摸屏）、其他 PLC 主从站、远程 I/O、变频器交换数据；PROFINET 是基于工业以太网的开放式现场总线，CM 1241（RS232/RS485）支持 Modbus、USS 等。
  • PLC 采用循环扫描、不断循环顺序执行的串行工作方式，有 RUN（运行）和 STOP（停止）两种模式；完成一次循环的时间称扫描周期，其长短取决于用户程序长短、指令种类和 CPU 执行速度。
  • 一个扫描周期分五个阶段：①内部处理（自检硬件/I/O/程序语法，复位看门狗）；②通信服务（与编程器、主从站、人机界面交换信息）；③输入采样（集中读入全部输入并刷新输入映像寄存器）；④程序执行（按顺序执行用户程序，结果送元件/输出映像寄存器）；⑤输出刷新（把结果送输出锁存器，经继电器/晶体管/晶闸管驱动负载；下次刷新前锁存器状态不变）。
  • 因串行扫描，PLC 对输入存在系统响应滞后（系统响应时间）；当输入窄脉冲宽度小于扫描周期时可能丢失（捕捉不到）；看门狗（监控定时器 WDT）设定时间略大于扫描周期，程序跑飞、扫描超时时报警/复位。
  • S7-1200 是西门子小型模块化 PLC，可装标准导轨，由 CPU 模块、信号模块 SM、信号板 SB、通信模块 CM、电源模块 PM 组成；CPU 集成微处理器、电源、数字量/模拟量 I/O 电路、以太网口和高速运动控制接口，面板有运行/故障指示灯（绿运行、红故障）、可拆卸端子排和存储卡插口。
  • CPU 型号 1211C/1212C/1214C/1215C/1217C 物理尺寸和 I/O 点数依次增大（具体点数以手册为准）；CPU 最多可组态多个高速计数器（课堂讲最多 6 个，1217C 有高达 1MHz 的高速计数，普通高速输入频率约 100kHz 量级，待核对）。
  • 电源/输入/输出类型用三段表示：DC/DC/DC＝直流 24V 供电、直流输入、晶体管直流输出；AC/DC/继电器（RLY）＝交流供电、直流输入、继电器触点输出（可带交、直流负载）。
  • 集成工艺功能：高速计数、频率测量、高速脉冲输出 PWM（脉宽调制）/PTO（脉冲串）、运动控制（经工艺对象和 PLCopen 指令控制步进/伺服的速度与位置）、PID（比例-积分-微分）闭环控制。
  • 博途设备组态有强制物理规则：通信模块 CM 必须装在 CPU 左侧，信号模块 SM 必须装在 CPU 右侧，信号板 SB 装 CPU 正面槽位；拖错位置软件不允许。
  • TIA Portal（博途，课堂 V16，至少约 32GB 硬盘空间）开发流程：新建项目→添加新设备（选 S7-1200 CPU，如 1215C DC/DC/DC）→设备组态→建变量表（命名＋地址）→用梯形图 LAD 编程→编译→经以太网下载到 CPU→用监控表/PLCSIM 仿真调试。
  • 启保停（自锁）控制：按下启动按钮 SB2（I0.0 常开）电机连续运行，松手不停（靠 Q0.0 常开自锁触点与启动触点并联”保持”）；按下停止按钮 SB1（I0.1 常闭）电机停止。梯形图为”启动常开 I0.0 与自锁常开 Q0.0 并联 → 串停止常闭 I0.1 → 输出线圈 Q0.0”。
  • DC/DC/DC 晶体管输出只能带直流低压负载，若接触器 KM 线圈是交流（如 AC220V），须先用 Q0.0 驱动直流中间继电器 KA，再用 KA 触点控制交流接触器，实现交直流转换和强弱电隔离。
  • 相比纯继电器硬件接线，PLC 在控制点多、逻辑复杂时占地小、可整区集中控制、改逻辑只需改程序而不必重新接线。

三、详细笔记

3.1 PLC 的硬件基本组成

  • 小型 PLC 内部主要由四部分组成：输入单元（输入端子与输入电路）、CPU（中央处理器，含运算器和存储器）、输出单元（继电器/晶体管/晶闸管输出电路与输出端子）和电源。
  • 现场的按钮、行程开关、传感器接到输入端子；接触器线圈、指示灯、电磁阀等执行元件接到输出端子；CPU 按用户程序对输入信号运算后控制输出。
  • I/O 点数（输入/输出端子数量）是 PLC 的重要规格，点数不够时靠扩展模块增加。

3.2 数字量与模拟量输入输出单元

  • 数字量（开关量）I/O：处理只有通/断（1/0）两种状态的信号，如按钮、限位开关、指示灯、接触器线圈。
  • 模拟量输入单元（AI）：
    • 现场温度、压力、流量、转速等是连续变化的模拟量，变送器把它们变换成标准的电信号，常用 010V 直流电压或 420mA 直流电流；
    • 模拟量输入单元对信号滤波后进行 A/D 转换（模数转换），把连续模拟量量化成若干位二进制数字量送入 CPU。
  • 模拟量输出单元（AO）：把 CPU 运算得到的数字量经 D/A 转换（数模转换）还原成 010V/420mA 等模拟信号，去调节变频器、调节阀等执行机构。

3.3 外部接口、扩展单元与通信

  • I/O 扩展接口：当主机 I/O 点数不足时，通过它连接 I/O 扩展单元。
  • 特殊功能单元（模块）：为增强 PLC 功能而开发，包括模拟量 I/O 模块、通信模块、高速计数模块、运动控制模块等。
  • 通信接口与系统总线：各模块通过系统总线和通信口连接，实现 PLC 与编程器（电脑）、人机界面 HMI（触摸屏）、其他 PLC 主/从站、远程 I/O、变频器等设备之间的数据交换。
  • 常见通信方式（了解）：
    • PROFINET：基于工业以太网的开放式现场总线，是现场总线发展趋势，可一直延伸到最底层现场设备；S7-1200 CPU 自带以太网口支持；
    • CM 1241 通信模块：提供 RS232/RS485 接口，可使 S7-1200 作为 Modbus 主站或从站，并支持 USS 协议与变频器通信；
    • 另有 GPRS 远程通信模块（如 CP 1242/1243 系列）可实现远距离监视与控制。

3.4 PLC 的循环扫描工作方式与运行模式

  • PLC 有两种基本运行模式：RUN（运行）和 STOP（停止）。在 RUN 模式下，CPU 周而复始地按固定顺序执行，称为循环扫描。
  • 扫描周期：完成一次完整扫描（循环）所需要的时间；它与用户程序长短、指令种类（简单/复杂指令）以及 CPU 执行指令的速度有关。优化程序、精简指令可缩短扫描周期。
  • 循环扫描是 PLC 区别于继电器控制的根本特征，本质是一种串行工作方式（继电器电路是并行、同时动作）。

3.5 扫描过程的五个阶段

  1. 内部处理阶段：CPU 自检，检查自身功能是否正常、I/O 连接是否正常、用户程序是否有语法错误；同时定期复位监控定时器（看门狗 WDT）。看门狗的设定时间略大于正常扫描周期，若程序陷入死循环或跑飞、扫描时间超限，看门狗得不到及时复位就会报警并引起系统复位，保证安全。
  2. 通信服务阶段：完成与编程器、PLC 主从站、操作站、人机交互界面等设备的通信和信息交换。
  3. 输入处理（输入采样）阶段：CPU 把所有外部输入电路的接通/断开状态集中采样一次，并存入相应的输入映像寄存器，该阶段内输入映像寄存器被刷新；在本次扫描的其余时间里，即使外部输入变化，输入映像寄存器内容也保持到下一扫描周期才更新。
  4. 程序执行阶段：CPU 按用户程序从上到下、从左到右的顺序，从输入映像寄存器（和其他元件映像寄存器）读取状态进行逻辑运算，结果写入输出映像寄存器（元件映像寄存器）。
  5. 输出处理（输出刷新）阶段：CPU 把输出映像寄存器（输出锁存器）的状态集中送到输出接口，经继电器、晶体管或晶闸管驱动外部负载；在下一个输出刷新阶段到来之前，输出锁存器的状态保持不变。

3.6 系统响应滞后与窄脉冲丢失

  • 由于串行循环扫描，从输入信号发生变化的时刻，到 PLC 输出改变、外部负载状态相应改变，需要经过一段时间，称为系统响应时间（系统响应滞后）。
  • 窄脉冲丢失：PLC 只在每个扫描周期的输入采样阶段读输入，若某输入信号是一个很窄的脉冲、其脉冲宽度小于扫描周期，就可能恰好在采样时刻之外出现而不被检测到，造成信号丢失；要求可靠捕捉的输入脉冲宽度应大于扫描周期（或使用高速计数器/中断输入）。
  • 串行扫描还与数字电路中的”竞争与冒险”概念相关：信号在时间上的先后会影响结果，分析时序时要注意这种滞后。

3.7 S7-1200 硬件组成与 CPU 面板

  • S7-1200 是西门子紧凑型小型 PLC，采用模块化结构，可方便地安装在标准导轨上，主要包括 CPU 模块、信号模块 SM、信号板 SB、通信模块 CM、电源模块 PM。
  • CPU 模块把微处理器、集成电源、数字量/模拟量输入输出电路、以太网接口、高速运动控制接口等紧凑集成在一台主机上。
  • CPU 面板上一般有：可拆卸的接线端子排、I/O 状态指示灯、CPU 运行状态指示灯（绿色表示运行正常、红色表示故障）、存储卡插口、以太网（网线）接口等。

3.8 CPU 型号与 I/O 点数

  • 常见型号有 CPU 1211C、1212C、1214C、1215C、1217C 等，型号数字越大，物理尺寸越大、本机集成的数字量输入/输出点数越多、可扩展能力越强（如课堂展示的 1212C 点数较少、1214C/1215C 点数更多）。各型号具体的”几入几出”以教材/选型手册为准（待核对）。

3.9 电源配置与 DC/DC/DC、AC/DC/继电器命名

  • S7-1200 CPU 型号后缀用三段表示”电源电压 / 输入类型 / 输出类型“：
    • DC/DC/DC：第一段 DC 表示 CPU 用直流 24V 供电；第二段 DC 表示数字量输入为直流（接直流 24V 开关信号）；第三段 DC 表示输出为晶体管直流输出（只能带直流负载、动作快、适合高速脉冲）。
    • AC/DC/继电器（RLY）：第一段 AC 表示 CPU 用交流电源供电；第二段 DC 表示直流输入；第三段”继电器”表示输出为继电器触点输出（触点可接通直流或交流负载、容量较大，但动作速度慢、有机械寿命）。
  • 选型时要根据现场电源、输入信号和负载（直流/交流、容量）综合选择。

3.10 S7-1200 的集成工艺功能

  • 高速计数与频率测量：CPU 可组态多个高速计数器（课堂讲最多 6 个，可使用 CPU 内置输入或信号板输入；1217C 有高达 1MHz 的高速计数通道，普通高速输入频率在 100kHz 量级，具体数值待核对），用于接编码器等脉冲信号并测频。
  • 高速脉冲输出：PWM（脉宽调制）输出周期固定、占空比可调的脉冲，经滤波可得到近似模拟量；PTO（脉冲串输出）输出一定数量和频率的脉冲。
  • 运动控制：高速脉冲输出配合”工艺对象”和 PLCopen 运动控制指令，对步进电机或伺服电机进行速度和位置控制。
  • PID 控制：CPU 内置比例-积分-微分闭环控制功能，用于温度、压力、速度等连续量的闭环调节。

3.11 信号模块、信号板、通信模块与电源模块

  • 信号模块 SM：装在 CPU 右侧，提供数字量 I/O、模拟量 I/O 等扩展点数；模块上有状态指示灯，绿色为运行、红色为故障。
  • 信号板 SB：装在 CPU 正面（顶部）的小槽内，只增加少量 I/O/通信能力，不额外占用右侧空间、不增大整机宽度。
  • 通信模块 CM：装在 CPU 左侧（如 CM 1241 的 RS232/RS485、PROFINET 等）。
  • 电源模块 PM：把市电变换为直流 24V，为 CPU、信号板/信号模块、通信模块以及现场传感器供电；当扩展模块所需功率超出 CPU 本体供电能力时，需外加电源模块。
  • 设备组态强制规则（考点）：在博途中组态机架时，所有通信模块必须配置在 CPU 左侧，所有信号模块必须配置在 CPU 右侧；把模块拖到错误一侧软件不接受，这与实际安装位置一一对应。

3.12 TIA Portal（博途）软件与项目开发流程

  • 编程软件为 TIA Portal（博途），课堂用 V16 版本（市面 V18/V19 亦可），软件较大，安装至少需要约 32GB 硬盘空间，建议在实验室或配置较高的电脑上安装。
  • 界面有 Portal 视图（入口向导）和项目视图（工程组态），包含菜单栏、工作区、任务卡、巡视（详细信息）窗口等。
  • 基本开发流程：
    1. 创建新项目、打开项目视图；
    2. “添加新设备”→控制器→选 SIMATIC S7-1200→选具体 CPU 型号和版本（教材用 CPU 1215C DC/DC/DC，订货号/固件版本以教材为准）；
    3. 添加后自动生成机架（导轨），进行设备组态：左侧拖通信模块、右侧拖信号模块；
    4. 在变量表（PLC 变量）中为每个 I/O 命名并指定地址（如启动按钮 I0.0）；
    5. 用梯形图 LAD（触点、线圈等图形符号）编写主程序 OB1；
    6. 编译，检查无错误（警告酌情处理）；
    7. 计算机经网线与 CPU 以太网口连接，选择通信接口、搜索（在线访问）到设备后下载程序；
    8. 用监控表强制/修改变量值（0/1）或用 PLCSIM 仿真器、Factory IO 等进行离线/三维仿真调试；还可组态触摸屏 HMI。

3.13 实训：电动机启保停（启动-保持-停止）控制

  • 控制要求：用 S7-1200（教材用 CPU 1214C/1215C DC/DC/DC）控制一台电动机——按下启动按钮 SB2，电动机启动并连续运行（松开 SB2 仍运行）；按下停止按钮 SB1，电动机停止。
  • I/O 分配表：
元件 功能 PLC 地址 程序中触点
启动按钮 SB2（常开） 启动 输入 I0.0 常开触点
停止按钮 SB1（常闭/演示常开） 停止 输入 I0.1 常闭触点
接触器/中间继电器线圈 K（KM/KA） 控制电机 输出 Q0.0 输出线圈
  • 梯形图（启保停/自锁电路）：从左母线出发，把启动按钮常开触点 I0.0 与 输出 Q0.0 的常开辅助触点并联，再串联停止按钮常闭触点 I0.1，最后接输出线圈 Q0.0 到右母线。用文字表达逻辑关系：

$$Q0.0=(I0.0+Q0.0)\cdot\overline{I0.1}$$

  • 工作过程（启—保—停）：
    • 启动：按下 SB2，I0.0 常开触点闭合，能流经停止常闭触点 I0.1 使输出线圈 Q0.0 得电，电机启动；
    • 保持（自锁/自保）：Q0.0 得电的同时，与其并联的 Q0.0 常开触点闭合；松开 SB2 后 I0.0 断开，但能流改经已闭合的 Q0.0 触点继续给线圈供电，把输出状态”记忆/保持”下来，电机连续运行；
    • 停止：按下 SB1，串联在回路中的 I0.1 常闭触点断开，线圈 Q0.0 失电，其常开自锁触点也随之断开，即使松开停止按钮也不会自行再启动，电机停止。
  • 该梯形图与前面继电接触控制中的”启动常开按钮并联接触器自锁常开触点、再串停止常闭按钮、接接触器线圈”完全对应，只是把硬件接线逻辑改用 PLC 程序实现，二者思路相通。
  • 监控仿真：在监控表中把 I0.0 修改为 1（相当于按住启动），Q0.0 变为 1 并自锁保持；再把 I0.0 改回 0（松手）Q0.0 仍为 1；把停止 I0.1 修改为 1 使其常闭断开，Q0.0 变为 0。注意变量必须先在变量表中正确定义，监控时才能修改。

3.14 输出类型不匹配与中间继电器隔离

  • DC/DC/DC 型 CPU 的输出是晶体管直流输出（直流 24V 等级），若现场接触器 KM 线圈是交流负载（如 AC220V，具体电压以图纸为准），PLC 输出不能直接驱动。
  • 做法：用 PLC 的 Q0.0 先驱动一个直流中间继电器 KA 的线圈，再用 KA 的触点去接通交流接触器 KM 的线圈和交流主回路。
  • 作用：①实现交直流转换（过渡）；②实现强电与弱电的隔离，保护 PLC 输出点，类似手机充电器把交流变换成直流给手机供电。

3.15 PLC 控制相对继电器控制的优势

  • 当工业现场要控制几十、几百甚至上千台设备、逻辑较复杂时，PLC 相比传统继电器柜占用空间小、可整区集中控制、可靠性高；
  • 最关键的是改变控制逻辑只需修改程序、重新下载，不必像继电器电路那样重新接线、改动硬件，调试和改造方便。

四、例题与案例分析

4.1 扫描阶段排序题

  • 给出”输出刷新、输入采样、内部处理、程序执行、通信服务”，要求按一个扫描周期排序：内部处理→通信服务→输入采样→程序执行→输出刷新。

4.2 窄脉冲与看门狗判断

  • 某输入脉冲宽度为 2ms，而 PLC 扫描周期为 10ms，该脉冲可能在两次输入采样之间出现并消失，PLC 捕捉不到（信号丢失），应缩短扫描周期或改用高速计数/中断输入；若用户程序死循环使扫描时间超过看门狗设定值，看门狗不能被复位，将报警并使系统复位。

4.3 模块安装位置判断

  • 在博途中为 S7-1200 组态：CM 1241 通信模块只能拖到 CPU 左侧，数字量/模拟量信号模块 SM 只能拖到右侧，信号板 SB 装 CPU 正面；拖错位置系统不接受。

4.4 CPU 型号后缀含义

  • CPU 1214C DC/DC/DC：直流 24V 供电、直流输入、晶体管直流输出；CPU 1214C AC/DC/RLY：交流供电、直流输入、继电器触点输出，可直接带交流负载。

4.5 启保停梯形图分析

  • 见 3.13：指出启动触点 I0.0、自锁触点 Q0.0、停止常闭 I0.1 和输出线圈 Q0.0；说明为什么松开启动按钮电机仍运行（自锁触点闭合自供电）、按下停止为何能停机且不能自行重启（线圈失电后自锁触点断开）。

4.6 晶体管输出带交流负载

  • DC/DC/DC 型 PLC 控制 AC220V 接触器：Q0.0→直流中间继电器 KA 线圈，KA 常开触点→交流接触器 KM 线圈回路，完成交直流转换与强弱电隔离。

主动回忆题

  1. PLC 硬件由哪几部分组成？模拟量输入单元和输出单元各完成什么转换？标准模拟信号有哪些？
  2. 主机 I/O 点数不够怎么办？特殊功能模块有哪些？PLC 通过什么与触摸屏、变频器、其他 PLC 通信？
  3. PLC 有哪两种运行模式？什么是扫描周期？它与哪些因素有关？
  4. 按顺序写出 PLC 一个扫描周期的五个阶段，并说明输入映像寄存器和输出锁存器在其中的作用。
  5. 什么是系统响应滞后？为什么宽度小于扫描周期的窄脉冲可能丢失？看门狗起什么作用？
  6. S7-1200 的 DC/DC/DC 和 AC/DC/继电器分别表示什么？晶体管输出和继电器输出各适合什么负载？
  7. S7-1200 有哪些集成工艺功能？信号模块、信号板、通信模块、电源模块的代号和安装位置规则是什么？
  8. 简述用博途完成一个 PLC 控制项目的主要步骤。
  9. 写出电动机启保停控制的 I/O 分配和梯形图逻辑表达式，说明”启动—保持—停止”分别由哪些触点实现、为什么松手不停。
  10. DC/DC/DC 的 PLC 要控制一个交流 220V 接触器，为什么不能直接接？应怎样用中间继电器解决？

答案要点

  1. PLC 由输入单元、CPU（运算器＋存储器）、输出单元（继电器/晶体管/晶闸管）和电源组成。模拟量输入单元完成 A/D（模数）转换，把 010V、420mA 等连续模拟量经滤波、采样变成数字量送 CPU；模拟量输出单元完成 D/A（数模）转换，把数字量还原成模拟量控制执行机构。数字量 I/O 只处理通/断（1/0）信号。
  2. I/O 点数不足时通过 I/O 扩展接口连接扩展单元（信号模块）；特殊功能模块包括模拟量 I/O 模块、通信模块、高速计数模块、运动控制模块等；PLC 经系统总线和通信接口（PROFINET 工业以太网、CM1241 的 RS232/RS485、Modbus/USS 等）与触摸屏 HMI、其他 PLC 主从站、远程 I/O、变频器交换数据。
  3. 有 RUN（运行）和 STOP（停止）两种模式。扫描周期是 CPU 完成一次完整循环扫描所需的时间，其长短取决于用户程序长短、指令种类和 CPU 执行指令的速度；程序越简洁、CPU 越快，扫描周期越短。
  4. 五阶段依次为：①内部处理（自检硬件、I/O、程序语法并复位看门狗）；②通信服务（与编程器、主从站、人机界面交换信息）；③输入采样（集中读入全部输入并刷新输入映像寄存器）；④程序执行（按顺序运算、结果写入输出/元件映像寄存器）；⑤输出刷新（把结果送输出锁存器并经输出接口驱动负载，下次刷新前锁存器保持不变）。输入映像寄存器保证一个扫描周期内输入状态一致，输出锁存器使输出在周期内保持稳定。
  5. 系统响应滞后是从输入信号变化到输出负载状态改变所经历的时间，由串行扫描造成。PLC 只在每周期输入采样阶段读输入，若窄脉冲宽度小于扫描周期、又恰好落在两次采样之间，就检测不到而丢失（应缩短扫描周期或用高速计数/中断）。看门狗（监控定时器）设定时间略大于正常扫描周期，程序死循环/跑飞使扫描超时时，看门狗得不到复位就报警并复位系统。
  6. 三段依次表示电源电压/输入类型/输出类型。DC/DC/DC 表示直流 24V 供电、直流输入、晶体管直流输出，只能带直流负载、动作快、适合高速脉冲；AC/DC/RLY（继电器）表示交流供电、直流输入、继电器触点输出，触点可带交流或直流负载、容量大，但动作慢、有机械寿命。
  7. 集成工艺功能有高速计数、频率测量、高速脉冲输出 PWM/PTO、运动控制（控制步进/伺服速度位置）、PID 闭环控制。SM 信号模块装 CPU 右侧（扩展数字量/模拟量 I/O），SB 信号板装 CPU 正面小槽（少量扩展、不增宽），CM 通信模块装 CPU 左侧，PM 电源模块提供直流 24V 供电；组态时通信模块必须在左、信号模块必须在右，拖错软件不接受。
  8. 博途开发步骤：新建项目并进入项目视图→添加新设备（选 S7-1200 及 CPU 型号版本）→设备组态（左通信、右信号）→在变量表命名并分配 I/O 地址→用梯形图 LAD 编写程序→编译查错→经以太网搜索并下载到 CPU→用监控表修改变量或 PLCSIM/Factory IO 仿真调试，必要时组态 HMI。
  9. I/O 分配：启动按钮 SB2（常开）→I0.0，停止按钮 SB1（常闭）→I0.1，控制电机的接触器/中间继电器线圈→Q0.0。梯形图逻辑为 $Q0.0=(I0.0+Q0.0)\cdot\overline{I0.1}$：启动常开 I0.0 与输出常开 Q0.0 并联后串停止常闭 I0.1，再接 Q0.0 线圈。按下 SB2，I0.0 闭合使 Q0.0 得电（启动）；Q0.0 常开触点随之闭合，松手后 I0.0 断开但能流经 Q0.0 自锁触点继续供电（保持）；按下 SB1，I0.1 常闭断开，Q0.0 失电且自锁触点断开（停止），不会自行重启。
  10. DC/DC/DC 是晶体管直流输出，只能接直流低压负载，不能直接接通 AC220V 交流接触器线圈，否则不匹配且不安全。应让 Q0.0 先驱动一个直流中间继电器 KA 的线圈，再用 KA 的常开触点去接通交流接触器 KM 的线圈和交流主回路；这样既完成交直流转换，又实现强电与弱电（PLC 与交流主回路）的隔离，保护 PLC 输出点。
