滚动轴承选型与寿命计算、轮系与蜗杆传动

《机械设计基础》课堂笔记：轮系 · 滚动轴承（类型 / 代号 / 选型 / 寿命）· 蜗杆蜗轮传动

一、这节课讲了什么

一次课讲了三块内容，滚动轴承是绝对主体（约占 60 分钟）：

模块 时长占比 内容
轮系（收尾复习） 约 10 分钟 定轴 / 周转 / 复合轮系的判别与传动比
滚动轴承 约 60 分钟 功用与结构 → 调心与偏位角 → 极限转速 → 分类 → 代号 → 常用类型 → 选型 → 受力 → 寿命
蜗杆蜗轮传动（引入） 约 15 分钟 蜗杆蜗轮区分、参数、传动比

二、核心结论速览

  1. 轮系按轴的位置是否固定分为定轴轮系与周转轮系，两者叠加即为复合轮系。
  2. 平面轮系传动比的方向用符号表达；空间轮系（轴不平行）必须用箭头表达。
  3. 传动比中的符号项为 $(-1)^m$，$m$ 是外啮合齿轮的对数。
  4. 周转轮系含行星架 $H$，用转化机构法（反转法）求解，公式中出现 $n_H$ 时要扣除。
  5. 复合轮系先分别判定「哪些是定轴、哪些是周转」，各自列式后再联立。
  6. 轴承的功用：把转动的轴与固定的机架连接起来，减少摩擦。
  7. 滚动轴承四大件：内圈、外圈、滚动体、保持架；内圈随轴转动，外圈固定不动。
  8. 调心＝轴承具备自动调心功能；理论轴线与实际轴线的夹角叫偏位角。
  9. 极限转速：在保证一定润滑条件下轴承能承受的最高工作转速；轴的工作转速必须小于它。
  10. 按承载方向分为向心轴承（径向）与推力轴承（轴向）。
  11. 接触角越大，承受轴向力的能力越大。
  12. 按滚动体形状分为球轴承（点接触）与滚子轴承（线接触）。
  13. 滚子轴承的承载能力约为球轴承的 1.5～3 倍，但极限转速更低。
  14. 轴承基本代号（5 位）＝类型代号 ＋ 尺寸系列（宽度系列＋直径系列）＋ 内径代号。
  15. 内径 10 / 12 / 15 / 17 mm 对应代号 00 / 01 / 02 / 03；内径 20～500 mm 时，内径代号 ＝ 内径 ÷ 5。
  16. 公差等级由低到高：P0 < P6 < P5 < P4 < P2（P0 为普通级，代号中省略）。
  17. 3 类（圆锥滚子）和 7 类（角接触球）轴承必须成对使用，正装或反装。
  18. 选型三步：先看载荷方向 → 再看载荷大小 → 最后看转速。
  19. 纯径向载荷选深沟球（或圆柱滚子）；纯轴向选推力；径向＋轴向选角接触球或圆锥滚子。
  20. 转速高选球轴承，转速低选滚子轴承；推力轴承极限转速最低，不宜用于高速。
  21. 基本额定寿命 $L_{10}$：一批相同轴承在相同条件下运转，10% 出现失效时的寿命（转数或小时）。
  22. 寿命计算：$L_{10}=(C/P)^{\varepsilon}$（单位 $10^6$ 转），球轴承 $\varepsilon=3$，滚子轴承 $\varepsilon=10/3$。
  23. 蜗杆头数 $z_1$ 常用 1、2、4、6；蜗轮齿数 $z_2$ 一般取 28～80。
  24. 蜗杆传动比 $i=z_2/z_1$，蜗杆为主动件。

三、知识结构树

四、知识点详解

4.1 轮系

分类

类型 判别依据
定轴轮系 各齿轮的轴的位置固定
周转轮系 至少有一个齿轮的轴线绕另一轴线回转（含行星架 $H$）
复合轮系 定轴轮系与周转轮系的叠加

传动比

从首轴（输入轴）到末轴（输出轴）：

  • 平面轮系（各轴平行）：用符号表达方向

$$i_{1k}=(-1)^{m}\frac{z_{2}z_{4}z_{6}\cdots}{z_{1}z_{3}z_{5}\cdots}$$

即「所有从动轮齿数的连乘积 ÷ 所有主动轮齿数的连乘积」；其中 $m$ 为外啮合齿轮的对数——这是课堂上反复强调的「那个负号」的来源。

  • 空间轮系（含锥齿轮、蜗杆蜗轮等轴不平行的场合）：不能用正负号，必须用箭头表示各轮的转向关系。

周转轮系的求解：转化机构法（反转法）

给整个轮系加上一个 $-n_H$ 的公共转速，使行星架「静止」，周转轮系就转化为定轴轮系，再按定轴轮系的方法列式。

课堂原话要点：公式里的 $n_H$ 要扣除，因为它「找跨制做」——即由转化机构得来。行星架转速 $n_H$ 是周转轮系区别于定轴轮系的关键量。

复合轮系的解题步骤

  1. 先判定哪一部分是定轴轮系、哪一部分是周转轮系；
  2. 各部分分别列传动比方程；
  3. 找联系条件（同一构件的转速相等）；
  4. 联立求解。

装配条件

周转轮系中各轮要能实际装上去，需满足：

  • 同心条件：中心距相等；
  • 装配条件：齿数满足特定关系；
  • 邻接条件：相邻行星轮不干涉。

课堂强调：「不合理的轮系结构改进」是重点，但不算很难——题型相对固定，多看例题即可。

4.2 滚动轴承的功用与结构

功用

轴要转动，机架（轴承座）是固定的。要让两者既连接、又允许相对转动，就需要轴承——其核心作用是尽量减少轴与机架之间的摩擦。

结构（四大件）

零件 位置与作用
内圈 装在轴上，随轴转动
外圈 装在轴承座孔内，固定不动
滚动体 在内、外圈滚道之间滚动，是承载的核心
保持架 把滚动体均匀隔开，防止相互摩擦

要点补充：

  • 内圈的外表面、外圈的内表面上都开有沟槽（滚道），滚动体在其中滚动；
  • 内圈随轴转、外圈固定，滚动体在两圈之间做复合运动；
  • 轴承两端常设防尘盖 / 密封圈：防尘、防止润滑脂泄漏，并限制轴向窜动。

4.3 调心与偏位角

  • 轴受力后会产生弯曲变形，实际轴线偏离理论轴线；
  • 调心轴承：具备自动调心功能，能让轴回到原来的轴线位置；
  • 偏位角（偏移角）：理论轴线与实际轴线之间的夹角——这是衡量调心能力的核心指标；
  • 调心球轴承的偏位角约为 2°～3°，超出后需改进结构才能适应。

选调心轴承的场合：轴有明显的挠曲变形，或两轴承座孔同轴度差、安装难以对中时。

4.4 极限转速

  • 定义：在保证一定润滑条件下，轴承能够承受的最高工作转速；
  • 使用原则：轴的工作转速必须小于轴承的极限转速；
  • 规律：
    • 球轴承摩擦小 → 极限转速高；
    • 滚子轴承摩擦大 → 极限转速低；
    • 推力轴承极限转速最低，高速时滚动体有被甩出的风险。

4.5 轴承的分类

按承载方向

类型 承受的载荷
向心轴承 主要承受径向载荷（垂直于轴线）
推力轴承 主要承受轴向载荷（沿轴线方向）

接触角 $\alpha$ 的作用：接触角越大，轴承承受轴向力的能力越强。

  • $\alpha=0$：接触方向与径向一致 → 典型为深沟球轴承；
  • 接触角增大 → 角接触球轴承（$\alpha$ = 15°、25°、40°）。

按滚动体形状

类型 接触形式 承载能力 极限转速
球轴承 点接触 较低 较高（摩擦小）
滚子轴承 线接触 较高（约为球轴承的 1.5～3 倍） 较低（摩擦大）

课堂原话：「滚子轴承为什么比球轴承承载能力高？因为它是线接触。」

其他分类

  • 按滚动体列数：单列 / 双列 / 多列；
  • 按能否调心：调心 / 非调心；
  • 按内外圈能否分离：可分离 / 不可分离。

4.6 轴承代号

基本代号的构成（5 位）

类型代号（常用）

代号 轴承类型
1 调心球轴承
2 调心滚子轴承
3 圆锥滚子轴承
5 推力球轴承
6 深沟球轴承
7 角接触球轴承
N 圆柱滚子轴承

课堂强调：6 类是深沟球（最常用）、7 类是角接触球。

内径代号（必记）

内径 $d$ 内径代号
10 mm 00
12 mm 01
15 mm 02
17 mm 03
20～480 mm（5 的倍数） $d \div 5$
≥ 500 mm 直接标注内径（用斜杠分隔）

反向推算：已知内径代号 ≥ 04 时，内径 $d$ = 内径代号 × 5（mm）。

例：6208 → 内径代号 08 → $d = 8 \times 5 = 40$ mm。

公差等级

由低到高：P0 < P6 < P5 < P4 < P2。

  • P0 为普通级，在代号中省略；
  • 等级越高，旋转精度越好，价格也越高。

配置（成对安装）

成对安装的角接触球轴承 / 圆锥滚子轴承，用后置代号表示配置方式：

代号 含义
DF 面对面
DB 背对背
DT 串联

课堂提到的「面对面」配置即 DF。

4.7 常用轴承类型详解

调心球轴承（1 类）

  • 结构：外圈滚道为球面，滚动体为两列球（课堂上描述为「两个球、球上方有两个圆弧」）；
  • 承载：以径向为主，可承受较小的轴向载荷；
  • 极限转速：中等；
  • 偏位角：约 2°～3°，具备自动调心能力。

圆锥滚子轴承（3 类）

  • 结构：外圈一端为大头、另一端为小端，滚动体为圆锥滚子；
  • 安装：分正装与反装；
  • 承载：由于是线接触，整体承载能力大于角接触球轴承（后者为点接触）；
  • 使用：必须成对使用。

深沟球轴承（6 类）

  • 最常用、性价比最高的一类；
  • 承载：主要承受径向载荷，也能承受较小的轴向载荷；
  • 极限转速：高（滚动体为球，摩擦小）。

角接触球轴承（7 类）

  • 接触角有 15°、25°、40° 等规格（对应不同后缀）；
  • 能同时承受径向载荷与较大的轴向载荷；
  • 必须成对使用，采用面对面（DF）或背对背（DB）配置。

4.8 轴承类型的选用

第一步：按载荷方向

载荷情况 推荐类型
纯径向 深沟球轴承、圆柱滚子轴承
纯轴向（小） 推力球轴承
纯轴向（大） 推力滚子轴承
径向 + 较小轴向 深沟球轴承、角接触球轴承
径向 + 较大轴向 角接触球轴承（大接触角）、圆锥滚子轴承

第二步：按载荷大小

  • 载荷大 → 选滚子轴承（线接触，承载能力约为球轴承的 1.5～3 倍）；
  • 载荷小 → 选球轴承。

第三步：按转速

  • 转速高 → 选球轴承（摩擦小，极限转速高）；
  • 转速低 → 选滚子轴承；
  • 推力轴承极限转速最低，高速场合不宜使用——转速很高时滚动体可能被甩出，此时应改用角接触球轴承等。

第四步：按调心要求

  • 轴有挠曲变形、或轴承座孔同轴度差 → 选调心轴承。

经济性

一般情况下球轴承比滚子轴承便宜，因此优先选球轴承；但最终要结合载荷、转速等条件综合考虑。

例外：3 类（圆锥滚子）和 7 类（角接触球）在使用时通常都需要成对安装（正装或反装）。

4.9 滚动轴承的受力分析

轴承受径向力 $F$ 时，各滚动体的受力并不相等：

  • 位于最下方的滚动体受力最大；
  • 越往两侧，滚动体受到的径向分力越小；
  • 到水平轴线附近时基本不受力。

滚动体的受力随时间变化：滚动体每转过一圈，只在下方受力区内受到载荷，且力的大小从小到大、再减小——即承受循环变化的接触应力。

主要失效形式：接触点的疲劳（点蚀）、磨损、塑性变形。

因此轴承寿命计算主要围绕接触疲劳展开。

4.10 轴承的寿命

两个基本概念

概念 定义
总寿命 轴承从开始运转到失效的全部时间（可用转数或小时表示）
基本额定寿命 $L_{10}$ 一批相同轴承在相同条件下运转，其中 10% 出现失效（90% 仍能正常工作）时的寿命

寿命计算公式

$$L_{10}=\left(\frac{C}{P}\right)^{\varepsilon}$$

$$L_{10h}=\frac{10^{6}}{60n}\left(\frac{C}{P}\right)^{\varepsilon}$$

符号 含义 单位
$L_{10}$ 基本额定寿命（以 $10^6$ 转为单位） $10^6$ r
$L_{10h}$ 基本额定寿命（以小时为单位） h
$C$ 基本额定动载荷 N
$P$ 当量动载荷 N
$n$ 转速 r/min
$\varepsilon$ 寿命指数：球轴承 $\varepsilon=3$，滚子轴承 $\varepsilon=10/3$ —

$C$ 越大，说明轴承能承受的载荷越大，寿命越长。

当量动载荷

$$P=XF_r+YF_a$$

符号 含义
$F_r$ 径向载荷
$F_a$ 轴向载荷
$X$ 径向动载荷系数
$Y$ 轴向动载荷系数
  • $X$、$Y$ 需查表确定（课堂提及教材第 143 页的表）；
  • 单列、双列、成对安装的轴承，$X$、$Y$ 取值不同，查表时要看清是哪一种。

4.11 蜗杆蜗轮传动（引入）

蜗杆与蜗轮的区分

  • 蜗杆：外形类似一根圆柱（矩形），是主动件；
  • 蜗轮：外缘呈圆弧形，包住蜗杆，是从动件；
  • 两者啮合处的接触也是圆弧接触。

主要参数

参数 说明
蜗杆头数 $z_1$ 常用 1、2、4、6
蜗轮齿数 $z_2$ 一般取 28～80
传动比 $i$ $i=z_2/z_1$
旋向 右旋 / 左旋

举例：若 $z_1=2$、要求 $i=14$，则 $z_2 = i \cdot z_1 = 28$。

课堂还提到蜗杆的直径系数 $q$、模数等参数，以及与齿轮传动（直齿轮、斜齿轮、锥齿轮）的对比——这部分是下一节课的内容。

五、例题与解题方法汇总

题型 1：轮系传动比计算

  1. 判断是定轴、周转还是复合轮系；
  2. 定轴部分：直接用 $i=(-1)^m \times$ 齿数比；
  3. 周转部分：用转化机构法（反转法），注意 $n_H$；
  4. 复合轮系：分块列式 → 找联系条件 → 联立求解。

题型 2：轴承代号解读

例：解读 6208。

  • 6 → 类型代号：深沟球轴承；
  • 2 → 尺寸系列：轻系列（直径系列 2）；
  • 08 → 内径代号：$d = 8 \times 5 = 40$ mm。

例：解读 30208。

  • 3 → 圆锥滚子轴承；
  • 02 → 尺寸系列；
  • 08 → $d = 40$ mm。

题型 3：轴承寿命计算

  1. 求出轴承的径向载荷 $F_r$ 与**轴向载荷 $F_a$**；
  2. 查表取 $X$、$Y$，算当量动载荷 $P=XF_r+YF_a$；
  3. 代入 $L_{10}=(C/P)^{\varepsilon}$ 得寿命（$10^6$ 转）；
  4. 需要小时数时，再用 $L_{10h}=\frac{10^6}{60n}\left(\frac{C}{P}\right)^{\varepsilon}$。

题型 4：轴承类型选择

按「载荷方向 → 载荷大小 → 转速 → 调心要求」四步逐一筛选。

蜗杆头数 $z_1$ 蜗杆上螺旋线的条数，常用 1、2、4、6
蜗轮齿数 $z_2$ 蜗轮的齿数，一般 28～80

七、课堂强调与复习重点

  1. 滚动轴承是本节重点，代号（尤其内径代号）和选型是必考内容。
  2. 轮系中「不合理的结构改进」是重点，但题型固定，多练例题即可。
  3. 传动比的符号只对平面轮系有效，空间轮系必须画箭头。
  4. 内径代号要背熟：10/12/15/17 → 00/01/02/03；20～500 → 内径 ÷ 5。
  5. 选型口诀：先方向、后大小、再看转速、最后调心。
  6. 3 类和 7 类必须成对使用（正装 / 反装）。
  7. 寿命计算要区分转数（$L_{10}$）与小时数（$L_{10h}$），别把单位搞混。
  8. 轴承寿命的设计原则：轴承的寿命应与轴上其他零件匹配，做到便于及时更换和维修。

八、【以教材为准】待核对清单

以下内容课堂口述不够完整或存在识别歧义，请以教材为准：

  1. 内径 ≥ 500 mm 的代号表示方法：课堂只提到「用分数表示」，具体写法需查教材。
  2. 当量动载荷系数 $X$、$Y$ 的具体取值：需查教材第 143 页对应的表格，并区分单列 / 双列 / 成对安装。
  3. 蜗轮齿数下限：课堂口述为「28」，建议按教材确认（一般为 $z_2 \geq 28$）。
  4. 角接触球轴承后缀与接触角的对应关系（C / AC / B 分别对应 15° / 25° / 40°）：课堂只提到 15°，请核对教材。

  7. 蜗杆直径系数 $q$ 与模数的关系：本节只作引入，待下节课展开。
