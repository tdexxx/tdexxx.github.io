HMI 触摸屏组态与自动伸缩门 PLC 控制系统

《电气控制与PLC》课堂笔记：HMI（触摸屏）组态 · 自动伸缩门 PLC 控制系统设计

一、这节课讲了什么

这节课是「电气控制 + PLC + HMI」三件套的第一次合体，从「为什么要有触摸屏」讲到「用触摸屏控制一台真实的门」。

模块 内容
HMI 认知 触摸屏 = 人机界面，是什么、有什么用、有哪几类面板
组态软件 WinCC 的版本与定位
博途实操 添加 HMI 设备 → 设备组态 → 建立 HMI 连接 → 变量关联
画面组态 指示灯、按钮、动画与 PLC 变量的绑定
项目实战 自动伸缩门控制系统：控制要求 → I/O 分配 → 程序分析 → 触摸屏重复控制
电气控制复习 启动按钮 + 中间继电器 + 自锁（记忆与保持）

课堂节奏：先跟着做一遍基础操作（约 25 分钟），再进入本节的正式项目（自动伸缩门）。

二、核心结论速览

  1. 触摸屏又称人机界面（HMI，Human Machine Interface），是操作人员与 PLC 之间的「对话窗口」。
  2. HMI 广泛应用于工业控制现场，通常与 PLC 配套使用。
  3. HMI 的核心作用是替代传统按钮和指示灯，把设备的运行状态可视化。
  4. 按用途和形态，面板大致分为：精简面板、精智面板、移动面板、按键面板四类。
  5. 移动面板可在移动中实时监测；按键面板是传统按钮的替代方案。
  6. HMI 一般带 USB 接口，可连接键盘、鼠标、条码扫描器等外设。
  7. HMI 通过 PROFINET 等工业以太网与 PLC 通信，可与多种 PLC 连接。
  8. WinCC 是西门子的人机界面组态软件，有 Basic / Comfort / Advanced / Professional 等多个版本。
  9. 组态的标准流程：添加 HMI 设备 → 设备组态 → 建立 HMI 与 PLC 的连接 → 关联变量 → 编辑画面。
  10. 在博途中添加 HMI 设备时，要先选系列、再选具体型号（含屏幕尺寸），选错系列会导致后续无法连接。
  11. HMI 与 PLC 之间必须先建立「连接」，否则画面上的对象找不到数据源。
  12. 画面上的每个对象（指示灯、按钮）都要绑定一个 PLC 变量，变量的值决定对象的表现。
  13. 指示灯用颜色或亮/灭表示变量状态；按钮按下时改变变量值（置位 / 复位）。
  14. 每个对象都可以设置动画，动画的时间轴与 PLC 变量的变化同步。
  15. HMI 组态的本质是「把电气原理图上的按钮和指示灯搬到屏幕上」——逻辑不变，载体变了。
  16. 本节项目是自动伸缩门控制系统，控制对象是一台真实的门。
  17. 门的三个执行动作：开门（Y1）、关门（Y2）、暂停（Y3）。
  18. 控制要求一：按开门按钮 → 电动机正转 → 门打开 → 开门限位开关动作时停止。
  19. 控制要求二：按关门按钮 → 延时 5 秒 → 电动机反转 → 门关闭 → 关门限位开关动作时停止。
  20. 控制要求三：门的内侧设有暂停按钮，用于紧急停止（安全要求）。
  21. 控制要求四：关门过程中若碰到障碍，应能触发安全动作（防夹）。
  22. 程序结构上，开门与关门是两条独立的控制支路，各自带自锁，并通过互锁避免同时接通。
  23. 硬件设计阶段要完成设备连接与地址分配，明确每个输入、输出对应的物理点。
  24. 项目要求用触摸屏实现重复控制——即同一套逻辑既能在屏上操作，也能在现场按钮上操作。
  25. 电气控制的基础仍是那三件套：启动按钮 + 中间继电器 + 自锁触点，实现信号的记忆与保持。
  26. 自锁就是「按一下，松手后电路自己保持通电」；互锁就是「你通了我就不能通」。

三、知识结构树

四、知识点详解

4.1 HMI 是什么

触摸屏又称人机界面（HMI），是操作人员与 PLC 之间交互的窗口，广泛应用于工业控制现场，通常与 PLC 配套使用。

它能做什么

  • 把设备的运行状态显示出来（门开没开、电动机转没转）；
  • 让操作人员在屏幕上操作（按「开门」「关门」）；
  • 替代传统的按钮 + 指示灯组合，减少柜内元件与接线。

面板的分类

类型 特点
精简面板 面向简单应用，功能基础
精智面板 可做较复杂的画面与程序
移动面板 可在移动过程中进行实时监测
按键面板 传统按钮的创新替代方案

接口能力

  • USB：可连接键盘、鼠标、条码扫描器等外设；
  • PROFINET：与 PLC 通信的工业以太网接口。

课堂上演示的是与西门子 S7 系列 PLC 配合使用的情形。

4.2 组态软件 WinCC

WinCC 是西门子的人机界面组态软件，用于给 HMI 面板「画画面」。

课堂上介绍了它的多个版本，按功能由简到繁大致是：

版本 定位
Basic 基础版，面向精简面板
Comfort 舒适版，面向精智面板
Advanced 高级版，面向 PC 与复杂应用
Professional 专业版，面向分布式系统

选版本的原则是与手上的面板型号匹配——面板是精简型就用 Basic，是精智型就用 Comfort。

4.3 在博途中添加 HMI 设备（实操步骤）

这是本节课的动手主线，步骤如下：

步骤 1：打开项目，添加 HMI 设备

在项目中执行「添加设备」，选择 HMI 类型。

步骤 2：先选系列，再选型号

  • 先选系列（如精简系列、精智系列）；
  • 再选具体型号，型号里包含屏幕尺寸（例如 9 寸面板）。

易错点：系列选错，后面就无法与手上的实物面板匹配，连接会失败。选型号时注意区分相近的型号后缀。

步骤 3：设备组态

进入设备组态（Device configuration）界面，确认面板的通信接口设置。

步骤 4：确认 PLC 设备

项目里必须已经有 PLC 设备（这是 HMI 的数据来源）。

步骤 5：建立 HMI 连接

在项目的「HMI 连接」中建立 HMI 与 PLC 之间的连接。

关键点：连接建立之前，画面上的对象是「无源」的——它们找不到变量。先连接，再画画面。

步骤 6：关联变量

打开「PLC 变量」表，把 PLC 的变量（包括线圈、位存储器等）关联到画面对象上。

步骤 7：编辑画面

  • 指示灯：设置颜色，让它在变量为 1 时点亮；
  • 按钮：设置按下时对变量执行的动作（置位 / 复位）；
  • 动画：每个对象都可以设置动画，动画与 PLC 变量同步。

课堂原话大意：HMI 组态其实是一层更深层的编辑——你编辑的不只是画面，而是画面背后与 PLC 变量的绑定关系。

4.4 项目实战：自动伸缩门控制系统

背景

自动伸缩门在企业和学校很常见。本项目的目标是用 PLC + 触摸屏来控制一台真实的门。

控制要求（课堂口述整理）

序号 要求
1 按开门按钮 → 电动机正转 → 门打开 → 开门限位开关动作时停止
2 按关门按钮 → 延时 5 秒 → 电动机反转 → 门关闭 → 关门限位开关动作时停止
3 门的内侧设有暂停按钮，用于紧急停止
4 关门过程中若碰到障碍，应能触发安全动作
5 要求用触摸屏实现重复控制

第 2 条的「延时 5 秒」是课堂上明确强调的：按关门按钮后不立即关门，先延时 5 秒再动作，给人员留出通过时间。

I/O 分配

类型 符号 说明
输出 Y1 开门（电动机正转）
输出 Y2 关门（电动机反转）
输出 Y3 暂停 / 状态指示
输入 开门按钮 启动开门
输入 关门按钮 启动关门（带 5 秒延时）
输入 暂停按钮 紧急停止
输入 开门限位开关 门开到位的信号
输入 关门限位开关 门关到位的信号
中间量 中间继电器 / 位存储器 记录「正在开门」「正在关门」等状态
中间量 定时器 实现 5 秒延时

课堂在分析程序时反复提到的 M1.1、M1.3 属于位存储器（中间继电器），分别代表开门、关门相关的中间状态；限位开关信号则用于断开对应的支路。

程序结构分析

  1. 开门支路

    • 按下开门按钮 → 中间继电器动作 → 输出 Y1 接通 → 电动机正转；
    • 支路带自锁：松开按钮后继续保持；
    • 当开门限位开关动作时，断开该支路 → 门停在开到位处。

  2. 关门支路

    • 按下关门按钮 → 定时器开始计时；
    • 计时到 5 秒后 → 输出 Y2 接通 → 电动机反转；
    • 支路同样带自锁；
    • 当关门限位开关动作时，断开该支路 → 门停在关到位处。

  3. 暂停支路

    • 按下暂停按钮 → 断开正在执行的支路 → 门立即停止。

  4. 互锁

    • 开门与关门不能同时接通，必须在程序或线路中互锁。

课堂原话大意：门在关闭过程中如果碰到东西，应当触发安全动作——这对应现实中的防夹保护。

HMI 画面

  • 画面上放置按钮：启动（开门）、停止、暂停；
  • 放置指示灯：显示门的当前状态；
  • 每个对象都关联到上面 I/O 表中的变量；
  • 最终效果：在现场按按钮和在屏幕上点按钮，效果一致。

4.5 电气控制线路复习

课堂在讲 PLC 程序前，先回顾了继电器—接触器控制线路的基础：

三个基本要素

  1. 启动按钮：常开触点，按下时接通；
  2. 中间继电器 / 接触器线圈：得电动作，带动其触点翻转；
  3. 自锁触点：把接触器自己的常开触点并联在启动按钮两端。

自锁（记忆与保持）

  • 按下启动按钮 → 线圈得电 → 其常开触点闭合；
  • 松开启动按钮 → 电流经自锁触点继续供给线圈 → 电路保持通电。

这就是电气控制里的「记忆与保持」——按一下，松手后电路自己记住「已启动」。

互锁

两条互斥支路（如正转与反转）之间，把对方的常闭触点串进自己的回路：

  • 正转支路串反转接触器的常闭触点；
  • 反转支路串正转接触器的常闭触点；
  • 结果：一个通了，另一个就通不了。

常开 / 常闭触点

触点 未动作时 动作后
常开（NO） 断开 闭合
常闭（NC） 闭合 断开

线圈输出

程序的最后一级是线圈——它对应实际的输出继电器或接触器线圈，得电即动作。

五、例题与解题方法汇总

题型 1：根据控制要求做 I/O 分配表

步骤

  1. 数清有几个执行动作 → 决定输出点数；
  2. 数清有几个操作按钮 + 限位开关 → 决定输入点数；
  3. 需要记忆状态的，列出中间继电器；
  4. 需要延时的，列出定时器。

题型 2：绘制带自锁与互锁的控制电路

步骤

  1. 画出启动按钮 + 自锁触点并联；
  2. 把停止（或限位）信号以常闭形式串在回路里；
  3. 需要互锁的，把对方接触器的常闭触点串进来；
  4. 最后接线圈。

要点：停止和限位用常闭，启动用常开——这是电气控制线路的基本约定。

题型 3：带延时的控制（如延时 5 秒关门）

步骤

  1. 按关门按钮 → 启动定时器（不是直接启动电动机）；
  2. 定时器到达设定值（5 秒）→ 其触点动作；
  3. 用定时器触点去接通关门输出。

要点：分清通电延时与断电延时两种定时器，按题意选用。

题型 4：HMI 组态的步骤排序

正确顺序：

添加 HMI 设备 → 选系列与型号 → 设备组态 → 建立 HMI 连接 → 关联变量 → 编辑画面

易错点：把「编辑画面」放在「建立连接」之前——这样画出来的对象是没有变量来源的。

七、课堂强调与复习重点

  1. 先建立 HMI 连接，再编辑画面——顺序反了对象就没有数据源。
  2. 添加 HMI 设备时先选系列、再选型号，系列选错后面全错。
  3. 按钮替代不了逻辑：HMI 只是把按钮搬到屏幕上，控制逻辑仍在 PLC 里。
  4. 关门延时 5 秒是本题的关键细节，别漏。
  5. 开门与关门必须互锁。
  6. 限位开关要用常闭触点串在回路里，这样断线也能停机（故障安全）。
  7. 电气控制的根基还是自锁与互锁，PLC 程序只是把线路「翻译」成梯形图。
  8. 做项目先写控制要求，再做 I/O 分配表，最后才写程序——顺序不要颠倒。

  21. 电气控制线路中的「线圈」对应实际系统中的什么器件？
  22. PLC 程序与继电器控制线路之间是什么关系？

十、复习自测参考答案

建议先自己做完第九部分，再对照这里。带「★」的是本题的重点。

1. HMI = Human Machine Interface（人机界面），日常就叫触摸屏。它位于操作人员与 PLC 之间，是人与控制系统交互的窗口：向上给操作者显示设备状态，向下与 PLC 交换数据。

2. ① 把设备运行状态可视化，操作者一眼就能看清门开没开、电动机转没转；② 用软件画面替代实物按钮和指示灯，减少柜内元件与接线；③ 工艺变了只需改画面，不用改硬件；④ 还能做报警、趋势、配方这些传统按钮做不到的功能。

3. 精简面板（面向简单应用，功能基础）、精智面板（可做较复杂的画面与程序）、移动面板（可在移动过程中实时监测）、按键面板（传统按钮的创新替代方案）。

4. 通信一般通过 PROFINET（工业以太网）。此外通常带 USB 接口，可接键盘、鼠标、条码扫描器等外设。

5. WinCC 是西门子的人机界面组态软件，用于给 HMI 面板做画面。主要版本由简到繁为：Basic、Comfort、Advanced、Professional。

6. ★ 因为型号是挂在系列下面的——先确定系列，才能列出该系列下可选的型号。系列决定了面板的能力范围（支持的画面复杂度、可用控件、配套的组态软件版本），型号进一步确定屏幕尺寸与接口配置。系列选错，后面就无法与手上的实物面板匹配，连接会失败。

7. 设备组态主要设置设备的通信接口与硬件参数——即面板用哪个接口、以什么协议与 PLC 通信，以及模块的地址分配。

8. ★ 因为画面上的每个对象（指示灯、按钮）都必须绑定一个 PLC 变量才能工作，而连接就是变量传输的通道。连接没建立，对象就没有数据源，画出来的东西是「死」的。所以必须先把连接建好，再画画面。

9. 在对象属性里指定它绑定的变量地址（如某个输出位或位存储器）。运行时 HMI 周期性读取该变量的值：为 1 时按设定的「亮」状态显示，为 0 时按「灭」状态显示。颜色、闪烁、动画都由这个值驱动。

10. 按钮按下时对变量执行写操作——通常是置位（Set）或复位（Reset），也可以是「按下置位、松开复位」（点动）。具体动作在按钮的事件配置里设定。

11. 意思是：HMI 组态改的不只是画面长什么样，而是画面背后与 PLC 变量的绑定关系。你表面上在拖控件、调颜色，实际上是在配置「哪个控件读写哪个变量、在什么条件下动作」——这一层逻辑才是 HMI 的实质，所以它比单纯的「画图」深一层。

12. ① 按开门按钮 → 电动机正转 → 门打开 → 开门限位开关动作时停止；② 按关门按钮 → 延时 5 秒 → 电动机反转 → 门关闭 → 关门限位开关动作时停止；③ 门内侧设暂停按钮，用于紧急停止；④ 关门过程中碰到障碍应能触发安全动作；⑤ 要求用触摸屏实现重复控制。

13. ★

类型 符号 说明
输出 Y1 开门（电动机正转）
输出 Y2 关门（电动机反转）
输出 Y3 暂停 / 状态指示
输入 开门按钮 启动开门
输入 关门按钮 启动关门（带 5 秒延时）
输入 暂停按钮 紧急停止
输入 开门限位开关 门开到位信号
输入 关门限位开关 门关到位信号
中间量 中间继电器 / 位存储器 记录「正在开门 / 正在关门」
中间量 定时器 实现 5 秒延时

14. 延时是为了给人员留出通过时间——按下关门按钮后门不立刻动，5 秒内人员可以安全通过或退出。这 5 秒由定时器实现：按关门按钮先启动定时器，定时到达后再接通关门输出。

15. ★ 开门（Y1，正转）与关门（Y2，反转）如果同时接通，会造成主电路两相短路（正反转接触器同时吸合 → 电源相间短路），是严重事故。互锁就是让两条支路互相封锁：一个通了，另一个就通不了。

16. ★ 用常闭触点串在回路里，是为了故障安全：正常时触点闭合、回路通畅；一旦导线断线、触点接触不良或限位开关损坏，回路立即断开，门停止动作。如果反过来用常开触点，断线时回路反而「以为已经到位」，会造成失控。这就是电气控制里「停止与保护一律用常闭」的原因。

17. 自锁：把接触器（或继电器）自己的常开辅助触点并联在启动按钮两端。按下启动按钮 → 线圈得电 → 常开触点闭合；松开按钮后，电流经这个触点继续供给线圈，电路自行保持通电。作用是实现信号的记忆与保持——「按一下，松手后电路记住已经启动」。

18. ★ 互锁：把对方接触器的常闭触点串进自己的回路，使两条互斥支路不能同时通电。

记忆要点：正转支路串 KM2 的常闭触点，反转支路串 KM1 的常闭触点——用对方的常闭来封锁自己。

19. 常开（NO）：未动作时断开，动作后闭合。常闭（NC）：未动作时闭合，动作后断开。

20. ① 先写清控制要求（有哪几个动作、什么条件启动、什么条件停止）；② 再做 I/O 分配表（输出点数、输入点数、中间量、定时器）；③ 然后画电气原理图或写程序；④ 最后做 HMI 画面并与变量关联。顺序颠倒容易漏掉条件。

21. 线圈对应实际系统中的执行器件——输出继电器、中间继电器、接触器的线圈。在 PLC 里，线圈对应输出端子（Q）或位存储器（M），得电即动作，进而驱动接触器、电磁阀、指示灯等。

22. PLC 程序（梯形图）与继电器控制线路是逻辑等价的：梯形图的触点对应线路里的常开/常闭触点，线圈对应继电器/接触器线圈，自锁、互锁这些结构一一对应。区别在于：继电器线路靠硬件接线实现，PLC 靠程序扫描实现——改逻辑不用改线，还能实现定时、计数、运算等继电器做不到的功能。
