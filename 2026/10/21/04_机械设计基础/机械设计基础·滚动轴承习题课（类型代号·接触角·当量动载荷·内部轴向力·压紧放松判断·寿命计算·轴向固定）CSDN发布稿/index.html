滚动轴承习题课：类型代号、当量动载荷与寿命计算

《机械设计基础》滚动轴承习题课：类型代号 · 接触角 C/AC/B · 当量动载荷 · 内部轴向力 · 压紧放松判断 · 寿命计算 · 轴向固定与轴系结构

本篇为《机械设计基础》滚动轴承习题课整理。这节课把”滚动轴承”这一章的计算题从头到尾走了一遍，并补上了教材里讲得少、但工程上必须会的轴向固定与轴系结构。

主线是这样一条链：

认得出（类型代号、接触角、内径代号）→ 选得对（调心？极限转速？）→ 算得准（当量动载荷 P → 内部轴向力 S → 压紧/放松判断 → 各轴承的 Fa → 寿命 L）→ 装得上（轴向固定方式、装拆、轴系结构改错）。

中间穿插了三个完整例题：单轴承求 P、一对圆锥滚子轴承求轴向力分配与寿命、深沟球与角接触球轴承的选型对比。

文中公式统一采用行内数学写法；课堂口述与教材符号不一致、或录音模糊处，均标注【以教材为准】。

一、这节课讲了什么

这是一节习题课，老师的组织方式是”先补基础、再走例题、最后讲结构”。

第一段（约 25:28–34:20）把”认得出来”解决掉。
老师给了一套类型代号的记忆顺序：调心球（1）、调心滚子（2）、圆锥滚子（3）、推力球（5）、深沟球（6）、角接触球（7）、圆柱滚子（N）。接着讲角接触球轴承的三个接触角 C（15°）、AC（25°）、B（40°），以及轴承代号的三段结构——前置代号、基本代号（类型代号 + 尺寸系列代号 + 内径代号）、后置代号。这里有一个必考的坑：**内径代号 00/01/02/03 分别对应 10/12/15/17 mm，从 04 起才是”代号 × 5”**。

第二段（约 32:19）用一道选型题把”选得对”讲清。
轴发生偏移、转速又较大——该选调心球轴承还是调心滚子轴承？答案是调心球轴承，理由是球轴承的极限转速更高。老师顺带纠正了一处常见错误：极限寿命 $L$ 的单位是 $10^6$ 转，不是”转”。

第三段（约 34:25–1:31:00）是全课的计算主线。
先用一道单轴承例题讲清当量动载荷：查表得判断系数 $e$，再比较 $F_a/F_r$ 与 $e$ 的大小，决定 $X$、$Y$ 取值。然后讲内部轴向力（派生轴向力）$S$ 是怎么产生的——径向力作用在滚动体上，因为有接触角，合力会分解出一个轴向分量，各滚动体轴向分量之和就是 $S$。深沟球轴承接触角为零，不产生 $S$。接着是正装/反装的力线判断，以及一对轴承里”谁被压紧、谁被放松“的判断方法——这是全章最绕的一步。最后进入寿命计算：$P^{\varepsilon} L$ 为常数，球轴承 $\varepsilon = 3$、滚子轴承 $\varepsilon = 10/3$，并引入温度系数 $f_T$ 与载荷系数 $f_P$。

第四段（约 1:32:00–1:51:00）讲”装得上”。
包括轴向固定方式（双支点单向固定、一端固定一端游动）、内圈与外圈各自的固定手段（弹性挡圈、圆螺母、轴肩、端盖、套筒）、装拆要点（拆装工具必须卡在内圈上，卡外圈是错的），以及一组轴系结构改错——齿轮与轴承之间必须加隔离套（油润滑与脂润滑不能混）、轴肩高度要够、键槽要同侧、用阶梯轴降低加工面。

二、核心结论速览

  1. 类型代号记忆顺序：调心球 1、调心滚子 2、圆锥滚子 3、推力球 5、深沟球 6、角接触球 7、圆柱滚子 N。
  2. 角接触球轴承的三个接触角：C = 15°、AC = 25°、B = 40°。题目给”接触角 25°”，就对应代号 AC。
  3. 轴承代号三段结构：前置代号 + 基本代号（类型代号 + 尺寸系列代号 + 内径代号）+ 后置代号。
  4. 内径代号必背：00 → 10 mm、01 → 12 mm、02 → 15 mm、03 → 17 mm；从 04 起，内径 = 代号 × 5。
  5. 例：轴径 $d = 60$ mm，内径代号 $= 60/5 = 12$；轴径 $d = 30$ mm，内径代号 $= 30/5 = 6$。
  6. 调心球 vs 调心滚子：两者都能调心，但球轴承的极限转速更高。转速较大时选调心球轴承。
  7. 极限寿命 $L$ 的单位是 $10^6$ 转，不是”转”——说”$L$ 的单位是转”是错的。
  8. 当量动载荷：$P = X F_r + Y F_a$。
  9. 判断系数 $e$ 从表格查，查表要看清轴承类型 + 接触角分档（角接触球轴承 7 类里还分 C/AC/B 三小行）。
  10. $F_a / F_r \le e$ 时：$X = 1$、$Y = 0$，即 $P = F_r$——轴向力”不产生额外影响”。
  11. $F_a / F_r > e$ 时：$X$、$Y$ 按表格取值（角接触球轴承常见 $X = 0.41$，$Y$ 随接触角变）。
  12. 内部轴向力 $S$（派生轴向力）只在有接触角时产生：角接触球轴承、圆锥滚子轴承有；**深沟球轴承接触角为零，没有 $S$**。
  13. $S$ 的产生机理：径向力 $F_r$ 作用在滚动体上产生反力，因接触角存在，合力分解出轴向分量，各滚动体轴向分量之和即 $S$。
  14. 角接触球轴承：$S = e F_r$（$e$ 查表）。
  15. 圆锥滚子轴承：$S = \frac{F_r}{2Y}$（$Y$ 查表）。
  16. 正装（面对面）与反装（背对背） 的区别在于接触角方向 / 力线交点的位置：力线向内收敛为面对面，向外张开为背对背。
  17. 一对轴承的轴向力要重新分配：先算两端各自的 $S$，再判断整个轴系的运动趋势朝哪边。
  18. 被压紧的一端：$F_a = S’ + F_A$（外部轴向力 + 另一端的内部轴向力）。
  19. 被放松的一端：$F_a = S$（只承受自身的内部轴向力）。
  20. 判断”压紧/放松”是解题的关键一步——判错了，后面 $P$ 和 $L$ 全错。
  21. 寿命计算的基本关系：$P^{\varepsilon} L$ 为常数。
  22. 寿命指数：**球轴承 $\varepsilon = 3$；滚子轴承 $\varepsilon = 10/3$**。
  23. 滚子轴承的 $\varepsilon$ 大于球轴承，因为滚子是线接触、承载能力更强，寿命对载荷变化更不敏感。
  24. 基本额定寿命：$L_{10} = (\frac{C}{P})^{\varepsilon}$，单位 $10^6$ 转。
  25. 换算成小时：$L_{10h} = \frac{10^6}{60n}(\frac{C}{P})^{\varepsilon}$。
  26. **温度系数 $f_T$**：工作温度低于 100 °C 时取 1（常温约 25 °C 一般取 1）。
  27. 载荷系数 $f_P$：轻微冲击或无冲击取 1～1.2，计算时为方便常取 1。
  28. 反算所需额定动载荷：$C_{req} = \frac{f_P P}{f_T}(\frac{60 n L_h}{10^6})^{1/\varepsilon}$，选轴承时要求**样本 $C \ge C_{req}$**。
  29. 当量静载荷 $C_{0r}$ 一般不作计算要求，知道它是”静止或极低速时的承载能力指标”即可。
  30. 轴向固定两种基本方式：双支点单向固定（两端各限制一个方向）与一端固定一端游动（一端双向固定、另一端可游动补偿热伸长）。
  31. 内圈固定手段：轴肩、弹性挡圈、圆螺母 + 止动垫圈、端盖压紧、套筒。
  32. 外圈固定手段：孔内挡肩、孔用弹性挡圈、端盖、螺纹环。
  33. 装拆铁律：拆装工具的受力点必须落在要拆的那个套圈上——拆内圈就卡内圈，卡到外圈是错误结构。
  34. 油润滑与脂润滑不能混：齿轮用油润滑、轴承用脂润滑时，两者之间必须加隔离（挡油环/隔离套）。
  35. 轴系结构改错的四个高频点：① 齿轮与轴承之间要加隔离套；② 轴肩高度要能顶住套圈；③ 键槽要在同一侧；④ 用阶梯轴减少不必要的配合加工面。

三、知识结构树

四、知识点详解

4.1 类型代号与记忆方法

老师给了一条”按记忆顺序背”的路子——先记调心类，再记其他：

类型 代号 备注
调心球轴承 1 能调心，球轴承，极限转速高
调心滚子轴承 2 能调心，承载能力大，极限转速低
圆锥滚子轴承 3 能承受较大轴向力，需成对使用
推力球轴承 5 只能承受轴向力
深沟球轴承 6 最常用，性价比最高
角接触球轴承 7 有接触角，能承受轴向力
圆柱滚子轴承 N 只能承受径向力

为什么要按顺序记：考试里经常给一个轴承代号让你”读出类型”，或给一个工况让你”写出代号”。这套顺序是老师建议的记忆锚点，按它顺下来不容易漏。

4.2 角接触球轴承的接触角：C / AC / B

角接触球轴承按接触角大小分三档：

代号 接触角 特点
C 15° 接触角小，主要承受径向力，极限转速最高
AC 25° 常用档，兼顾径向与轴向
B 40° 接触角大，承受轴向力能力强，极限转速最低

考试提示：题目如果说”某角接触球轴承接触角为 25°”，那它的代号就是 AC。老师特别说明：这三个是要记的，其他角度（如 45°）不在本课程要求范围内。

4.3 轴承代号的结构

一个完整的轴承代号分三段：

内径代号是必考点，规则要分两段记：

内径代号 对应内径 $d$
00 10 mm
01 12 mm
02 15 mm
03 17 mm
04 及以上 $d = 5n$ mm（$n$ 为内径代号）

为什么 00~03 要单独记：因为这四个是”一一对应”的例外，不按 ×5 的规律。老师说”这四个不同于其他的，它是直接一一对应的关系”。

反过来用：已知轴径 $d = 60$ mm，则内径代号 $= 60/5 = 12$；已知 $d = 30$ mm，则内径代号 $= 30/5 = 6$。

4.4 选型的两个典型判据

（1）有偏移 → 选调心类

轴发生弯曲变形或安装不同心时，轴颈会相对轴承座产生偏斜。这时必须选调心轴承，让轴线能自动恢复。调心类有调心球（1）和调心滚子（2）两种。

（2）转速高 → 选球轴承

这是本节的关键取舍：

  • 调心球轴承：点接触，摩擦小，极限转速高；
  • 调心滚子轴承：线接触，承载能力大，但摩擦大，极限转速低。

所以”有偏移 + 转速较大“这个组合，答案是调心球轴承，而不是调心滚子轴承。

老师的原话大意：球轴承的极限转速比较高，所以在选择的时候选调心球轴承，而不是调心滚子轴承。

（3）有轴向力 → 选角接触球或圆锥滚子

深沟球轴承虽然也能承受一定轴向力，但能力有限。斜齿轮传动会产生轴向力，这时应选圆锥滚子轴承或角接触球轴承。

4.5 当量动载荷

4.5.1 基本公式

$P = X F_r + Y F_a$

其中 $F_r$ 为径向载荷、$F_a$ 为轴向载荷，$X$、$Y$ 分别为径向系数与轴向系数，由表格按轴承类型与 $F_a/F_r$ 与 $e$ 的比较结果查取。

4.5.2 判断系数 $e$ 的查表与比较

查表的顺序是：

  1. 先定轴承类型（例如角接触球轴承是 7 类）；
  2. 再看分档（7 类里还分 C、AC、B 三小行，按题目给的接触角选行）；
  3. **读出 $e$**；
  4. **比较 $F_a/F_r$ 与 $e$**：
比较结果 系数取值 说明
$F_a/F_r \le e$ $X = 1$，$Y = 0$ 轴向力不产生额外影响，$P = F_r$
$F_a/F_r > e$ $X$、$Y$ 查表 轴向力开始起作用

4.5.3 例题：角接触球轴承求当量动载荷

已知：角接触球轴承，接触角 25°（即代号 AC），径向载荷 $F_r = 1000$ N，轴向载荷 $F_a = 600$ N。

求解步骤：

  1. 由接触角 25° 确定代号为 AC；
  2. 查表：角接触球轴承 7 类、AC 档，得**判断系数 $e = 0.68$**；
  3. 计算比值：$F_a / F_r = 600/1000 = 0.6$；
  4. 比较：$0.6 < 0.68$，即 $F_a/F_r \le e$；
  5. 取 $X = 1$、$Y = 0$；
  6. 所以 $P = 1 \times 1000 + 0 \times 600 = 1000$ N。

这题的考点：不是算乘法，而是会不会查 $e$、会不会比较。很多同学一上来就套 $X=0.41$、$Y=1.6$，忘了先比较 $F_a/F_r$ 与 $e$。

4.6 内部轴向力（派生轴向力）$S$

4.6.1 产生机理

这是本章最抽象的一节，老师的讲法是”从受力图往上推”：

  1. 轴受径向力 $F_r$，通过内圈传给滚动体；
  2. 滚动体受压后产生反力；
  3. 因为轴承有接触角，这个反力不是纯径向的，而是沿接触线方向；
  4. 把每个滚动体的反力分解成径向分量与轴向分量；
  5. 所有滚动体的轴向分量之和，就是**内部轴向力 $S$**（也叫派生轴向力）。

4.6.2 产生条件

必须要有接触角。这是判断”某轴承有没有 $S$”的唯一标准：

轴承类型 接触角 有 $S$ 吗
深沟球轴承 0° 没有
角接触球轴承 15°/25°/40° 有
圆锥滚子轴承 有 有

老师的推理：假设是深沟球轴承，接触角为零，滚动体只受径向反力，那么各滚动体的轴向分量全为零，自然就没有内部轴向力。

4.6.3 计算公式

轴承类型 内部轴向力
角接触球轴承 $S = e F_r$
圆锥滚子轴承 $S = \frac{F_r}{2Y}$

式中 $e$、$Y$ 均由表格查取。

注意：这两个公式形式不同，考试时不要混。角接触球轴承用 $e$ 乘 $F_r$；圆锥滚子轴承是 $F_r$ 除以 $2Y$。

4.7 正装与反装（面对面 / 背对背）

一对角接触球轴承（或圆锥滚子轴承）成对使用时，有两种安装方式：

安装方式 别名 力线特征
正装 面对面 两端接触角力线向内收敛，交点在两轴承之间
反装 背对背 两端接触角力线向外张开，交点在两轴承之外

判断方法：画出接触角方向 → 延长力线与轴线相交 → 看交点在两轴承之间还是之外。

工程习惯：老师说”一般情况都会采用正装”。反装时力线交点在外侧，支承点跨距变大，轴承受力情况不同，需要另行分析。

4.8 压紧端与放松端的判断（本章最绕的一步）

一对轴承成对使用时，外部轴向力只会由一个轴承承担，另一个只承受自身的内部轴向力。判断谁是”压紧端”的步骤：

第一步：算出两端的内部轴向力 $S_1$、$S_2$，并明确它们的方向（都指向轴承外侧）。

第二步：判断整个轴系的运动趋势朝哪一边。方法是比较”两端的 $S$ 与外部轴向力 $F_A$ 的合力方向”。

第三步：按趋势定压紧与放松：

端 轴向力取值
被压紧端 $F_a = S’ + F_A$
被放松端 $F_a = S$

第四步：用各自的 $F_a$ 与 $F_r$ 求 $F_a/F_r$，再与 $e$ 比较，得 $X$、$Y$，算 $P$。

为什么这么判：轴系向某一侧移动时，那一侧的轴承被”顶住”（压紧），所以它要承担”另一端推过来的内部轴向力 + 外部轴向力”；另一侧则”让开”（放松），只承受自身的内部轴向力。

4.9 寿命计算

4.9.1 基本关系

根据大量试验，当量动载荷 $P$ 与寿命 $L$ 之间存在：

$P^{\varepsilon} L$ 为常数

取 $L = 1$（即 $10^6$ 转）时的载荷定义为**基本额定动载荷 $C$**，于是：

$L_{10} = (\frac{C}{P})^{\varepsilon}$

单位是 $10^6$ 转。

**寿命指数 $\varepsilon$**：

轴承类型 $\varepsilon$
球轴承 3
滚子轴承 10/3

为什么滚子轴承的 $\varepsilon$ 更大：滚子是线接触，承载能力更强，寿命对载荷变化不那么敏感，所以指数更大。

4.9.2 换算成小时

$L_{10h} = \frac{10^6}{60n}(\frac{C}{P})^{\varepsilon}$

式中 $n$ 为转速（r/min）。工程上习惯用小时数表示寿命，所以这一步换算几乎必做。

4.9.3 修正系数 $f_T$ 与 $f_P$

系数 含义 取值
$f_T$ 温度系数 工作温度低于 100 °C 取 1；常温（约 25 °C）一般取 1
$f_P$ 载荷系数 轻微冲击或无冲击取 1～1.2；计算时为方便常取 1

引入后：

$L_{10h} = \frac{10^6}{60n}(\frac{f_T C}{f_P P})^{\varepsilon}$

老师的一个提醒：如果希望算出来的寿命尽量大，$f_P$ 就取小一点（取 1），因为它在分母上。

4.9.4 反算所需额定动载荷

实际设计中更常见的是已知预期寿命、反选轴承。把上式变形：

$C_{req} = \frac{f_P P}{f_T}(\frac{60 n L_h}{10^6})^{1/\varepsilon}$

算出的 $C_{req}$ 是所需的最小基本额定动载荷，选轴承时要求样本上的 $C$ 大于等于它。

这正是”试算—校核”流程的由来：先按轴径预选一个型号，查出它的 $C$ 与 $C_{0r}$，再算 $e$、$S$、$F_a$、$P$，最后算寿命或反算 $C_{req}$。如果不够就换大一档，重来一遍。

4.9.5 当量静载荷

$C_{0r}$ 是基本额定静载荷，用于静止或极低速、有冲击的场合。本课程一般不要求计算，知道它是”抗塑性变形的能力指标”即可。

4.10 轴向固定方式

方式 做法 适用
双支点单向固定 两端各用一个轴承，各自限制一个方向的轴向移动 跨距较小、温升不高
一端固定一端游动 一端轴承双向固定，另一端可沿轴向游动 跨距较大、有热伸长

内圈的固定手段：

  • 轴肩（最常用，靠轴上的台阶顶住内圈端面）；
  • 弹性挡圈（卡在轴上的环槽里，结构简单）；
  • 圆螺母 + 止动垫圈（可调整、可预紧）；
  • 端盖压紧；
  • 套筒（隔套，同时起定位与隔离作用）。

外圈的固定手段：

  • 孔内挡肩；
  • 孔用弹性挡圈；
  • 端盖（只限制一个方向）；
  • 螺纹环。

4.11 装拆与轴系结构常见错误

4.11.1 装拆铁律

拆装工具的受力点必须落在”要拆的那个套圈”上。

  • 拆内圈（内圈与轴配合），工具必须卡内圈；
  • 如果结构上工具只能卡到外圈，那就是结构设计错误——因为力会经过滚动体传到另一个套圈，可能把滚动体压坏或挤裂。

4.11.2 轴系结构改错的四个高频点

错误 正确做法 原因
齿轮与轴承端面直接贴合 中间加隔离套（挡油环） 齿轮用油润滑、轴承用脂润滑，两者不能接触，必须隔离
轴肩高度不够 轴肩直径要能顶住套圈端面 轴肩太低顶不到套圈，定位失效
两个键槽不在同一侧 键槽布置在同一母线上 装配时便于对位、受力更合理
整根轴都做成配合面 用阶梯轴，只加工配合段 减少不必要的精加工面，降低成本

五、例题与解题方法汇总

题型 1：选型（给工况选轴承类型）

解题步骤：

  1. 看有没有偏斜/不同心 → 有则必须调心；
  2. 看转速 → 转速高选球轴承，转速低且载荷大选滚子轴承；
  3. 看有没有轴向力 → 有较大轴向力选角接触球或圆锥滚子；
  4. 看有没有冲击 → 有冲击优先滚子轴承（线接触、抗冲击好）；
  5. 综合：例如”有偏斜 + 转速较高”→ 调心球轴承；”斜齿轮传动 + 需承受轴向力”→ 圆锥滚子或角接触球。

题型 2：单个轴承求当量动载荷

解题步骤：

  1. 由型号/接触角确定类型与分档；
  2. 查表得 **$e$**；
  3. 算 $F_a/F_r$，与 $e$ 比较；
  4. 取 $X$、$Y$；
  5. $P = X F_r + Y F_a$。

易错点：忘了先比较 $F_a/F_r$ 与 $e$，直接套 $X=0.41$、$Y=1.6$。

题型 3：一对轴承的轴向力分配 + 寿命

解题步骤：

  1. 求两端内部轴向力：$S_1$、$S_2$（角接触球用 $e F_r$，圆锥滚子用 $F_r/(2Y)$）；
  2. 定方向：两端 $S$ 都指向轴承外侧；
  3. 判趋势：比较”$S_1$、$S_2$、$F_A$ 的合力方向”；
  4. 定压紧/放松：趋势指向的一端为压紧端；
  5. **算各端 $F_a$**：压紧端 $= S’ + F_A$；放松端 $= S$；
  6. **算 $F_a/F_r$**，与 $e$ 比较，取 $X$、$Y$；
  7. **算 $P$**，再算 $L_{10h}$ 或反算 $C_{req}$。

题型 4：轴系结构改错

检查清单（逐条过）：

  1. 齿轮与轴承之间有没有隔离套？（油/脂不能混）
  2. 轴肩高度够不够顶住套圈？
  3. 两个键槽是否在同一侧？
  4. 是否用了阶梯轴减少配合面？
  5. 拆装工具能不能卡到内圈？
  6. 轴承的轴向固定是否完整（内圈、外圈各限制了什么方向）？
  7. 是否有多余约束（两端都双向固定会导致热伸长无补偿）？

六、术语速查表

术语 含义
接触角 滚动体与滚道接触点法线与轴承径向平面的夹角，用 $\alpha$ 表示
基本额定动载荷 $C$ 使轴承基本额定寿命为 $10^6$ 转时所能承受的载荷
基本额定静载荷 $C_{0r}$ 使受载最大滚动体与滚道接触处产生规定永久变形量的静载荷
当量动载荷 $P$ 与实际载荷组合等效的假想载荷，$P = X F_r + Y F_a$
判断系数 $e$ 用于判断轴向力是否起作用的界限值
径向系数 $X$ 当量动载荷中径向载荷的系数
轴向系数 $Y$ 当量动载荷中轴向载荷的系数
内部轴向力 $S$ 因接触角存在，径向载荷派生出的轴向力，又称派生轴向力
正装（面对面） 一对轴承的接触角力线向内收敛的安装方式
反装（背对背） 一对轴承的接触角力线向外张开的安装方式
压紧端 轴系轴向移动时被顶住的一端，承受另一端内部轴向力与外部轴向力
放松端 轴系轴向移动时让开的一端，只承受自身内部轴向力
寿命指数 $\varepsilon$ 寿命公式中的指数，球轴承 3、滚子轴承 10/3
基本额定寿命 $L_{10}$ 一批相同轴承中 90% 不出现疲劳点蚀时能达到的寿命
温度系数 $f_T$ 考虑工作温度对额定动载荷影响的修正系数
载荷系数 $f_P$ 考虑冲击、振动等实际工况的修正系数
双支点单向固定 两端各限制一个方向轴向移动的固定方式
一端固定一端游动 一端双向固定、另一端可游动以补偿热伸长的固定方式
轴肩 轴上直径变化形成的台阶，用于轴向定位
弹性挡圈 卡入轴或孔上的环槽以实现轴向固定的零件
隔离套（挡油环） 隔开油润滑与脂润滑区域的零件
阶梯轴 各段直径不同的轴，用于减少配合加工面、便于装拆

七、课堂强调与复习重点

  1. 内径代号 00～03 是例外，必须单独背；从 04 起才是”代号 × 5”。
  2. 接触角 C/AC/B 对应的角度要记牢：15°、25°、40°。
  3. 极限寿命 $L$ 的单位是 $10^6$ 转，不是”转”。
  4. 调心球 vs 调心滚子的取舍靠极限转速，不是靠承载能力。
  5. **当量动载荷的第一步是查 $e$ 并比较 $F_a/F_r$**，不是直接套 $X$、$Y$。
  6. 内部轴向力只在有接触角时才有——深沟球轴承没有。
  7. **角接触球用 $S = eF_r$，圆锥滚子用 $S = F_r/(2Y)$**，两个公式不能混。
  8. 压紧/放松判断是本章最难的一步，判错则全错。先求 $S$、再定方向、再判趋势。
  9. 寿命指数：球 3、滚子 10/3。
  10. 实际设计是”试算—校核”循环：预选型号 → 查表 → 算 $P$ → 算寿命或反算 $C_{req}$ → 不合适就换型号重来。老师说考试不会考这种反复试算，会直接给 AC 或 B 这类具体档位。
  11. $f_P$ 在分母，想算出的寿命大就取小（取 1）。
  12. 轴向固定两种方式要能画出来：双支点单向固定、一端固定一端游动。
  13. 装拆工具必须卡内圈，卡外圈是错误结构。
  14. 油润滑与脂润滑之间必须隔离，否则脂被油冲走、油被脂污染。
  15. 轴系结构改错题按清单逐条查，别凭感觉。

八、【以教材为准】待核对清单

以下条目因录音环境噪声、口述省略或与教材符号习惯不一致，建议对照教材核对：

  1. 类型代号的记忆顺序。课堂上口述为”调心球的一、圆柱滚子的十三、推力的五、深沟球的六、角接触的 7、圆锥的 N”，其中”十三”与”N”的对应关系听录不清（圆柱滚子轴承标准代号为 N）。正文按标准代号表给出，以教材为准。
  2. 接触角 C 的角度。课堂口述中出现”25 度”（对应 AC）与”C 45 度”两处表述，标准规定 C = 15°、AC = 25°、B = 40°。正文按标准值，以教材为准。
  3. 判断系数 $e$ 的具体数值。例题中口述 $e = 0.68$（AC 档），不同教材/手册的表格数值可能略有差异，请以所用教材的表格为准。
  4. 例题载荷数值。录音中径向载荷口述为”1000 N”（另一处似为”1100”），正文取 $F_r = 1000$ N、$F_a = 600$ N，比值 0.6 与课堂口述的”0.6”一致。
  5. 角接触球轴承 $X$ 的取值。正文按常见手册取 $X = 0.41$（$F_a/F_r > e$ 时），具体数值以教材表格为准。
  6. 圆锥滚子轴承综合例题的数值。录音中出现 30206、$C_r = 43$ kN、$e = 0.37$、$Y = 1.6$、$S_1 = 1250$ N、$S_2 = 1330$ N、$F_A = 350$ N 等，均为听录，请以教材例题为准。
  7. 深沟球轴承选型例题的型号。录音中出现 6212、6312、736C 等型号与 $C_{0r} = 20.3$ kN、$C_r = 32.3$ kN 的参数，听录可能有误，以教材/手册为准。
  8. 温度系数 $f_T$ 的分档。正文按”低于 100 °C 取 1”表述，具体分档表以教材为准。
  9. 载荷系数 $f_P$ 的取值范围。正文按”轻微冲击或无冲击取 1～1.2”表述，具体分档以教材为准。
  10. 教材页码（录音中提到 143 页、145 页、243 页等）为听录，正文未引用。
  11. 轴向固定方式的分类名称。正文按”双支点单向固定”与”一端固定一端游动”两大类表述，部分教材还有”两端固定”一类，以教材为准。
  12. 轴系结构改错的具体图例。课堂是按图纸逐处讲解，正文归纳为四个高频错误点，具体图例请对照教材。

十、复习自测参考答案

1. 调心球 1、调心滚子 2、圆锥滚子 3、推力球 5、深沟球 6、角接触球 7、圆柱滚子 N。

2. C = 15°、AC = 25°、B = 40°。

3. 由前置代号 + 基本代号 + 后置代号三部分组成，其中基本代号又包含类型代号、尺寸系列代号、内径代号。内径代号 00 → 10 mm、01 → 12 mm、02 → 15 mm、03 → 17 mm。

4. $45/5 = 9$，内径代号为 09。

5. 选调心球轴承。两者都能调心，但球轴承是点接触、摩擦小、极限转速高；调心滚子轴承是线接触、承载能力大但极限转速低。转速较高时应优先保证转速能力。

6. $10^6$ 转（不是”转”）。

7. $P = X F_r + Y F_a$。当 $F_a/F_r \le e$ 时取 **$X = 1$、$Y = 0$**，此时 $P = F_r$。

8. $F_a/F_r = 900/2000 = 0.45 < e = 0.68$，故 $X = 1$、$Y = 0$，$P = 1 \times 2000 + 0 \times 900 = 2000$ N。

9. 径向载荷 $F_r$ 通过内圈作用在滚动体上，滚动体产生反力；因为轴承有接触角，反力沿接触线方向，可分解出轴向分量；各滚动体轴向分量之和即为内部轴向力 $S$。产生前提是必须有接触角。

10. 因为深沟球轴承的接触角为零，滚动体只承受径向反力，没有轴向分量，所以各滚动体的轴向分量之和为零，不产生内部轴向力。

11. 角接触球轴承：$S = e F_r$；圆锥滚子轴承：$S = \frac{F_r}{2Y}$（$e$、$Y$ 查表）。

12. 正装（面对面）：两端接触角力线向内收敛，力线交点落在两轴承之间；反装（背对背）：力线向外张开，交点落在两轴承之外。判断方法是画出接触角方向、延长力线与轴线相交，看交点位置。

13. 步骤：① 求两端内部轴向力 $S_1$、$S_2$ 并明确方向（都指向轴承外侧）；② 比较两端 $S$ 与外部轴向力 $F_A$ 的合力，判断整个轴系的运动趋势朝哪一侧；③ 趋势所指向的一端为压紧端，另一端为放松端。压紧端 $F_a = S’ + F_A$，放松端 $F_a = S$。

14. $L_{10} = (\frac{C}{P})^{\varepsilon}$。**球轴承 $\varepsilon = 3$，滚子轴承 $\varepsilon = 10/3$**。

15. 因为滚子是线接触，接触面积大、承载能力强，寿命对载荷变化的敏感度较低，所以寿命指数更大。

16. $L_{10h} = \frac{10^6}{60n}(\frac{C}{P})^{\varepsilon}$。

17. 先算载荷比：$C/P = 32/8 = 4$；再算 $4^3 = 64$；代入：

$L_{10h} = \frac{10^6}{60 \times 1500} \times 64 = \frac{10^6}{90000} \times 64 \approx 11.11 \times 64 \approx 711$ h

即约 711 小时。

18. ① 双支点单向固定：两端各限制一个方向的轴向移动，适用于跨距较小、温升不高的场合；② 一端固定一端游动：一端双向固定、另一端可沿轴向游动，适用于跨距较大、有热伸长的场合。

19. 必须在齿轮与轴承之间加隔离套（挡油环）。因为齿轮用油润滑、轴承用脂润滑，两者不能相互接触——油会把脂冲走，脂会污染油，都会破坏润滑效果。

20. 受力点必须落在要拆的那个套圈上——拆内圈就卡内圈。如果结构上只能卡到外圈，说明轴肩/台阶设计有误：力会经外圈→滚动体→内圈传递，可能把滚动体压坏或挤裂，属于结构设计错误，应修改轴肩结构使工具能卡到内圈。
