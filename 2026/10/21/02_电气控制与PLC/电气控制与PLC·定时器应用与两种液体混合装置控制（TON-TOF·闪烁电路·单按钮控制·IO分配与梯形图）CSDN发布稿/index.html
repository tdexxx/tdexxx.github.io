定时器应用与两种液体混合装置控制

电气控制与PLC：定时器应用与两种液体混合装置控制（TON/TOF · 闪烁电路 · 单按钮控制 · I/O 分配与梯形图）

本篇为《电气控制与PLC》课堂整理。这节课的主线是**从”继电器逻辑”过渡到”程序逻辑”**，然后用三个由浅入深的实例把定时器用透：

  1. 定时器的两种基本用法——接通延时 TON 与关断延时 TOF，两者的动作时刻完全不同，这是最容易记混的地方；
  2. 闪烁电路——用两个定时器做出”亮 3 秒、灭 2 秒”的循环；
  3. 单按钮控制（二分频电路）——为了省一个输入点，用一个按钮实现启停切换；
  4. 综合实例：两种液体混合装置——从控制要求 → I/O 分配表 → 硬件接线 → 梯形图，完整走一遍小型控制系统的设计流程。

文中公式统一采用行内数学写法；课堂口述与教材符号不一致、或录音模糊处，均标注【以教材为准】。

一、这节课讲了什么

第一段（约 2:00–2:02）从继电器逻辑讲到 PLC。
老师先做了一个对照：机械式继电器靠触点通断实现逻辑，触点是”物理的”；PLC 内部是”逻辑触点”，用程序里的软元件实现同样的功能。所以继电器-接触器电路里的自锁、互锁、正反转，在 PLC 里都能一一对应地”翻译”过来——只是把”接线”变成了”写程序”。老师用电动机正反转做了示范：SB1 正转、SB2 反转，KM1 与 KM2、KM3 之间必须互锁。

第二段（约 2:02–2:15）定时器的两种用法。
这是本讲的技术核心。老师反复强调：

  • TON（接通延时）：输入闭合后要等设定的时间，输出才动作；
  • TOF（关断延时）：输入闭合时立即动作，输入断开后再延时才复位。

一句话概括：**TON 延时的是”来”，TOF 延时的是”走”**。

第三段（约 2:03–2:07）闪烁电路。
用两个定时器串起来，让指示灯”亮 3 秒、灭 2 秒”地循环。老师现场演示了时序：闭合开关 → 定时器 1 计时 → 时间到 → 灯亮并启动定时器 2 → 定时器 2 时间到 → 灯灭并复位定时器 1 → 循环。

第四段（约 2:50–3:00）单按钮控制。
为了节省一个输入点，用一个按钮实现”按一下启动、再按一下停止”。这个电路又叫二分频电路——因为输出信号的频率正好是输入按钮信号频率的一半。老师讲了两种写法（教材上的 A、B 两种电路），核心都是靠中间继电器 + 上升沿实现状态翻转。

第五段（约 3:00–3:22）综合实例：两种液体混合装置。
这是一个完整的小型控制系统设计题：容器里有 A、B 两种液体，靠三个液位传感器（高位 L1、中位 L2、低位 L3）检测液面，要求按”加 A 液 → 加 B 液 → 搅拌 20 秒 → 放液 → 再延时 5 秒 → 循环”的顺序自动运行。老师带着做了I/O 分配表、硬件接线（QF 断路器、KM 接触器、PLC 电源）和梯形图。

二、核心结论速览

  1. 继电器-接触器电路与 PLC 程序是一一对应的：物理触点 ↔ 逻辑触点，接线 ↔ 编程。
  2. 自锁、互锁、正反转这些基本环节，在 PLC 里用软元件照样实现，思路完全一样。
  3. 正反转必须有互锁：KM1（正转）与 KM2（反转）的常闭触点要串在对方的线圈回路里，防止同时吸合造成短路。
  4. PLC 硬件接线要先分清输入与输出：按钮、限位开关、传感器接输入（I 区）；接触器线圈、指示灯、电磁阀接输出（Q 区）。
  5. 电源要单独考虑：PLC 本体供电、输入回路供电、输出负载供电可能是不同的电源，接线时要看清。
  6. 断路器 QF 用于主回路与各分支的短路/过载保护，不同回路用不同编号（QF1、QF2、QF3）。
  7. TON = 接通延时：输入闭合后延时，延时到输出才动作。
  8. TOF = 关断延时：输入闭合时立即动作，输入断开后延时才复位。
  9. 一句话记法：**TON 延时”来”，TOF 延时”走”**。
  10. TON 的输入端断开时，输出立即复位、当前值清零；TOF 的输入端闭合时，输出立即置位、当前值清零。
  11. 闪烁电路 = 两个定时器 + 一个自复位：定时器 1 控制”灭”的时间，定时器 2 控制”亮”的时间，交替循环。
  12. **闪烁电路的本质是”振荡”**：输出状态不断翻转，翻转周期 = 两个定时时间之和。
  13. 单按钮控制（二分频电路） 的目的：节省一个输入点，用一个按钮完成启停切换。
  14. 叫”二分频”的原因：输出信号的频率是按钮信号频率的一半——按两次才完成一个完整周期。
  15. **单按钮控制的关键是”上升沿”**：只在按钮按下的那一瞬间产生一个扫描周期的脉冲，用这个脉冲去翻转状态。
  16. 单按钮控制的两种写法（教材上的电路 A 与电路 B）思路一致，区别在于用中间继电器还是用输出自身来做状态记忆。
  17. 调试单按钮电路要盯住”复位”那一步：按下第二次时，必须把第一次置位的中间继电器复位，否则状态翻不过来。
  18. 设计一个控制系统的标准流程：控制要求 → I/O 分配表 → 硬件接线图 → 梯形图 → 调试。
  19. I/O 分配表是设计与编程的桥梁：把每个按钮、传感器、执行元件对应到一个具体的 I 或 Q 地址，后面写程序才不会乱。
  20. 地址分配要有规律：输入按”启动 → 停止 → 各传感器”的顺序排，输出按”动作先后”排，便于阅读与查错。
  21. **液位控制的核心是”顺序 + 互锁”**：每个液位信号触发下一个动作，同时要保证同一时刻不会有两个进液阀同时打开。
  22. 定时器可以级联：前一个定时器的完成位可以作为后一个的启动条件，从而实现多段时间控制。
  23. 液体混合装置的完整流程：启动 → 加 A 至中位 → 加 B 至高位 → 搅拌 20 秒 → 放液至下限 → 再延时 5 秒 → 关闭并循环。
  24. “再延时 5 秒”的作用：液面到下限时容器里还有残液，延时 5 秒让残液排空，避免下次配比不准。
  25. 梯形图要按”从左到右、从上到下”的顺序扫描，写程序时要想清楚每个扫描周期里各元件的状态变化。
  26. 自锁回路是”持续运行”的基础：启动按钮是瞬动的，必须靠输出自身的常开触点并联在启动按钮上，才能松手后继续运行。
  27. 停止信号必须用常闭触点串在回路里（或在程序里用常闭逻辑），这样断线时也能停机，符合安全要求。
  28. 程序调试的常用手段：看状态表/监视表、看定时器当前值、单步或分段运行。
  29. 经验设计法的局限：它依赖”典型基本环节”的积累，复杂系统容易出现逻辑漏洞，需要反复修改完善。
  30. 顺序控制更适合用步进/顺控指令，但当题目规模不大时，用基本逻辑 + 定时器也能实现。

三、知识结构树

四、知识点详解

4.1 继电器-接触器控制与 PLC 控制的对应关系

继电器-接触器电路 PLC 程序
物理触点（常开/常闭） 软元件触点（常开/常闭）
线圈（KM、KA） 输出线圈（Q）、中间继电器（M）
时间继电器（KT） 定时器（TON/TOF）
导线连接 程序连线（梯形图）
自锁（自身常开触点并联启动按钮） 同样的自锁逻辑
互锁（对方常闭触点串入线圈回路） 同样的互锁逻辑

结论：继电器电路会画，PLC 程序就会写——**只是把”接线”换成”编程”**。老师说”机械的辅助也可以理解成一个逻辑的辅助”，说的就是这个对应关系。

4.2 PLC 硬件接线：电动机正反转

（1）主回路

  • **QF1**：总电源断路器，做短路与过载保护；
  • **KM1**：正转接触器；
  • **KM2、KM3**：反转接触器（两相调换实现反转）；
  • **FR**：热继电器，做过载保护。

（2）控制回路

  • SB1：正转启动按钮 → 接输入 I0.0；
  • SB2：反转启动按钮 → 接输入 I0.1；
  • SB3：停止按钮 → 接输入 I0.2（【以教材为准】，编号按实际分配）。

（3）互锁

正反转必须互锁：KM1 的常闭触点串在 KM2 的线圈回路里，KM2 的常闭触点串在 KM1 的线圈回路里。这样即使误操作同时按下两个启动按钮，也不会造成主回路短路。

为什么必须互锁：正转与反转是两相调换，如果两个接触器同时吸合，相当于相间短路，会烧毁接触器甚至引发事故。

（4）输出侧

接触器线圈、指示灯接 Q 区输出。注意：PLC 输出点的容量有限，驱动接触器线圈时要注意电压等级与电流是否匹配。

4.3 定时器：TON 与 TOF

这是本讲最重要的一组概念，两者动作时刻完全相反。

4.3.1 接通延时 TON

动作逻辑：

  1. 输入条件闭合（变为 ON）；
  2. 定时器开始计时，当前值从 0 递增；
  3. 当前值达到设定值时，定时器输出位置位（动作）；
  4. 输入条件断开时，输出位立即复位，当前值清零。

特点：延时发生在”来”的时候——要等够时间才动作。

典型应用：启动后延时若干秒再动作（如星三角启动的切换、搅拌时间的控制）。

4.3.2 关断延时 TOF

动作逻辑：

  1. 输入条件闭合时，输出位立即置位（动作），当前值清零；
  2. 输入条件断开时，定时器开始计时；
  3. 当前值达到设定值时，输出位复位（释放）。

特点：延时发生在”走”的时候——先动作，断电后再拖一段时间才复位。

典型应用：停机后风扇继续运转一段时间（冷却）、关断后延时关闭某设备。

4.3.3 两者的区别（务必记牢）

对比项 TON（接通延时） TOF（关断延时）
输入闭合时 开始计时，延时后动作 立即动作
输入断开时 立即复位 开始计时，延时后复位
延时发生在 动作之前 动作之后
记忆口诀 延时”来” 延时”走”

老师课堂上的验证方式：设定 9 秒的 TON，闭合开关后要等 9 秒输出才动作，灯才亮；而设定 7 秒的 TOF，闭合时灯立刻亮，断开后还要再亮 7 秒才灭。用”看灯什么时候亮、什么时候灭”就能把两者区分开。

4.4 闪烁电路（用两个定时器实现）

目标：让指示灯按”亮 3 秒、灭 2 秒”的节奏循环闪烁。

实现思路：用两个定时器交替，一个管”亮”的时间，一个管”灭”的时间，互相触发、互为复位。

时序分析（设 T1 控制灭的时间 2 秒，T2 控制亮的时间 3 秒）：

时刻 状态
0 s 开关闭合，灯灭，T1 开始计时
2 s T1 到，灯亮，T2 开始计时
5 s T2 到，灯灭，同时复位 T1
5 s 起 T1 重新计时，进入下一循环

关键点：

  1. 两个定时器互为”启动/复位”条件，形成闭环振荡；
  2. 闪烁周期 = 两个定时时间之和（本例 2 + 3 = 5 秒）；
  3. 占空比由两个时间之比决定（本例亮 3 秒、灭 2 秒，占空比 60%）；
  4. 若只需”亮”而不需要精确占空比，也可以用系统时钟脉冲（如 1 Hz 特殊继电器）实现简单闪烁。

为什么用两个定时器而不是一个：一个定时器只能产生”一次”延时，要形成”循环”必须有”复位自己”的环节，而这个复位要靠另一个定时器来完成。

4.5 单按钮控制（二分频电路）

4.5.1 为什么要做这个电路

目的：节省一个输入点。

正常情况下启停需要两个按钮（启动 + 停止）。如果 PLC 输入点紧张，可以用一个按钮实现”按一下启动、再按一下停止”，这叫单按钮控制。

4.5.2 为什么叫”二分频”

按钮每按一次产生一个脉冲。而输出（设备运行状态）要按两次才完成一个”开—关”的完整周期。所以输出信号的频率是按钮信号频率的一半——这就是”二分频“名称的由来。

4.5.3 实现要点

**核心是”上升沿”**：

  1. 只在按钮按下的那一瞬间产生一个只持续一个扫描周期的脉冲（上升沿）；
  2. 用这个脉冲去翻转状态（置位或复位）；
  3. 第二次按下时，脉冲把第一次置位的中间继电器复位，于是输出关闭。

教材上的两种写法：

写法 状态记忆方式
电路 A 用中间继电器（M）记忆当前状态
电路 B 用输出自身的常开/常闭触点参与翻转

两者思路一致，区别只在”状态存在哪里”。老师说两种都是对的。

4.5.4 调试时的注意点

按下第二次时，必须确认第一次置位的中间继电器被复位。老师现场就专门问了这个问题：”为什么这个中间继电器变成了 0？”——答案是按下的那个脉冲同时触发了复位。这一步没处理好，按钮就会”只能开不能关”。

4.6 综合实例：两种液体混合装置控制系统

4.6.1 控制要求

容器内有 A、B 两种液体，需按比例混合后排出。用三个液位传感器检测液面：

传感器 位置 作用
S1（L1） 高位 检测 B 液加满
S2（L2） 中位 检测 A 液加到位
S3（L3） 低位 检测放液到底

工作流程：

  1. 按启动按钮 SB1 → 打开 A 液阀，注入 A 液；
  2. 液面升到 中位 L2 → 关闭 A 液阀，打开 B 液阀；
  3. 液面升到 高位 L1 → 关闭 B 液阀，启动搅拌机并定时 20 秒；
  4. 20 秒到 → 停止搅拌，打开放液阀；
  5. 液面降到 低位 L3 → 继续放液并定时 5 秒；
  6. 5 秒到 → 关闭放液阀，一次循环结束（可回到步骤 1 继续）；
  7. 任何时候按停止按钮 SB2 → 全部输出停止，回到初始状态。

“再延时 5 秒”的意义：液面刚到下限时，容器底部与管路里还有残液。延时 5 秒让残液排空，否则下一次配比会偏多，混合比例就不准了。

4.6.2 I/O 分配表

类别 元件 说明 地址
输入 SB1 启动按钮（常开） I0.0
输入 SB2 停止按钮（常闭） I0.1
输入 S1 高位液位传感器 I0.2
输入 S2 中位液位传感器 I0.3
输入 S3 低位液位传感器 I0.4
输出 YV1 A 液进液阀 Q0.0
输出 YV2 B 液进液阀 Q0.1
输出 M1 搅拌电动机 Q0.2
输出 YV3 放液阀 Q0.3

地址编号以实际分配为准，本表按”启动 → 停止 → 各传感器”与”按动作先后”的规律编排，便于阅读。【以教材为准】

4.6.3 硬件接线

主回路与保护：

  • **QF1**：总电源断路器；
  • **QF2**：PLC 电源回路断路器；
  • **QF3**：输出负载回路断路器；
  • **KM**：搅拌电动机接触器（若电动机功率较大，经接触器驱动）。

电源：

  • PLC 本体供电（交流或直流，按机型）；
  • 输入回路供电（按钮与传感器）；
  • 输出回路供电（电磁阀、接触器线圈）。

接线顺序：电源 → QF → PLC → 输入元件（按钮、传感器）→ 输出元件（电磁阀、接触器）→ 负载。

注意：输入与输出不能接反。按钮、传感器是”给信号”的，接 I 区；电磁阀、接触器是”被执行”的，接 Q 区。接反了轻则不动作，重则损坏模块。

4.6.4 梯形图分析

梯形图按”启动自锁 → 顺序控制 → 定时 → 复位“四段来组织：

（1）启动与自锁

I0.0（SB1）与 Q0.0（或一个中间继电器 M）的常开触点并联，形成自锁；I0.1（SB2）的常闭触点串联在回路中作为停止条件。

为什么要自锁：按钮是瞬动的，松手就断开。必须靠自身触点并联，才能”松手后继续运行”。

（2）顺序控制（液位链）

  • I0.0 启动 → 置位 Q0.0（A 液阀）；
  • I0.3（中位 S2）到 → 复位 Q0.0、置位 Q0.1（B 液阀）；
  • I0.2（高位 S1）到 → 复位 Q0.1、置位 Q0.2（搅拌机）并启动定时器 T1（20 秒）；
  • T1 到 → 复位 Q0.2、置位 Q0.3（放液阀）；
  • I0.4（低位 S3）到 → 启动定时器 T2（5 秒）；
  • T2 到 → 复位 Q0.3，循环结束。

（3）互锁

A 液阀与 B 液阀之间要互锁（同一时刻只能开一个），放液阀与进液阀之间也应互锁（放液时不进液）。

（4）停止与复位

I0.1（SB2）动作时，复位所有输出与定时器，系统回到初始状态。

老师的提醒：这类程序”看起来逻辑很清楚，实际写的时候很容易漏掉某一步的复位”。建议先画时序图（横轴时间、纵轴各元件状态），把每一步的”谁开谁关”标清楚，再照着写梯形图。

五、例题与解题方法汇总

题型 1：把继电器-接触器电路改写成 PLC 梯形图

解题步骤：

  1. 列出原电路的输入元件（按钮、限位、传感器）与输出元件（接触器、电磁阀、指示灯）；
  2. 做 I/O 分配表；
  3. 逐个回路”翻译”：串联 → 与逻辑（触点串联），并联 → 或逻辑（触点并联）；
  4. 自锁：输出自身常开触点并联在启动条件上；
  5. 互锁：对方常闭触点串入本回路；
  6. 检查是否有遗漏的复位条件。

题型 2：用定时器实现延时动作

判断用哪种定时器：

要求 用哪个
启动后等一段时间才动作 TON
停机后继续运行一段时间才停 TOF
循环通断（闪烁） 两个定时器交替

易错点：把 TON 和 TOF 的动作时刻记反——记住”TON 延时来，TOF 延时走“。

题型 3：设计闪烁电路

解题步骤：

  1. 确定”亮”与”灭”的时间；
  2. 定时器 1 控制”灭”的时长，定时器 2 控制”亮”的时长；
  3. 定时器 1 的完成位 → 点亮输出 + 启动定时器 2；
  4. 定时器 2 的完成位 → 熄灭输出 + 复位定时器 1；
  5. 校验：周期 = 两时间之和，占空比 = 亮时间 / 周期。

题型 4：单按钮启停（二分频）

解题步骤：

  1. 取按钮的上升沿，得到一个扫描周期的脉冲；
  2. 用这个脉冲去翻转状态（未运行则置位，运行中则复位）；
  3. 用中间继电器记忆当前状态；
  4. 调试重点：确认第二次按下时第一次的置位被复位。

题型 5：小型顺序控制系统设计（如液体混合装置）

标准流程：

  1. 写控制要求：按时间顺序列出每一步的动作与转换条件；
  2. 做 I/O 分配表：输入、输出各占多少点，地址怎么排；
  3. 画时序图：横轴时间，纵轴各元件状态，把”谁开谁关”标清楚；
  4. 画硬件接线图：电源、QF、KM、输入元件、输出负载；
  5. 写梯形图：自锁段 → 顺序段 → 定时段 → 复位段；
  6. 加互锁与保护：进液阀之间互锁、停止按钮全局复位；
  7. 调试：分段运行，用状态表监视各元件与定时器当前值。

七、课堂强调与复习重点

  1. TON 与 TOF 的动作时刻是反的——这是本讲第一易错点，务必用”看灯什么时候亮、什么时候灭”来验证。
  2. 正反转必须互锁，否则相间短路。
  3. 自锁靠输出自身的常开触点并联，不能只靠按钮。
  4. 停止信号要串常闭，符合”断线即停机”的安全原则。
  5. 闪烁电路要两个定时器，一个定时器做不出循环。
  6. 闪烁周期 = 两个定时时间之和，占空比 = 亮时间 / 周期。
  7. 单按钮控制的关键是上升沿，且第二次按下必须复位第一次的置位。
  8. “二分频”这个名字来自输出频率是输入的一半。
  9. I/O 分配表是设计与编程的桥梁，先做表再写程序。
  10. 输入接 I 区、输出接 Q 区，不能接反。
  11. 电源要分三路确认：PLC 本体、输入回路、输出回路。
  12. 写顺序控制程序前先画时序图，能避免漏掉复位。
  13. 互锁不只用在正反转：进液阀之间、进液与放液之间也要互锁。
  14. “再延时 5 秒”是为了排空残液，这类”看似多余”的步骤往往是保证工艺精度的关键。
  15. 经验设计法依赖典型环节的积累，复杂系统容易有漏洞，要反复调试完善。

十、复习自测参考答案

1. ① 物理触点 ↔ 逻辑触点；② 线圈（KM/KA）↔ 输出线圈（Q）/中间继电器（M）；③ 时间继电器（KT）↔ 定时器（TON/TOF）；④ 导线连接 ↔ 梯形图连线；⑤ 自锁、互锁等基本环节一一对应。

2. 因为正转与反转是两相调换，若两个接触器同时吸合，相当于相间短路，会烧毁接触器甚至引发事故。实现方式：把 KM1 的常闭触点串在 KM2 线圈回路里，把 KM2 的常闭触点串在 KM1 线圈回路里，形成相互封锁。

3. 输入元件接 I 区，例如按钮、限位开关、液位传感器；输出元件接 Q 区，例如接触器线圈、电磁阀、指示灯。

4. 自锁是把输出自身的常开触点并联在启动条件上。因为按钮是瞬动的（松手即断开），必须靠自锁触点维持回路导通，设备才能持续运行。

5. 因为常闭触点在正常情况下是闭合的，一旦线路断线或按钮损坏，回路就断开、设备停机——符合”故障安全“原则。若用常开，断线时反而无法停机。

6. 控制要求 → I/O 分配表 → 硬件接线图 → 梯形图 → 调试（复杂系统还应先画时序图）。

7. 输入闭合 → 开始计时、当前值递增 → 当前值达到设定值时输出置位（动作）→ 输入断开时输出立即复位、当前值清零。延时发生在动作之前。

8. 输入闭合时输出立即置位（动作）、当前值清零 → 输入断开 → 开始计时 → 当前值达到设定值时输出复位。延时发生在动作之后。

9. TON **延时”来”**（闭合后延时动作）；TOF **延时”走”**（断开后延时复位）。两者的延时时刻正好相反。

10. 用 TON（接通延时）——启动后等 10 秒再动作。

11. 用 TOF（关断延时）——断开后继续运行 30 秒再停。

12. 当前值是定时器已经累计的时间；设定值是要达到的目标时间。当前值达到设定值时定时器动作。

13. 因为一个定时器只能产生一次延时，无法自己复位形成循环。必须用两个定时器交替：一个的完成位启动另一个，另一个的完成位复位第一个，才能形成闭环振荡。

14. 周期 = 3 + 2 = 5 秒；占空比 = 3 / 5 = **60%**。

15. 目的是节省一个输入点——用一个按钮实现”按一下启动、再按一下停止”。叫”二分频”是因为输出（运行状态）的频率是按钮信号频率的一半：按两次才完成一个完整的”开—关”周期。

16. 上升沿把”按钮一直按着”变成”只持续一个扫描周期的脉冲“，这样才能做到”按一次翻转一次”，否则按住不放会连续翻转。调试时最容易出的问题是：第二次按下时没有把第一次置位的中间继电器复位，导致”只能开不能关”。

17. ① 按启动按钮 → 打开 A 液阀；② 液面到中位 L2 → 关 A 阀、开 B 阀；③ 液面到高位 L1 → 关 B 阀、启动搅拌并定时 20 秒；④ 20 秒到 → 停搅拌、开放液阀；⑤ 液面降到下限 L3 → 定时 5 秒；⑥ 5 秒到 → 关放液阀，循环结束。

18. 因为液面刚到下限时，容器底部与管路里还有残液。延时 5 秒让残液排空，否则下次配比时液量偏多，混合比例就不准了。

19.

输入 SB2 停止按钮 I0.1
输入 S1 高位传感器 I0.2
