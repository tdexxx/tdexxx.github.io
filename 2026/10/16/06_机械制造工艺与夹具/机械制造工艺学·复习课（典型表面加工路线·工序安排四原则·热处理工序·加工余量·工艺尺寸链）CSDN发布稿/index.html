机械制造工艺学复习课：加工路线、工序安排与工艺尺寸链

《机械制造工艺学》复习课：典型表面加工路线 · 工序安排四原则 · 热处理工序安排 · 加工余量 · 工艺尺寸链

本篇为《机械制造工艺学》课堂复习课整理。这节课把”工艺规程设计”这一大块内容从头到尾串了一遍，共五个主题：

  1. 典型表面的加工路线——外圆、孔、平面各有哪些成熟路线，怎么根据精度和材料选；
  2. 工艺顺序的安排原则——先基准后其他、先粗后精、先主后次、先面后孔；
  3. 热处理工序与辅助工序的安排——退火正火、时效、调质、淬火、渗碳、冷处理各放在哪一段；
  4. 加工余量——单边与双边、被包容面与包容面、最大最小余量与余量公差、三种确定方法；
  5. 工艺尺寸链——封闭环、组成环、增环减环的判定，极值法与概率法公式，以及测量基准不重合时的换算。

中间穿插了两个工序排序判断例题（加工中心方案、流水线方案）和一个45 号钢轴外圆加工路线设计例题。

文中公式统一采用行内数学写法；课堂口述与教材符号不一致、或录音模糊处，均标注【以教材为准】。

一、这节课讲了什么

这是一节复习课，把工艺规程设计的几大块内容串成一条线。

第一块（约 10:14–20:08）典型表面的加工路线。
老师反复强调的学习目标是：给你一个零件和它的精度要求，你能不能判断出该走哪一条路线。外圆表面有”车削路线”和”磨削路线”两大分支；孔有”钻-扩-铰”和”镗削”两大分支；平面有”铣”、”刨”、”拉”三条主线。选哪条，看公差等级、表面粗糙度、材料硬度三个条件。这里还专门讲了几种”特殊工艺”：金刚镗、浮动镗、珩磨、研磨。

第二块（约 20:08–23:40）工艺顺序的安排原则。
就四条，老师说”很简单的一个字”：先基准后其他、先粗后精、先主后次、先面后孔。难的不是记住，而是拿到一张图纸能套用——基准是哪一面？主次怎么分？面在哪里、孔在哪里？

第三块（约 23:40–28:30）热处理工序与辅助工序的安排。
热处理的安排位置取决于目的：为了改善切削性能（退火、正火）放在切削加工之前；为了消除内应力（时效）放在粗加工之前或之后；为了改善物理力学性能（调质）放在粗加工之后、精加工之前；为了提高硬度（淬火）放在半精加工之后；渗碳放在半精加工之后、精加工之前；高精密零件最后安排冷处理稳定尺寸；表面处理（镀铬等）放在工艺最后。辅助工序（检验、去毛刺、清洗、去磁）穿插在整个流程中。

第四块（约 28:30–32:10）工序集中与工序分散、加工阶段的划分。
工序集中的典型是加工中心——一次装夹完成多道工序；工序分散则设备工装简单、对操作者要求低。加工阶段划分为粗加工、半精加工、精加工、光整加工四段。

第五块（约 51:35–1:45:00）加工余量与工艺尺寸链。
这是全课的”计算”部分。加工余量讲清了工序余量 = 相邻两工序尺寸之差、被包容面与包容面的方向差异、单边与双边余量的关系、最大最小余量与余量公差（余量公差 = 上道工序尺寸公差 + 本道工序尺寸公差），以及计算法、查表法、经验法三种确定方法。工艺尺寸链部分讲了封闭环、组成环、增环、减环的判定与两组公式（极值法、概率法），最后用”两孔中心距用游标卡尺测量”的例子说明测量基准与设计基准不重合时要做尺寸换算。

二、核心结论速览

  1. 选加工路线的三个依据：公差等级、表面粗糙度、材料硬度（是否淬火）。老师原话：给你一个零件，你要能判断”走哪一条路”。
  2. 外圆表面两条主线：车削路线（粗车 → 半精车 → 精车）与磨削路线（粗车 → 半精车 → 粗磨 → 精磨）。
  3. 外圆表面要更高精度：在精磨之后再加研磨、超精加工、镜面磨削。
  4. 淬火钢、合金钢淬火后硬度高，车削路线走不通（刀具磨损快），必须走磨削路线。
  5. 孔的两条主线：毛坯无孔时走”钻 → 扩 → 铰“；毛坯已有孔（铸出、锻出）时走”粗镗 → 半精镗 → 精镗“。
  6. 孔要更高精度：粗镗 → 半精镗 → 精镗 → 浮动镗 / 金刚镗；或钻 → 扩 → 铰 → 珩磨。
  7. 难加工材料（淬火钢等）的孔：走”粗镗 → 半精镗 → 精磨”（磨孔）。
  8. 平面的三条主线：铣削路线（粗铣 → 半精铣 → 精铣）、刨削路线（粗刨 → 半精刨 → 精刨 → 宽刀精刨）、拉削路线（粗拉 → 精拉）。
  9. 拉削只适合大批量生产：设备昂贵、刀具专用，一年要生产几十万件才有经济性；小厂与教学环节少见。
  10. 平面有淬火要求时：在半精铣（或半精刨）之后加淬火或调质，之后改为磨削。
  11. 金刚镗：在精密镗床上用金刚石刀具（或硬质合金刀具）进行高速、小进给、小切深的精密切削，精度与表面质量都很高。
  12. 浮动镗：镗刀块不固定在镗杆上，可沿径向自由滑动，自动对中，因此加工精度高、效率高。
  13. 珩磨与研磨的区别：珩磨是珩磨头（带油石条）旋转并往复、工件不动；研磨是工件运动、研具不动。珩磨对机床精度要求不高，能提高尺寸精度与表面质量。
  14. 工艺顺序四原则：先基准后其他、先粗后精、先主后次、先面后孔。
  15. 先基准后其他：先把设计基准（或工艺基准）加工出来，再以它为基准加工其他表面；以精确的基准去加工其他面，其他面的精度才有保证。
  16. 先粗后精：粗加工放在一起、精加工放在一起，不要粗精交替。否则后一道的精加工变形会破坏前一道已保证的精度。
  17. 先主后次：先加工主要表面（重要面、基准面），后加工次要表面（沟槽、螺纹等）；主要面加工好后再精加工次要面，以保证相互位置关系。
  18. 先面后孔有两层含义：① 面与孔之间有垂直度要求，先加工面、再以面为基准加工孔；② 孔所在表面是毛坯面时，直接钻孔容易引偏、打刀，所以先把面加工出来。
  19. 加工中心上也要”先粗后精”：粗加工集中做完，再集中做精加工。老师特别指出”粗加工完就精加工同一个面”是错的——粗加工的变形会直接带入精加工。
  20. 划分加工阶段的意义：合理使用设备、便于安排热处理工序、及时发现毛坯缺陷、保证加工质量。
  21. 什么时候需要半精加工：粗加工余量大，或粗加工时工件刚性差产生变形，需要在精加工前修正。
  22. 热处理按”目的”定位置：改善切削性能（退火/正火）→ 切削加工之前；消除内应力（时效）→ 粗加工前或后；改善力学性能（调质）→ 粗加工之后精加工之前（有半精加工则放在半精加工之后）；提高硬度（淬火）→ 半精加工之后；渗碳 → 半精加工之后精加工之前；稳定尺寸（冷处理）→ 最后；表面处理 → 工艺最后。
  23. 表面处理放最后：镀铬之类的表面处理如果放在前面，后面的切削会把镀层切掉，”白处理了”。
  24. 辅助工序：检验穿插在整个流程中（工序间、车间间、流水段间都要检查）；去毛刺一般安排在切削加工之后；清洗一般安排在零件加工之后、装配之前。
  25. 工序集中 vs 工序分散：集中（如加工中心）可保证各表面相互位置精度、可用高效设备、省时间省面积便于管理；分散则设备工装简单、对操作者技术水平要求低。趋势是多品种小批量 → 加工中心。
  26. 工序余量 = 相邻两工序尺寸之差。
  27. 被包容面（外表面，如轴）：加工后尺寸变小，余量 = 加工前尺寸 − 加工后尺寸。
  28. 包容面（内表面，如孔）：加工后尺寸变大，余量 = 加工后尺寸 − 加工前尺寸（方向与轴相反）。
  29. 单边余量与双边余量：平面按单边计算；回转表面（外圆、内孔）按双边计算，双边余量是单边余量的 2 倍。
  30. 余量公差 = 上道工序尺寸公差 + 本道工序尺寸公差（即余量的最大值与最小值之差）。
  31. 加工余量的三种确定方法：计算法（精确但工作量大，实际少用）、查表法（查手册，生产上主要方法）、经验法（凭经验估，用于单件小批）。
  32. 注意手册上”基本余量”的定义：手册给出的多为基本余量（相当于最小余量），使用时一定要看清它的定义，不要与最大余量混用。
  33. 工序尺寸的确定方向：从最终加工工序（图纸上的设计尺寸）开始，依次往前加上各道工序的加工余量，逐道倒推。
  34. 入体原则：标注工序尺寸时，被包容面取最大极限尺寸（上偏差为零）；包容面取最小极限尺寸（下偏差为零）。
  35. 尺寸链：在零件加工或装配过程中，由相互联系的尺寸形成的封闭尺寸组。
  36. 封闭环：加工或装配过程中最终形成（间接得到）的那个环。判断关键——不是题目让你求的那个环，而是”最后才形成、间接得到”的那个环。
  37. 组成环：除封闭环以外的所有环，一般是加工过程中直接得到的尺寸。
  38. 增环：该环增大时，封闭环随之增大；减环：该环增大时，封闭环随之减小。
  39. 增环减环的两种判定方法：① 定义法（看变动方向）；② 箭头法（沿尺寸链画箭头，与封闭环箭头方向相反的是增环，相同的是减环）。环数多时用箭头法。
  40. 尺寸链基本公式（极值法）：封闭环公称尺寸 = 所有增环公称尺寸之和 − 所有减环公称尺寸之和。
  41. 封闭环上偏差 = 所有增环上偏差之和 − 所有减环下偏差之和。
  42. 封闭环下偏差 = 所有增环下偏差之和 − 所有减环上偏差之和。
  43. 极值法公差：封闭环公差 = 各组成环公差之和（最保守，可能过于苛刻）。
  44. 概率法公差：封闭环公差 = 各组成环公差平方和再开方，即 $T_0 = \sqrt{\sum T_i^2}$。比极值法合理。
  45. 测量基准与设计基准不重合时要换算：例如设计图给的是两孔中心距，而现场只能用游标卡尺量内孔边距，此时要建立尺寸链，算出”卡尺读数应在什么范围内”才能保证中心距合格。

三、知识结构树

四、知识点详解

4.1 典型表面的加工路线

老师说这部分的学习目标是：拿到一个零件、知道它的精度要求，要能判断该走哪一条路线。判断依据是三个：公差等级、表面粗糙度、材料硬度。

4.1.1 外圆表面的加工路线

路线 工序组成 大致能达到的精度
车削路线 粗车 → 半精车 → 精车 IT8～IT7，Ra 3.2～0.8
车削路线（精细车） 粗车 → 半精车 → 精车 → 精细车 用于有色金属，可接近磨削水平
磨削路线 粗车 → 半精车 → 粗磨 → 精磨 IT7～IT6，Ra 0.8～0.2
精密磨削路线 粗车 → 半精车 → 粗磨 → 精磨 → 精密磨削 / 镜面磨削 IT5 以上，Ra 0.1 以下
光整加工 在磨削之后加研磨、超精加工 进一步提高尺寸精度、降低粗糙度

关键判断：淬火钢、合金钢淬火后硬度很高，车削路线走不通——刀具磨损快、精度无法保证。老师原话是”它比较硬，很容易使我们的砂轮被磨损”，因此这类零件要走磨削路线。

老师特别提醒：同一条路线里”走到哪一处停”，取决于最终产品要求的公差等级和表面粗糙度——不是走到底，而是够用就停。

4.1.2 孔的加工路线

孔的路线选择，第一件事是看毛坯上有没有孔：

情形 路线
毛坯无孔 钻 → 扩 → 铰
毛坯有孔（铸出、锻出） 粗镗 → 半精镗 → 精镗
要求更高 粗镗 → 半精镗 → 精镗 → 浮动镗 / 金刚镗
小孔、要求高 钻 → 扩 → 铰 → 珩磨
难加工材料（淬火钢等） 粗镗 → 半精镗 → 精磨（磨孔）

为什么毛坯有孔就不从钻开始？ 因为铸出或锻出的孔余量不均匀，直接用钻头容易引偏，所以用镗削逐步修正。反之，毛坯上原本没有孔，就必须先钻出来。

最后一条”粗镗 → 半精镗 → 精磨”是专门为难加工材料准备的——因为材料硬，用镗刀切削困难，改用磨削。

4.1.3 平面的加工路线

路线 工序组成 说明
铣削路线 粗铣 → 半精铣 → 精铣 最常用
刨削路线 粗刨 → 半精刨 → 精刨 → 宽刀精刨 宽刀精刨可达到较高精度
拉削路线 粗拉 → 精拉 仅适合大批量生产
磨削路线 在半精加工之后加淬火/调质，再磨平面 有淬火要求时采用
精密路线 磨 → 研磨 / 刮研 高精度平面

为什么拉削少见？ 老师讲得很直接：

  • 拉削设备昂贵，小厂负担不起；
  • 教学环节也用不到；
  • 它主要用于大批量生产——一年要生产十几万、几十万件，为了生产效率才值得投这条工艺；
  • 但拉削对表面有凹槽、台阶面的零件效果非常好。

平面有淬火要求时怎么排？ 在半精铣或半精刨之后加一道淬火或调质，之后改走磨削。老师解释说：淬火或调质之后表面硬度提高，原来用的铣削、刨削就不合适了，所以要改用磨削。

4.1.4 几种特殊的孔加工与光整工艺

工艺 要点
金刚镗 在精密镗床上，用金刚石刀具（也可能是硬质合金刀具）进行高速、小进给、小切深的精密切削。有在普通车床上和在精密镗床上两种实现方式，两者能达到的精度基础不同
浮动镗 镗刀块不固定在镗杆上，可沿径向自由滑动，能自动调整、自动对中。因此加工精度高、表面粗糙度等级高，加工效率也高，质量与效率兼顾
珩磨 用珩磨头（上面装有油石条，均匀分布在圆周上）旋转并往复运动，靠机械或液压力使油石径向涨开压在孔壁上。加工时工件不动，只有珩磨头运动。对机床精度要求不高，能提高尺寸精度并获得很好的表面粗糙度
研磨 与珩磨原理类似，但运动状态相反——研磨时是工件运动、研具不动（相对珩磨是”工件不动、珩磨头运动”）。用于获得极高精度和极低的表面粗糙度

理解口诀：珩磨是”头动件不动”，研磨是”件动研具不动”。

4.2 工艺顺序的安排原则

老师说这部分”很简单的一个字”——四条原则：

原则 含义 理由
先基准后其他 先把设计基准（或工艺基准）加工出来，再以它为基准加工其他表面 基准越精确，其他表面的精度才越有保证
先粗后精 粗加工集中在一起、精加工集中在一起，不交替 粗加工的变形会破坏已保证的精加工精度
先主后次 先加工主要表面（重要面、基准面），后加工次要表面（沟槽、螺纹等） 保证主要面之间的相互位置关系
先面后孔 先加工平面，再加工孔 见下

先面后孔的两层含义（老师反复强调）：

  1. 面与孔之间有垂直度要求。在面上打孔，孔与面之间必然有位置要求，所以先把面加工好，再以这个精确的面为基准去加工孔；
  2. 孔所在的表面是毛坯面时，钻头下刀容易引偏、打刀，所以必须先把面加工出来再钻孔。

老师对”先粗后精”的补充说明（加工中心场景）：

加工中心上一次装夹可以完成很多工序，粗加工和精加工都可能在同一台设备上完成。这时更要注意把粗加工集中做完、再做精加工。如果”粗加工完 A 面就精加工 A 面，再粗加工 B 面、精加工 B 面”，B 面的精加工产生的切削力和夹紧力会造成变形，把 A 面已经保证的平行度等精度破坏掉。

老师的总结：四个原则”感觉好像很简单，不就是先粗加工还是精加工”，但难在拿到图纸能套用——需要一定的熟练度，”看多了、做多了自然可以”。

4.3 热处理工序与辅助工序的安排

4.3.1 热处理工序：按”目的”定位置

这是本节的核心逻辑——不要背位置，要背目的：

目的 热处理种类 安排位置
改善切削性能 退火、正火 切削加工之前
消除内应力 时效处理（自然时效、人工时效） 视内应力来源而定，一般在粗加工前或后
改善物理力学性能 调质 粗加工之后、精加工之前；有半精加工时放在半精加工之后
提高表面硬度 淬火 半精加工之后
提高表面耐磨性 渗碳 半精加工之后、精加工之前
稳定尺寸 冷处理 高精密零件放在最后
改善表面性能与美观 表面处理（镀铬等） 工艺最后

几条要点展开：

  • 消除内应力要分清来源。如果内应力是粗加工反复切削产生的，那时效就安排在粗加工之后；如果毛坯本身是铸造件或锻造件，来料时内应力就已经很大（老师举例”钢件、锻件”），那就要在切削加工之前先安排一道时效或退火来消除。
  • 渗碳的位置：如果渗碳放在精加工之后，那么”你再粗铣一下、把它铣掉了”，渗碳层就白做了。所以渗碳一般安排在半精加工之后、精加工之前（老师表述为”半精加工以后、精加工之前”）。
  • 冷处理：高精密零件在最后安排冷处理，目的是稳定零件的尺寸。
  • 表面处理（镀铬等）一定要放最后：如果放在前面，后面的切削会把镀层切掉，”你就不是白处理了”。

4.3.2 辅助工序的安排

辅助工序 安排位置
检验 穿插在整个流程中。零件加工完后、传递到下一道时要检查；不同车间、不同工段、不同流水段之间的传递都要检查
去毛刺 一般安排在切削加工之后（此时才有毛刺、飞边）
清洗 一般安排在零件加工之后、装配之前；研磨、珩磨等完成之后也要清洗
去磁 采用磁力夹紧（电磁吸盘）装夹后，要对工件去磁

4.4 工序集中与工序分散

对比项 工序集中 工序分散
含义 一个工序里包含很多工步 工序内容少、工序数量多
典型设备 加工中心 通用机床
优点 保证各表面相互位置精度；可采用高效设备；节省加工时间；减少支出；节省生产面积；便于管理 设备和工装简单；对操作者技术水平要求较低
缺点 设备复杂、投资大 工序多、设备多、占地面积大

趋势：随着市场需求变化，产品品种越来越多、批量越来越小，为了应对这种多品种小批量生产，越来越多地采用加工中心这类先进设备，工序集中的优势越来越明显。

4.5 加工阶段的划分

阶段 任务
粗加工 切除大部分加工余量
半精加工 达到一定精度，为精加工做准备
精加工 达到零件主要表面的精度和表面质量要求
光整加工（精密加工） 进一步提高尺寸精度、降低表面粗糙度，如研磨、珩磨、超精加工、抛光

什么时候需要半精加工？

  • 粗加工余量很大时；
  • 粗加工时工件刚性差、产生了变形，需要在精加工前修正一下——因为精加工的切削余量很小，如果带着粗加工的变形直接精加工，反而会造成较大误差。

划分加工阶段的意义：

  • 合理使用设备（粗加工用功率大、精度低的设备，精加工用精度高的设备）；
  • 便于安排热处理工序；
  • 及时发现毛坯缺陷（粗加工后就能暴露）；
  • 保证加工质量。

4.6 加工余量

4.6.1 工序余量的概念

工序余量 = 相邻两工序的尺寸之差，也就是某一工序从工件表面切去的金属层厚度。

老师强调：不要从定义去理解，直接从图形上去理解——在尺寸图上，工序余量就是”上一道工序尺寸线”与”本道工序尺寸线”之间那一段。

4.6.2 被包容面与包容面

这是最容易搞错的地方：

表面类型 加工后尺寸 余量表达式
被包容面（外表面，如轴） 变小 $Z = d_1 - d_2$
包容面（内表面，如孔） 变大 $Z = D_2 - D_1$

式中：$d_1$、$D_1$ 为上道工序的尺寸，$d_2$、$D_2$ 为本道工序的尺寸；$d$ 表示外表面尺寸（轴），$D$ 表示内表面尺寸（孔）。

直观理解：轴越车越细，所以余量是”加工前减加工后”；孔越镗越大，所以余量是”加工后减加工前”——方向恰好相反。

4.6.3 单边余量与双边余量

表面 余量按哪种算
平面 单边余量
回转表面（外圆、内孔） 双边余量，$Z_d = 2 \times Z_s$

式中 $Z_s$ 为单边余量、$Z_d$ 为双边余量。

因为回转表面是”两边同时被切掉一层”，所以双边余量是单边余量的 2 倍。做题时一定要看清题目给的是单边还是双边——双边要乘 2，单边不要乘。

4.6.4 最大余量、最小余量与余量公差

以被包容面（轴）为例，设上道工序尺寸为 $d_1$、本道工序尺寸为 $d_2$，对应的尺寸公差分别为 $T_1$、$T_2$：

  • $Z_{max} = d_{1max} - d_{2min}$
  • $Z_{min} = d_{1min} - d_{2max}$
  • $T_Z = Z_{max} - Z_{min} = T_1 + T_2$

即：余量公差 = 上道工序尺寸公差 + 本道工序尺寸公差。

包容面（孔）方向相反，用后道尺寸减前道尺寸，公式形式一致。

4.6.5 加工余量的确定方法

方法 说明 适用
计算法 根据影响余量的各项因素（表面粗糙度、表面缺陷层深度、空间偏差、装夹误差等）逐项计算 精确，但工作量大，实际很少用
查表法 查机械加工工艺手册确定 生产上主要方法，也是教学重点
经验法 凭经验估计（例如”半精加工留 1.5、精加工留 1.2 就行”） 单件小批、有经验的场合

老师特别提醒：手册上给出的余量，很多是**”基本余量”——它相当于最小余量。使用时一定要看清它的定义**，不要与最大余量混用。这是查手册时最容易出错的地方。

4.7 工序尺寸及其公差的确定

确定方向：从最终加工工序往前倒推。

  1. 最后一道工序的尺寸就是图纸上的设计尺寸（设计尺寸是已知的、不能改的）；
  2. 往前依次加上各道工序的加工余量，得到各道工序的公称尺寸；
  3. 各道工序的公差按该工序能达到的公差等级确定。

入体原则（标注工序尺寸时的约定）：

表面类型 工序尺寸取 偏差
被包容面（轴） 最大极限尺寸 上偏差为零
包容面（孔） 最小极限尺寸 下偏差为零

这样标注的好处是：加工时”尺寸往材料里面走”即为合格，工人操作与测量都方便。

4.8 工艺尺寸链

4.8.1 尺寸链的定义与分类

尺寸链：在零件加工或装配过程中，由相互联系的尺寸形成的封闭尺寸组。

按研究对象分：

类型 研究对象
设计尺寸链 零件设计图上尺寸之间的关系
工艺尺寸链 零件加工过程中，同一零件有关工序尺寸之间的关系
装配尺寸链 零件装配过程中，有关装配尺寸之间的关系

老师说：其实都是尺寸链，只是研究的对象不同——用在设计上就叫设计尺寸链，用在工艺上就叫工艺尺寸链。

4.8.2 环、封闭环、组成环

术语 定义
环 组成尺寸链的每一个尺寸
封闭环 在零件加工或装配过程中最终形成（间接得到）的那个环
组成环 尺寸链中除封闭环以外的所有环

最重要的判断技巧（老师反复强调）：封闭环不是”题目让你求的那个环”，而是”最终形成、间接得到“的那个环。很多同学做题时把”题目要求解的环”直接当成封闭环，这是错的——题目让你求的可能是组成环中的某一个。

举例说明：以 A 面为基准加工 C 面（尺寸 $A_1$），以 A 面为基准加工 B 面（尺寸 $A_2$），那么 B 面到 C 面的距离 $A_0$ 就是间接得到的——它没有直接加工，而是由 $A_1$ 和 $A_2$ 共同决定的。所以 $A_0$ 是封闭环，$A_1$、$A_2$ 是组成环。

  • 组成环之所以叫”组成”，是因为它们一般是加工时直接得到的尺寸——你编程序时就已经告诉了”A 到 C 多远”、”A 到 B 多远”；
  • 封闭环则是最后才能确定的。

4.8.3 增环与减环的判定

类型 定义 变化关系
增环 该环增大时，封闭环随之增大 同向变化
减环 该环增大时，封闭环随之减小 反向变化

两种判定方法：

  1. 定义法（看变动方向）：环数少时好用。想一下”这个环变大了，封闭环会变大还是变小”；
  2. 箭头法（画箭头）：环数多时好用。沿尺寸链依次画箭头，与封闭环箭头方向相反的为增环，与封闭环箭头方向相同的为减环。

易混点：两种方法的”同向/反向”说的不是同一件事——

  • 定义法看的是变动方向：同向变动的是增环；
  • 箭头法看的是箭头方向：箭头同向的是减环。

老师专门提醒”两个都有’同向’，不要搞混了”。

4.8.4 极值法基本计算公式

设增环用 $A^{+}$ 表示、减环用 $A^{-}$ 表示，封闭环为 $A_0$：

（1）公称尺寸

$A_0 = \sum A^{+} - \sum A^{-}$

即：封闭环公称尺寸 = 所有增环公称尺寸之和 − 所有减环公称尺寸之和。

（2）上偏差

$ES(A_0) = \sum ES(A^{+}) - \sum EI(A^{-})$

即：封闭环上偏差 = 所有增环上偏差之和 − 所有减环下偏差之和。

（3）下偏差

$EI(A_0) = \sum EI(A^{+}) - \sum ES(A^{-})$

即：封闭环下偏差 = 所有增环下偏差之和 − 所有减环上偏差之和。

注意：算上偏差时减环用下偏差，算下偏差时减环用上偏差——这是”减环要反号”的体现，也是公式最容易记混的地方。

（4）公差（极值法）

$T(A_0) = \sum T(A_i)$

即：封闭环公差 = 各组成环公差之和。极值法最保守，但有时会得出过于苛刻的结果。

4.8.5 概率法

概率法把”极限尺寸”换成”平均尺寸”、把”极限偏差”换成”中间偏差”，公差按平方和开方计算：

$T(A_0) = \sqrt{\sum T(A_i)^2}$

即：封闭环公差 = 各组成环公差的平方和再开方。

老师说：极值法”可能太极限了”，概率法是比较合适的方式。教学阶段两种方法都要了解、公式都要记住。

4.8.6 测量基准与设计基准不重合时的尺寸换算

老师用一个非常典型的例子说明为什么需要尺寸换算：

问题：图纸上标注的是两个孔的中心距（例如 127±0.07，【以教材为准】）。可是生产完以后，你怎么量这两个中心之间的距离？ 中心是虚的，找不到量点。

实际测量方式只有两种：

  1. 用游标卡尺卡内侧，量两个孔内边之间的距离；
  2. 用游标卡尺卡外侧，量两个孔外边之间的距离。

那卡尺读数应该落在什么范围，才能保证中心距合格？

这就是设计基准（中心距）与测量基准（孔边距）不重合的问题——必须建立尺寸链，把”中心距”作为封闭环，把”卡尺读到的孔边距”和”两个孔的半径”作为组成环，反算出卡尺读数的允许范围。

解法思路：中间那一段（孔边距）是可以直接量出来的（拿游标卡尺卡一下即可）；上下的两个孔半径也是可以量出来的。以”中心距”为封闭环，建立尺寸链换算即可。

五、例题与解题方法汇总

题型 1：给零件与精度要求，选加工路线

解题步骤：

  1. 看材料与热处理：是否淬火、硬度高不高？硬度高 → 走磨削类路线；
  2. 看表面类型：外圆、孔、还是平面？各走对应路线；
  3. 看毛坯状态（针对孔）：毛坯上有孔 → 从镗开始；无孔 → 从钻开始；
  4. 看公差等级与表面粗糙度要求：对照各路线能达到的精度，”够用就停”；
  5. 安排热处理：按目的插入相应位置；
  6. 安排辅助工序：检验、去毛刺、清洗等。

例题（45 号钢轴外圆加工路线）

  • 已知：45 号钢轴的外圆表面，表面粗糙度要求高（Ra 小于 0.16 量级，【以教材为准】）；
  • 45 号钢是中碳钢，通常不淬火，所以可以走车削 + 磨削路线；
  • 但精车达不到这么低的粗糙度，精磨（Ra 约 0.16～1.25）也差一点，需要再往后面走一步，用精密磨削 / 镜面磨削；
  • 加工路线：粗车 → 半精车 → 粗磨 → 精磨 → 精密磨削（镜面磨削）
  • 热处理安排：45 号钢常用的热处理是调质，目的是改善物理力学性能（不是消除内应力，也不是表面美观），所以应安排在粗加工之后、精加工之前；本例有半精加工，故放在半精加工之后；
  • 含热处理的完整路线：粗车 → 半精车 → 调质 → 粗磨 → 精磨 → 精密磨削（镜面磨削）

更严谨的做法：如果过程写完整，还要先车两个端面、打中心孔，调质之后因为会有一点变形，需要重新修正中心孔，再进入粗磨、精磨。如果来料长度不规格，还要先切段。

题型 2：判断工艺顺序是否合理

解题步骤：把四条原则一个一个套。

  1. 先粗后精：粗加工是否都集中在一起？有没有粗精交替？
  2. 先面后孔：面是否在孔之前加工？孔的定位面是否已经加工好？
  3. 先基准后其他：基准面（设计基准面）是否被安排在了最后？基准面放在最后是错的——基准面粗糙、精度低，以它为基准加工其他面，其他面的精度也差。
  4. 先主后次：主要面是否先加工？

典型错误（老师举的两个例子）：

  • 错误一：先加工两个孔，再加工两个端面 → 违反”先面后孔”；
  • 错误二：把基准面（底面）放到最后才精加工 → 违反”先基准后其他”；
  • 错误三：粗加工完一个面就精加工这个面，粗精交替 → 违反”先粗后精”，后道精加工的变形会破坏前道已保证的精度。

正确写法示例：粗铣底面 → 粗铣两个端面 → 粗镗半精镗两个孔 → 精铣底面 → 精铣顶面 → 精铣两个端面 → 精镗两个孔。

老师提醒：这类题”看上去好像没什么问题，实际上整个工序基本上都是错的”——必须一条一条原则去核对。

题型 3：计算加工余量

已知：某轴外圆，本道工序（精车）尺寸为 $d_2$，上道工序（粗车）尺寸为 $d_1$，各带上下偏差。

求：$Z_{max}$、$Z_{min}$、$T_Z$。

解题模板：

  1. 由尺寸与偏差算出 $d_{1max}$、$d_{1min}$、$d_{2max}$、$d_{2min}$；
  2. 判断是被包容面（轴）还是包容面（孔）；
  3. 被包容面：$Z_{max} = d_{1max} - d_{2min}$，$Z_{min} = d_{1min} - d_{2max}$；
  4. 校验：$T_Z = Z_{max} - Z_{min} = T_1 + T_2$。

数值示例（设上道尺寸 $d_1$ 为 50.5 上偏差 0、下偏差 −0.1；本道尺寸 $d_2$ 为 50 上偏差 0、下偏差 −0.02）：

  • $d_{1max} = 50.5$，$d_{1min} = 50.4$；$d_{2max} = 50$，$d_{2min} = 49.98$
  • $Z_{max} = 50.5 - 49.98 = 0.52$
  • $Z_{min} = 50.4 - 50 = 0.40$
  • $T_Z = 0.52 - 0.40 = 0.12 = 0.1 + 0.02$ ✓（与”余量公差 = 上道公差 + 本道公差”一致）

题型 4：尺寸链计算（正计算与反计算）

解题模板：

  1. 判断封闭环：找出”最终形成、间接得到”的那个环——不要直接把题目要求的环当封闭环；
  2. 判定增环、减环：环数少用定义法，环数多用箭头法；
  3. 代入公式：
    • 公称尺寸：$A_0 = \sum A^{+} - \sum A^{-}$
    • 上偏差：$ES(A_0) = \sum ES(A^{+}) - \sum EI(A^{-})$
    • 下偏差：$EI(A_0) = \sum EI(A^{+}) - \sum ES(A^{-})$
    • 公差（极值法）：$T(A_0) = \sum T(A_i)$
  4. 校验：$T(A_0)$ 应等于 $ES(A_0) - EI(A_0)$。

数值示例：已知 $A_1 = 60^{+0.05}{0}$、$A_2 = 20^{+0.03}{0}$，封闭环 $A_0 = A_1 - A_2$。

  • 公称尺寸：$A_0 = 60 - 20 = 40$
  • 上偏差：$ES(A_0) = +0.05 - 0 = +0.05$
  • 下偏差：$EI(A_0) = 0 - 0.03 = -0.03$
  • 公差校验：$T(A_0) = 0.05 - (-0.03) = 0.08 = 0.05 + 0.03$ ✓
  • 结果：$A_0 = 40^{+0.05}_{-0.03}$

七、课堂强调与复习重点

  1. **这一节是复习课，考的是”套用能力”**——四条工艺原则必须能对着图纸一条条套出来，而不是背下来。
  2. “封闭环”的判断是尺寸链部分最容易失分的地方：它不是题目要求解的环，而是”最终形成、间接得到”的环。
  3. 增环减环的两种判定方法要分清：定义法看变动方向（同向变动=增环），箭头法看箭头方向（同向箭头=减环）。老师专门提醒”两个都有’同向’，不要搞混”。
  4. 算上偏差时减环取下偏差、算下偏差时减环取上偏差——这是公式最容易记混的地方。
  5. 单边余量与双边余量：回转表面取双边，是单边的 2 倍；做题先看清题目给的是哪种。
  6. 被包容面与包容面的余量方向相反：轴是”前减后”，孔是”后减前”。
  7. 余量公差 = 上道公差 + 本道公差，这是校验计算是否正确的快捷方式。
  8. 查手册时注意”基本余量”的定义——手册给的常是最小余量，别当最大余量用。
  9. 热处理的安排位置由”目的”决定，不要死记：改善切削性能→前；改善力学性能→粗后精前；提高硬度→半精后；表面处理→最后。
  10. 表面处理（镀铬等）必须放最后，否则后面的切削会把镀层切掉。
  11. **加工中心上也要遵守”先粗后精”**，粗加工集中做、精加工集中做，不能粗精交替。
  12. 基准面不能放在最后加工——基准面精度低，以它为准加工其他面，其他面也差。
  13. “先面后孔”有两层含义：垂直度要求 + 毛坯面钻孔易引偏打刀。答题时两层都要写。
  14. 选路线的三要素：公差等级、表面粗糙度、材料硬度。
  15. 测量基准与设计基准不重合时要建尺寸链换算，游标卡尺量孔中心距就是典型例子。

十、复习自测参考答案

1. 三个依据：公差等级、表面粗糙度、材料硬度（是否淬火）。

2. ① 车削路线：粗车 → 半精车 → 精车；② 磨削路线：粗车 → 半精车 → 粗磨 → 精磨。（要更高精度时在精磨后加研磨、超精加工或镜面磨削。）

3. 因为淬火后硬度很高，车削时刀具磨损很快、切削困难，尺寸精度和表面质量都难以保证，所以必须改走磨削路线。

4. 毛坯无孔时从钻开始（钻 → 扩 → 铰），因为孔还不存在，必须先钻出来；毛坯有孔（铸出或锻出）时从粗镗开始（粗镗 → 半精镗 → 精镗），因为铸锻出来的孔余量不均匀、直接用钻头容易引偏，用镗削逐步修正更合理。

5. 工序余量 = 相邻两工序的尺寸之差，即某一工序从工件表面切去的金属层厚度。

6. 先基准后其他、先粗后精、先主后次、先面后孔。

7. ① 面与孔之间有垂直度要求，先加工面，再以这个精确的面为基准加工孔；② 孔所在的表面是毛坯面时，直接下钻容易引偏、打刀，所以必须先把面加工出来。

8. 因为加工中心上一次装夹可完成很多工序，如果粗精交替进行，后一道精加工产生的切削力和夹紧力会造成变形，破坏前一道已经保证的精度（例如 A 面已保证的平行度会因加工 B 面而超差）。所以要把粗加工集中做完，再集中做精加工。

9. ① 改善切削性能（退火、正火）→ 切削加工之前；② 消除内应力（时效）→ 视内应力来源，一般在粗加工前或后；③ 改善物理力学性能（调质）→ 粗加工之后、精加工之前（有半精加工则放在半精加工之后）；④ 提高表面硬度（淬火）→ 半精加工之后；⑤ 渗碳 → 半精加工之后、精加工之前；⑥ 改善表面性能与美观（表面处理）→ 工艺最后。（补充：高精密零件最后安排冷处理稳定尺寸。）

10. 因为表面处理是为了获得表面性能与外观，如果放在前面，后面的切削加工会把镀层切掉，”就白处理了”。所以必须放在整个工艺的最后。

11. 检验穿插在整个流程中（工序间、车间间、流水段之间的传递都要检查）；去毛刺一般安排在切削加工之后；清洗一般安排在零件加工之后、装配之前。

12. 工序集中（如加工中心）的优点：保证各表面相互位置精度、可采用高效设备、节省加工时间、减少支出、节省生产面积、便于管理；缺点是设备复杂、投资大。工序分散的优点是设备与工装简单、对操作者技术水平要求较低；缺点是工序多、设备多、占地大。发展趋势是工序集中——因为市场需求趋向多品种小批量，加工中心这类设备越来越有优势。

13. 四段：粗加工、半精加工、精加工、光整加工（精密加工）。需要安排半精加工的情况：① 粗加工余量很大；② 粗加工时工件刚性差、产生了变形，需要在精加工前修正（因为精加工余量小，带着变形直接精加工反而会造成较大误差）。

14. 被包容面（轴）加工后尺寸变小，$Z = d_1 - d_2$（加工前减加工后）；包容面（孔）加工后尺寸变大，$Z = D_2 - D_1$（加工后减加工前）。两者方向恰好相反。

15. 平面按单边余量计算；回转表面（外圆、内孔）按双边余量计算。两者关系：$Z_d = 2 \times Z_s$。

16. 三种：计算法（精确但工作量大，实际少用）、查表法（查手册，生产上主要方法）、经验法（凭经验估计，用于单件小批）。

17. 封闭环是在零件加工或装配过程中最终形成（间接得到）的那个环。判断关键：它不是题目要求解的那个环，而是”最后才形成、由其他尺寸间接决定”的那个环——题目要求解的可能是组成环中的某一个。

18. 增环：该环增大时，封闭环随之增大；减环：该环增大时，封闭环随之减小。两种判定方法：① 定义法（看变动方向，环数少时用）；② 箭头法（沿尺寸链画箭头，与封闭环箭头方向相反的为增环、相同的为减环，环数多时用）。

19. 设增环为 $A^{+}$、减环为 $A^{-}$：

  • 公称尺寸：$A_0 = \sum A^{+} - \sum A^{-}$
  • 上偏差：$ES(A_0) = \sum ES(A^{+}) - \sum EI(A^{-})$
  • 下偏差：$EI(A_0) = \sum EI(A^{+}) - \sum ES(A^{-})$
  • 公差：$T(A_0) = \sum T(A_i)$

20. 已知 $A_1 = 60^{+0.05}{0}$（增环）、$A_2 = 20^{+0.03}{0}$（减环）：

  • 公称尺寸：$A_0 = 60 - 20 = 40$
  • 上偏差：$ES(A_0) = ES(A_1) - EI(A_2) = +0.05 - 0 = +0.05$
  • 下偏差：$EI(A_0) = EI(A_1) - ES(A_2) = 0 - 0.03 = -0.03$
  • 结果：$A_0 = 40^{+0.05}_{-0.03}$
  • 公差校验：$T(A_0) = 0.05 - (-0.03) = 0.08$，而 $T(A_1) + T(A_2) = 0.05 + 0.03 = 0.08$，两者相等 ✓
