带传动与链传动课堂笔记

带传动与链传动机械设计课·课堂笔记

整理依据： 课堂逐字稿
说明： 已剔除无关闲聊与口语重复，修正语音转写错字，保留课堂讲解主线、公式、例题数据与课后要求。

一、带传动受力分析

1. 三个基本公式

有效拉力：

[
F=F_1-F_2
]

其中：

  • (F_1)：紧边拉力
  • (F_2)：松边拉力
  • (F)：有效拉力，也叫有效圆周力

初拉力关系：

[
F_1+F_2=2F_0
]

其中 (F_0) 为初拉力。

欧拉公式：

[
\frac{F_1}{F_2}=e^{f\alpha}
]

其中：

  • (f)：摩擦系数
  • (\alpha)：包角，必须用弧度制

课堂强调：欧拉公式描述的是临界打滑状态。正常工作时：

[
\frac{F_1}{F_2}<e^{f\alpha}
]

因为 (e^0=1)，且 (e^{0.1}>1)，所以比值大于 1，说明：

[
F_1>F_2
]

即紧边拉力大于松边拉力。

功率与圆周力：

[
P=Fv
]

工程单位中若 (P) 用 kW，(F) 用 N，(v) 用 m/s：

[
P=\frac{Fv}{1000}
]

2. 例题 6-3 解题思路

题目位置：教材 73 页 6-3。

课堂给出的已知条件包括：

  • 主动轮直径 (d_1=140\ \text{mm})
  • 转速 (n_1=1440\ \text{r/min})
  • 包角约 (150^\circ)
  • 当量摩擦系数
  • 初拉力等

解题思路：

  1. 把包角 (150^\circ) 换算为弧度：

[
\alpha=150^\circ\times\frac{\pi}{180^\circ}
]

  1. 联立两个方程：

[
\frac{F_1}{F_2}=e^{f\alpha}
]

[
F_1+F_2=2F_0
]

  1. 两个方程、两个未知数 (F_1,F_2)，可解出紧边和松边拉力。

  2. 求有效拉力：

[
F=F_1-F_2
]

  1. 代入功率公式：

[
P=\frac{Fv}{1000}
]

课堂提醒：欧拉公式在实际计算中如果题目需要，一般会给出；但基本印象必须要有。

二、带传动应力分析

带工作时受到三种应力。

1. 拉应力

[
\sigma_1=\frac{F_1}{A}
]

[
\sigma_2=\frac{F_2}{A}
]

其中 (A) 为带的横截面积。

紧边拉应力大于松边拉应力：

[
\sigma_1>\sigma_2
]

在带绕入主动轮小带轮时，拉应力由 (\sigma_1) 逐渐减小到 (\sigma_2)；绕入从动轮大带轮时，拉应力由 (\sigma_2) 逐渐增大到 (\sigma_1)。

2. 弯曲应力

弯曲应力发生在带与带轮接触的包角范围内。

[
\sigma_b\propto \frac{1}{D}
]

带轮直径 (D) 越小，弯曲应力越大。

因此：

[
\sigma_{b1}>\sigma_{b2}
]

即小带轮上的弯曲应力大于大带轮上的弯曲应力。

3. 离心应力

[
\sigma_c=\frac{qv^2}{A}
]

其中：

  • (q)：单位带长质量，单位 (\text{kg/m})
  • (v)：带速
  • (A)：横截面积

由于带速处处相等，且同一根带 (q)、(A) 确定，所以离心应力在整根带上处处相等。

4. 最大应力位置

最大应力发生在：

紧边绕入小带轮处

其值为：

[
\sigma_{\max}=\sigma_1+\sigma_{b1}+\sigma_c
]

课堂强调：

  • 拉应力最大在紧边；
  • 弯曲应力最大在小带轮；
  • 离心应力处处相等；
  • 三者叠加，最大应力在小带轮紧边绕入处。

5. 疲劳破坏

带上的任意一点随带循环运动一周，其应力不断变化。

长期工作后，应力循环达到一定次数，带会发生疲劳破坏。

因此带传动主要失效形式有两个：

  1. 打滑
  2. 疲劳破坏

三、弹性滑动与打滑

1. 弹性滑动

产生原因：带是弹性体，紧边和松边拉力不同，带在绕过带轮时发生弹性变形，从而与带轮之间产生微量相对滑动。

特点：

  • 固有特性；
  • 不可避免；
  • 从动轮圆周速度小于主动轮圆周速度；
  • 传动比不准确，但带仍能工作。

在小带轮上：

  • 进入点拉力为 (F_1)；
  • 离开点拉力为 (F_2)；
  • 拉力逐渐减小，带逐渐收缩；
  • 带速由与小带轮相同逐渐降低。

在大带轮上：

  • 进入点拉力为 (F_2)；
  • 离开点拉力为 (F_1)；
  • 拉力逐渐增大，带逐渐伸长；
  • 带速逐渐增大，但大带轮圆周速度仍小于小带轮圆周速度。

最终：

[
v_1>v>v_2
]

即主动轮圆周速度大于带速，带速大于从动轮圆周速度。

2. 打滑

产生原因：有效圆周力大于极限摩擦力总和，即过载。

特点：

  • 非正常现象；
  • 可以避免；
  • 通常先发生在小带轮上；
  • 会使传动失效、加剧磨损、发热。

为什么先在小带轮打滑？

因为小带轮包角较小，摩擦力较小。

3. 弹性滑动与打滑的区别

项目 弹性滑动 打滑
原因 带的弹性变形 过载，有效圆周力超过极限摩擦力
性质 固有特性，不可避免 失效现象，可以避免
发生范围 局部 整个或大部分接触弧
后果 从动轮速度略小于主动轮 传动失效、严重磨损
是否允许 允许 不允许

4. 滑动率与传动比

滑动率：

[
\varepsilon=\frac{v_1-v_2}{v_1}\times100%
]

一般：

[
\varepsilon=1%\sim2%
]

考虑弹性滑动后的传动比：

[
i=\frac{n_1}{n_2}=\frac{d_2}{d_1(1-\varepsilon)}
]

课堂提醒：计算传动比时，一般情况下滑动率可不代入；只有在需要较精确计算时才考虑。

四、V带传动设计

1. 设计准则

保证带传动：

  1. 不打滑；
  2. 具有足够疲劳寿命。

即：在保证不打滑的前提下，尽量提高疲劳寿命。

2. 设计步骤

第一步：计算设计功率

[
P_{ca}=K_A P
]

其中：

  • (P_{ca})：设计功率
  • (K_A)：工况系数
  • (P)：名义功率

工况系数查教材表 6-6。

第二步：选定带型

根据设计功率 (P_{ca}) 和小带轮转速 (n_1)，查选型图确定 V 带型号。

常见型号：Z、A、B、C、D、E 等。

第三步：确定带轮基准直径

小带轮基准直径：

[
d_1\ge d_{\min}
]

大带轮基准直径：

[
d_2=i d_1
]

并圆整为标准值。

课堂强调：小带轮直径不能小于该型号的最小基准直径。

第四步：验算带速

[
v=\frac{\pi d_1 n_1}{60\times1000}
]

一般要求：

[
5\ \text{m/s}\le v\le25\ \text{m/s}
]

若带速过大，应减小带轮直径；若带速过小，应增大带轮直径。

第五步：确定中心距和基准长度

初选中心距：

[
0.7(d_1+d_2)\le a_0\le2(d_1+d_2)
]

初算带长：

[
L_0=2a_0+\frac{\pi}{2}(d_1+d_2)+\frac{(d_2-d_1)^2}{4a_0}
]

根据标准系列选取相近的基准长度 (L_d)。

实际中心距：

[
a\approx a_0+\frac{L_d-L_0}{2}
]

课堂提醒：选取标准带长时，尽量靠近计算值；若无法把握，可往大选，便于增加张紧装置。

第六步：计算小带轮包角

[
\alpha_1=180^\circ-\frac{d_2-d_1}{a}\times57.3^\circ
]

一般要求：

[
\alpha_1\ge120^\circ
]

第七步：确定 V 带根数

[
z=\frac{P_{ca}}{(P_0+\Delta P_0)K_\alpha K_L}
]

其中：

  • (P_0)：单根 V 带基本额定功率
  • (\Delta P_0)：传动比功率增量
  • (K_\alpha)：包角系数
  • (K_L)：长度系数

计算结果向上取整。

第八步：计算初拉力

[
F_0=500\frac{2.5-K_\alpha}{K_\alpha}\frac{P_{ca}}{zv}+qv^2
]

其中：

  • (q)：单位带长质量，查表得到
  • (v)：带速

第九步：计算压轴力

[
F_Q=2zF_0\sin\frac{\alpha_1}{2}
]

压轴力用于后续轴和轴承的校核计算。

3. 课堂设计例题

已知：

  • 传递功率：(P=4\ \text{kW})
  • 每天工作：16 小时
  • 要求中心距尽量小于 (650\ \text{mm})
  • 电动机：三相异步电动机，Y 形连接
  • 载荷变动较小

计算过程：

  1. 工况系数：

[
K_A=1.2
]

  1. 设计功率：

[
P_{ca}=K_A P=1.2\times4=4.8\ \text{kW}
]

  1. 选带型：查选型图，选 A 型 V 带。

  2. 小带轮基准直径：

[
d_1=100\ \text{mm}
]

  1. 大带轮基准直径：考虑滑动率 (2%)，取：

[
d_2\approx355\ \text{mm}
]

  1. 验算带速：

[
v=\frac{\pi d_1 n_1}{60\times1000}\approx7.5\ \text{m/s}
]

在 (5\sim25\ \text{m/s}) 内，合格。

  1. 初选中心距：

[
a_0=450\ \text{mm}
]

  1. 初算带长约 (1650\ \text{mm})，查标准取：

[
L_d=1640\ \text{mm}
]

  1. 实际中心距：

[
a\approx444.6\ \text{mm}
]

满足小于 (650\ \text{mm}) 的要求。

  1. 小带轮包角：

[
\alpha_1\approx147^\circ
]

满足 (\alpha_1\ge120^\circ)。

  1. 查表：
  • (P_0\approx1.32\ \text{kW})
  • (\Delta P_0\approx0.16\sim0.17\ \text{kW})
  • (K_\alpha\approx0.92)
  • (K_L\approx0.99)
  1. 根数：

[
z=\frac{P_{ca}}{(P_0+\Delta P_0)K_\alpha K_L}\approx3.66
]

向上取整，取：

[
z=4
]

  1. 单位带长质量：

[
q=0.15\ \text{kg/m}
]

  1. 代入计算初拉力 (F_0)。

  2. 代入计算压轴力 (F_Q)。

五、带轮结构与张紧

1. 带轮材料

  • 一般用铸铁；
  • 高速时可用铸钢；
  • 小功率时可用铸铝或塑料。

2. 带轮组成

带轮由三部分组成：

  1. 轮缘
  2. 轮辐
  3. 轮毂

3. 带轮结构形式

根据直径大小分为：

  1. 实心式
  2. 腹板式
  3. 孔板式
  4. 轮辐式

4. 张紧

带工作一段时间后会松弛，需要重新张紧。

常用方法：

  • 调整中心距；
  • 使用张紧轮。

课堂提醒：

  • 更换带时，同一组带应整套更换，不宜新旧混用；
  • 带轮应避免与酸碱接触，避免暴晒；
  • 工作一段时间后要检查并重新张紧。

六、链传动简介

1. 特点

链传动靠链条与链轮齿的啮合传递动力。

优点：

  • 无弹性滑动；
  • 平均传动比准确；
  • 不需要很大张紧力；
  • 能在高温、多尘等恶劣环境下工作。

缺点：

  • 瞬时传动比不恒定；
  • 工作时有冲击和噪声；
  • 一般用于两轴平行的场合。

2. 类型

主要分为：

  1. 滚子链
  2. 齿形链

齿形链传动更平稳，但结构更复杂。

3. 应用

常见于自行车、摩托车、矿山机械等。

七、课堂思考题与要点

  1. 平带传动主要靠什么传递动力？

    • 摩擦力。

  2. (v_1)、(v)、(v_2) 三者关系？

    • (v_1>v>v_2)。

  3. 带传动不能保证准确传动比的原因？

    • 弹性滑动。

  4. V 带传动为什么比平带传动承载能力大？

    • 摩擦系数大，楔形效应。

  5. 影响带传动承载能力的因素有哪些？

    • 带型、小带轮直径、主动轮转速、传动比、包角、带长、材质等。

  6. 打滑先发生在哪个带轮上？

    • 小带轮，因为包角小。

  7. 弹性滑动和打滑的区别？

    • 弹性滑动不可避免；打滑可以避免。
    • 弹性滑动是固有特性；打滑是过载失效。

  8. 带传动的主要失效形式？

    • 打滑和疲劳破坏。
